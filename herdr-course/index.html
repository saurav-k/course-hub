Herdr from Zero

The terminal workspace your coding agents live on, taught from nothing: what it is, how it works underneath, how to install and drive it, what it is for in practice, and a complete plugin-development track. Thirteen lessons in five modules.

Written for a reader who has never used a terminal multiplexer or a coding agent. Every technical claim cites a source the authors opened while writing - mostly the herdr.dev docs and the Herdr repository itself. Start at Lesson 01 if Herdr is new; jump to Module 05 if you already know what a multiplexer is and just want to write plugins today.
