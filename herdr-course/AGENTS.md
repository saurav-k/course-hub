# AGENTS.md - Herdr from Zero

Instructions for AI coding agents working inside this course folder.
The repository root [`../AGENTS.md`](../AGENTS.md) still binds, and it wins wherever
the two disagree. Read it, [`MISSION.md`](MISSION.md), [`NOTES.md`](NOTES.md), and
[`PLOT.md`](PLOT.md) before writing anything here.

## What this course is

A beginner course on [Herdr](https://herdr.dev), the terminal workspace manager that
coding agents live on: thirteen lessons in five modules, from "what is it" to writing,
testing and publishing a plugin. The audience has never used a terminal multiplexer or
a coding agent.

## The rules that bite hardest here

- **This was a port.** The thirteen pages were authored standalone with the design
  system inlined, then converted to link the hub's shared assets. Do not reintroduce
  inline styles, inline runtime code, or a hand-written `COURSE_OUTLINE`; the
  `outline.js` here is generated by `scripts/gen_outline.py` and committed.
- **Teaching content stays as written.** New work appends new lesson numbers at the
  end (`PLOT.md`); nothing already published is renumbered, renamed, or rewritten in
  passing.
- **Version-sensitive claims carry their version.** Facts cite herdr.dev or the Herdr
  repository at 0.8.2-era master by file and line; `NOTES.md` lists which facts drift
  first when Herdr moves.
- **Quiz options match in length**, answer indices vary page to page, and the two
  silent Mermaid traps (literal `<br/>`, semicolons in labels) apply as everywhere in
  the hub.

## Out of scope here

How the coding agents themselves work, general tmux teaching, Herdr Rust internals,
and the full socket-API reference. `MISSION.md` owns the list.
