How to use this course. Each lesson is a lab: a clear goal, the commands and code to run, diagrams of the mechanism, a benchmark to measure, and a checklist. Do them on real hardware where you can (a single cloud GPU is enough for most). Ask your teacher when a step breaks.

Prerequisite mindset: comfort with a terminal, Docker, Python, and basic cloud. The Papers course supplies the theory behind the mechanisms optimised here.
