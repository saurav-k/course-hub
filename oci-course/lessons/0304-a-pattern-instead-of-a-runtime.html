Module 03 · Containers and serverless · Lesson 0304

Three answers in this area are compositions, and each one is documented as such

working 9 min Capability areas serverless-app and containers, matrix rows paas-web-runtime, static-site-hosting and service-mesh.

The one-minute version

  • The application-hosting row is filled by Visual Builder and APEX, both low-code. What OCI does not sell is a general-purpose managed runtime for an ordinary Node or Java web application.
  • That is not a gap in capability. Such an application runs on Kubernetes or Container Instances, which is the documented answer and the one this module has already built.
  • A bucket here has no website endpoint. A static site is served from Object Storage behind API Gateway, which supplies the custom domain and the certificate.
  • The managed service mesh reached end of life, and Oracle's own page names open-source Istio on Kubernetes as the replacement.
  • Each of the three is a composition with a vendor page behind it, which is what separates a documented pattern from a workaround someone invented.

The mental model: three rows, three compositions

The application-hosting row, stated precisely

Visual Builder hosts low-code web and mobile applications, and APEX is the low-code workload type backed by Autonomous AI Database for data-driven applications. Both are real products and both fill the row. What is genuinely different from the other three clouds is that neither of them is a general-purpose managed runtime into which you push a Node or Java application and receive a URL.

The reframing The honest sentence has two halves and both are needed. OCI ships no general-purpose web-application hosting platform of that shape, and an ordinary web application runs on Container Instances or on Kubernetes, which are the documented answers. Saying only the first half is the false absence; saying only the second half hides a real packaging difference.

The static-site row: why the gateway is there

The tutorial gives two ways for the gateway to reach the files: a public bucket, or a pre-authenticated request that scopes the access. The second is the one worth learning, because it keeps the bucket itself closed while letting exactly one route through.

This row is the classic false-absence generator, because the missing thing has a famous name on another cloud. A comparison table that writes "no equivalent" here is claiming OCI cannot serve a static site, which is plainly untrue - what it cannot do is serve one from a bucket endpoint on a custom domain without something in front.

The mesh row: a product that ended

Deployment strategies did not move with it. Traffic shifting for blue-green and canary releases is a first-class feature of OCI's own deployment pipelines against Kubernetes, and module 12 is where that is worked properly. What the mesh would have added on top - fine-grained per-request routing across the whole service graph - is now an open-source component you run yourself.

Retrieval practice

Answer from memory before revealing.

Which sentence about hosting an ordinary Java web application on OCI is both true and useful?
Both halves matter: there is no general-purpose managed web runtime of that shape, and the application runs perfectly well on Container Instances or Kubernetes. The first option is the false absence. The second and third point at real products that host low-code applications rather than an arbitrary Java one.
What does API Gateway supply that an Object Storage bucket cannot, for a static site?
A bucket has no website endpoint, so the vanity domain and the certificate come from the gateway. The other three are all things Object Storage does provide on its own - durability, replication and access control - which is precisely why the gateway is needed for one thing and not for everything.
A tutorial configures OCI Service Mesh for mutual TLS between services. What should a reader do?
The documentation page is now an end-of-life notice naming open-source Istio as the replacement, so the tutorial configures something that has ended. The first two treat a retired service as current, and the fourth swings the other way into a false absence - the capability exists, it is just yours to run.

Practice about 15 minutes, with paper

Practice 1working

A product needs three things shipped on OCI: a documentation site of static files on docs.example.com, an internal admin tool that a small team will build without much engineering time, and a public Go API that must survive an instance failure.

Choose the OCI answer for each, and for each one write the sentence you would put in an architecture document - the version that would survive a reviewer who knows another cloud well.

Hint

For each requirement, ask whether the answer is one product or a composition. Then, when writing the sentence, check whether it would still be true if the reader had never heard of the other cloud's product name.

Show the worked solution
  1. The documentation site. A composition: the files sit in Object Storage and API Gateway fronts them, supplying the custom domain and the certificate. The sentence: "Static documentation is served from an Object Storage bucket behind API Gateway, which terminates TLS for docs.example.com - OCI buckets have no website endpoint of their own."
  2. The admin tool. A product, and the low-code row is genuinely the right answer here rather than a consolation. The sentence: "The internal admin tool is built in APEX against Autonomous AI Database, which is OCI's low-code path for data-driven applications."
  3. The Go API. A product, and the choice is between two of them. The sentence: "The Go API runs as a container. It is deployed to a Kubernetes cluster so that a failed instance is replaced by the cluster - OCI has no general-purpose managed web-application runtime, and a container platform is the documented answer."
  4. Check the third sentence against a hostile reader. It names the packaging difference and the answer in one breath, so a reviewer arriving from a cloud with a managed web runtime learns what changed without being told the platform cannot do it. That two-part shape is what makes the sentence survive.

Sanity check. Exactly one of the three should have been a composition rather than a product, and none of the three sentences should contain the word cannot without a following clause saying what to do instead.

Your teacher. Next time an agent hands you a cloud comparison, look only at the cells that say a platform has nothing. For each one, ask what a customer with that requirement actually builds. The answer usually exists, and how the cell was written tells you how much to trust the rest of the table.

It is the shortest complete example of a documented composition on this platform, and doing it once makes the difference between a missing product and a missing capability concrete rather than theoretical.
