Renting a whole host buys placement control and gives up almost everything else

working 11 min Capability area compute-iaas, matrix rows bare-metal, dedicated-hosts and confidential-compute.

The one-minute version

  • Placement inside a region is two choices: which availability domain, and which of that domain's three fault domains. Both are made at launch.
  • Host tenancy is a separate ladder: shared host, a dedicated virtual machine host, or a whole bare metal server with no hypervisor at all.
  • A dedicated host bills for the entire shape whether or not you fill it, so the case for it is a density calculation before it is a security argument.
  • It also costs you mobility. Oracle documents dedicated virtual machine hosts as carrying no live migration, no autoscaling and no instance pools.
  • Confidential computing is not a separate product. It is a property of the shape, chosen at launch, with memory encrypted from the hypervisor by keys the host never sees.

The mental model: two independent choices

Fault domains are the resilience half and they were counted in lesson 0100: three per availability domain, everywhere, giving host-level anti-affinity for free. Nothing on the tenancy ladder replaces that, and the widest dedicated host in a region is still one failure boundary.

The mechanism: the three rungs and what each one costs

Bare metal is not a special ordering path on OCI. It is an ordinary shape family launched the way anything else is launched, which is why it carries advanced firmware options - disabling multithreading or cores, tuning memory locality - and why the dense variants carry local NVMe. What it does not carry is live migration: Oracle documents maintenance on bare metal as a reboot migration, so the guest stops and comes back.

The trade-off: the density calculation

The mobility cost is the one that is discovered late. Oracle records that dedicated virtual machine hosts have no live migration, no autoscaling and no instance pools. A workload placed there cannot later be wrapped in the fleet machinery of the next page without moving off the host first, and by then the licensing argument that put it there has usually hardened.

Confidential computing is a shape property

That framing matters because it means confidential computing composes with everything else on this page: it is available on virtual machine and bare metal shapes, and the decision is made in the same launch dialogue as the size. The full family list is on the confidential computing reference.

Retrieval practice

Answer from memory before revealing.

A team buys a dedicated virtual machine host so their two critical instances survive a hardware failure. What is wrong with the reasoning?
Both instances now sit on the same physical machine, which is the opposite of anti-affinity - fault domains are what spread instances across hardware. The first option is simply false, the second reverses the billing model, and the fourth names a network constraint that has nothing to do with the failure argument.
Which combination does Oracle document as unavailable on dedicated virtual machine hosts?
Those three are the documented exclusions, and together they are what stops a dedicated host from participating in the fleet machinery. The other three options each list ordinary compute capabilities that a dedicated host does not lose, so answering with any of them would remove the wrong thing from the design.
How is confidential computing selected on OCI?
It is a property of the shape, chosen when the instance is launched, so the real constraint is which families support it. The first invents a tenancy-level toggle, the second names a real OCI guardrail that governs resource creation rather than memory encryption, and the third describes a different design where the protected code is split out into a separate room.

Practice about 15 minutes, with paper

Practice 1working

A vendor licence is priced per physical core and permits sub-capacity licensing only on hardware the customer can prove is single-tenant. The application needs six virtual machines of four OCPUs each, has to survive one hardware failure without losing more than a third of its capacity, and must run in a region with a single availability domain.

Design the placement: how many dedicated hosts, how the six machines are arranged, and which requirement the design cannot satisfy at the same time as the licence.

Hint

Write down the isolation slots the region actually offers before deciding anything. Then ask what a dedicated host is, in terms of those slots, and how many slots one host can occupy.

Show the worked solution
  1. Count the isolation slots. One availability domain gives exactly 3 fault domains. Losing more than a third of six machines means losing more than two, so no fault domain may hold more than two machines.
  2. Turn that into a host count. A dedicated host is a single physical machine and therefore sits inside one fault domain. Six machines at two per fault domain means at least three dedicated hosts, one per fault domain, each holding two of the six.
  3. Check the host capacity. Each host carries two machines of four OCPUs, so eight OCPUs of the host shape are in use. Whatever the host shape's full size is, the tenancy pays for all of it three times over, and the licence is charged against the whole host rather than the eight OCPUs.
  4. Find the requirement that will not fit. None of the six machines can be in an instance pool or under autoscaling, because dedicated hosts support neither. The design satisfies the licence and the failure requirement, and gives up automatic replacement of a failed instance - which has to be handled outside the platform.

Sanity check. The host count should equal the fault-domain count, not the machine count. If your answer came out as six hosts, you spread by host rather than by fault domain and paid three times more than the failure requirement asked for.

Your teacher. If the ladder still feels like one decision, ask an agent for the same instance described twice: once by its fault domain and once by its host tenancy. Then ask which of the two you would have to change to survive a hardware failure. Only one of them is the answer, and the other is the one people buy.
