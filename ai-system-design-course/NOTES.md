# Notes

## Learner profile

- Principal engineer, twelve years, strong distributed systems background.
- Target: Senior to Staff+ AI/ML system design rounds.
- Already fluent in databases, caches, queues, sharding, replication, backpressure. Do not re-teach these.

## Teaching preferences

- Concept-only revision. No slow-walking of fundamentals.
- Mental model first, then the mechanism, then the trade-off, then the interview angle.
- Every technical claim carries a citation. Parametric memory is not a source.
- Plain dash, never an em dash, in all content.
- Quiz options must match in length so formatting never leaks the answer.

## Structure decisions

- Chapters, not micro-lessons. The learner asked for one chapter per pillar, covering every topic in that pillar.
- Each topic gets its own subsection with a linked primary source, so a chapter also works as a revision index the night before an interview.
- Each chapter ends with an interview drill: the questions actually asked, and the trap in each.
