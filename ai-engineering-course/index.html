Beyond the working demo

Your demo works, and you cannot prove it is any good.

This is the build track between the interview track and the harness track: what you do to turn one working LLM script into a system you can measure, improve, defend and operate. A retrieval pipeline with evaluation and observability wired in on day one, retrieval quality proved with numbers on your own thirty questions, agents with tools and memory graded on their trajectory, multi-agent orchestration over MCP and A2A priced before it is built, and a deployment with three probes, four caches and a threshold in CI. Fifty-three lessons across eight modules, 900 to 1,400 words each, built around one application you carry from the first page to the last.

Start with Your demo works and you cannot prove it, keep the Glossary open in a tab, and read AI System Design for Staff+ Interviews when your question turns from how to build one into how to defend one at a whiteboard.

02

Retrieval quality and context engineering

9 lessons

Working rung, and the module whose whole promise is a number that moved. No lesson here ships without stating what it changed on the reader's own golden set, and the module's capstone page must carry at least one row with a zero or a negative delta.

  • Lesson 0200Ingestion is a pipeline, and every chunk needs an identity - A chunk that cannot name its source, its offset and its checksum cannot be re-ingested or cited.
  • Lesson 0210A schema is a contract the model has to satisfy - One object in three forms: a Python class, a JSON Schema, and a wire payload you can validate at the boundary.
  • Lesson 0220Chunking is a boundary decision, and the boundary is where meaning is lost - Retrieval precision and generation sufficiency pull in opposite directions, and the sweep settles it.
  • Lesson 0230A chunk that cannot say where it came from cannot be found - Two repairs for the orphan chunk, with their bills: context written in, against embed then split.
  • Lesson 0240The window is an attention budget, not a container - More retrieved passages raise the chance the answer is present and lower the chance it is attended to.
  • Lesson 0250A prompt is a versioned artefact with a name - A prompt with no name and no version makes a regression unattributable, which is the Tuesday nobody enjoys.
  • Lesson 0260Two rankings beat one, and RRF is the cheapest way to add them - Reciprocal rank fusion needs no scores, no tuning and no training, and its k barely matters.
  • Lesson 0270A reranker is a second, more expensive opinion on twenty documents - A cross-encoder buys ranking quality with latency, linearly, and the funnel is where you choose how much.
  • Lesson 0280The document you retrieved is untrusted input - The retrieved passage is somebody else's text inside your prompt, and the model cannot see the seam.
  • Lesson 0290Free position - Held for a lesson a module 2 writer discovers they need.

From basic to agentic RAG

6 lessons

Working rung, and the join. Module 2's pipeline and module 3's loop become one system: retrieval the model decides to call, a grader with a refusal path, a pause the reader can resume, and a feedback loop that grows the golden set.

  • Lesson 0400Retrieval becomes a tool the model decides to call - Always retrieve becomes retrieve if needed, and the tool description is what decides.
  • Lesson 0410A retrieval you do not trust is one you can correct - A lightweight grader between retrieval and generation buys a refusal path, which is a designed exit rather than a failure.
  • Lesson 0420A pause is a state you saved, not a thread you blocked - Human-in-the-loop is a checkpoint on disk, and the node restarts from its first line rather than resuming mid-function.
  • Lesson 0430A thumb down is a row in the golden set - A feedback record with no trace id is unusable, and the loop closes on the set module 1 built.
  • Lesson 0440Your RAG app is a host, and its best source is one you did not write - Mounting a server you do not run changes what reaches the window without changing top-k, and the annotation defaults are the trap.
  • Lesson 0450A deep research agent is a retrieval loop with a citation contract - The loop is cheap to describe and expensive to run, and the citation contract is what makes it checkable.

06

Deployment, optimization and reliability

8 lessons

Working rung, and the heaviest module in the course. Six syllabus bullets that are each a separate mechanism with its own hands-on act: request shapes, health, latency, four caches, injection, the CI gate, and monitoring a system that fails without an error.

Lesson 0600
Four shapes for a request that takes thirty seconds
A model call is slow, streamed, expensive and non-idempotent. Every endpoint you have is synchronous, streamed, queued with a handle or offline batch, and the question that picks one is whether the caller waits.
working10 min
Lesson 0610
The provider is a dependency you do not own
Liveness restarts, readiness withdraws traffic, startup gates both. A liveness probe that calls the model kills every pod thirty seconds into an outage nobody could have fixed.
working9 min
Lesson 0620
Where the seconds go
Time to first token plus output tokens times the time between them. Only output length is yours, and the term you did not bound is the term that will move.
working10 min
Lesson 0630
Four caches, and only two of them are yours
Response cache, semantic cache, the provider's prompt cache and the serving engine's KV cache. On the published multipliers the prompt cache pays from the second request, and it is bought with prompt order rather than configuration.
working9 min
Lesson 0640
Semantic caching, and the false hit you have to measure
Every hit is a cheap right answer or a cheap wrong one. The one primary source that counted both found 39 wrong answers in 876 hits, and its authors call that unacceptable in production.
working10 min
Lesson 0650
What a prompt injection is allowed to do
Six published patterns constrain what an agent may do once it has read untrusted text, each giving up a named capability. The measured price of the strictest is seven points of task completion.
working9 min
Lesson 0660
CI when the unit test is a distribution
Three tiers at three frequencies, and a gate is a metric, a threshold and a sample size. Thirty questions carries about seven points of standard error, so a tighter threshold fails honest builds at random.
working10 min
Lesson 0670
Monitoring a system whose failures are quiet
Every failure in this module returns 200. Token counts, finish reasons, cache hit share and the nightly eval are the four signals, they already have standard names, and you scale on queue depth rather than CPU.
working10 min
Capstone 1050
Ship it
Module 6's eight changes assembled into one deployment and four short documents: the endpoint table, the two budgets and the containment note.
