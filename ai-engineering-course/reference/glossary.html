14 terms Every term this course introduces, linked to the page that develops it. Definitions here are deliberately narrower than the field's: they say what the word means in this course. Print it and cover the right-hand column.

This sheet is seeded rather than finished. It carries only the terms lesson 0000 introduces, because lesson 0000 is the only page written. The rest arrive in one pass after the eight modules land: every module would otherwise append to the same alphabetical list and conflict with every sibling, and the terms are better chosen once the whole course exists. Adding a row is the integrator's job, not a module writer's.
TermWhat it means here
baseline The first measurement, taken before anything is improved, and written into the repository rather than a notebook. Everything the course does afterwards is a delta against it.
capstone One application the reader carries from lesson 0000 to the last page, gaining an increment at the foot of most modules and measured every time on the same golden set. Not a final project.
corpus The set of documents the system answers from. Chosen by the reader, because a reader who cares about the corpus is the only one who will look at the failures.
Development status OpenTelemetry's marker for a convention that may still be renamed. Every GenAI semantic convention carries it, so every page in this course that quotes an attribute name says so in the same paragraph.
generation defect A wrong answer where the right passage was retrieved and reached the packed prompt, and the model still did not use it. The rarest of the three failure modes and the first one everybody reaches for.
golden set Questions written by hand, each with the passage that answers it, used to score every later change. Thirty in module 1; ten is where lesson 0000 starts.
packed prompt The request as it actually leaves the machine: a system prompt, an instruction, the question, and the retrieved passages. In the worked example the passages are 93% of it.
packing defect A wrong answer where the right passage was retrieved and then did not survive into the packed prompt, usually because something else took the room.
recall at k The share of golden-set questions whose answering passage appears in the first k results. The metric that matters most for retrieval, because a generator cannot use what was never returned.
retrieval-augmented generation A search engine with a writer attached. The search decides which facts exist for a request; the writer decides the wording and nothing else.
retrieval defect A wrong answer where the passage that would have answered the question was never returned at all. No change to the prompt can repair one.
retrieval span The one span in a request that records what the search returned: the query text, the top_k asked for, and every document with its id and its score.
span One recorded stage of a request, with a name, a duration and attributes. The GenAI conventions publish six kinds, of which three appear in the simplest retrieval request.
trace All the spans of one request, nested. What replaces the print statement the moment a request has more than one stage, which is immediately.
