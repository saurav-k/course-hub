Glossary

52 termsprint-friendly Every term this course introduces, linked to the page that develops it. Definitions here are deliberately narrower than the field's: they say what the word means in this course. Print it and cover the right-hand column.

One definition, one owner. Each row links the single page that develops the term, so a disagreement between this sheet and that page is always resolved in the page's favour. Terms the course uses but does not teach - transformer, attention, embedding model architecture - are deliberately absent; they belong to the neighbouring courses named in the course map.
TermWhat it means here
A2A A protocol for reaching an agent you cannot see inside. Its unit is a task with a lifecycle, and the peer is opaque by design - which is what distinguishes it from calling a tool.
Agent Card The committed description an A2A peer publishes about itself. A contract rather than a schema, because the caller cannot inspect the implementation behind it.
agent, against workflow A workflow runs predefined code paths; an agent directs its own. Most systems called agents are workflows, and knowing which you have decides how you bound it.
baseline Module 1's six artefacts committed as one object: the numbers plus enough identity to say which system produced them. Everything later in the course is a delta against it.
blast radius How far one wrong answer travels before a human sees it. The sixth review question, and the one most about the product rather than the code.
cache breakpoint The mark that tells a provider where a cacheable prefix ends. At most four, and everything before it must be stable across requests or nothing is cached.
capstone One application the reader carries from lesson 0000 to the last page, gaining an increment at the foot of most modules and measured every time on the same golden set. Not a final project.
chunk identity A stable id for a chunk that survives re-ingestion, so a corpus can be updated rather than only rebuilt.
context engineering Deciding what goes into one request's window and in what order. In this course it is one turn's retrieval payload, not state across a whole conversation.
contextual chunk A chunk with the surrounding context written back into it before embedding, so a passage that lost its subject can still be retrieved.
corpus The set of documents the system answers from. Chosen by the reader, because a reader who cares about the corpus is the only one who will look at the failures.
decision record Two numbers and a verdict: your measured cost, a projected alternative, and which you chose. A recorded no is a complete result.
degraded mode What your service does when the provider is unavailable - serve cached, queue, return retrieval without generation, or refuse clearly. An application decision, never a probe.
delta table One row per change with the delta it produced, on one unchanged question set. At least one row must read zero.
design record The six review questions answered in prose. Transcription rather than research, because the answers were produced at the previous stop.
Development status OpenTelemetry's marker for a convention that may still be renamed. Every GenAI semantic convention carries it, so every page in this course that quotes an attribute name says so in the same paragraph.
false hit A semantic cache returning a stored answer to a question it does not actually answer. It raises no error and is invisible in every ordinary metric.
finish reason Why generation stopped. A rise in the length-limit reason is truncation arriving as successful responses.
generation defect A wrong answer where the right passage was retrieved and reached the packed prompt, and the model still did not use it. The rarest of the three failure modes and the first one everybody reaches for.
golden set Questions written by hand, each with the passage that answers it. Thirty is the target, it only ever grows, and every number in the course is measured on it.
HNSW A layered proximity graph that trades recall for latency. Its knobs are yours; its default behaviour under a filter is the trap.
judge agreement How often a model scorer agrees with your own hand-scoring. It is the confidence interval on every automated score in the course.
MAST categories Three clusters of observed multi-agent failure - system design, inter-agent misalignment, task verification - that a trace can tell apart and a prompt edit cannot.
nDCG@10 A ranked retrieval measure that discounts hits by position. Use it once order matters; recall is enough while you are fixing what arrives.
packed prompt The request as it actually leaves the machine. In the worked example the retrieved passages are the overwhelming majority of it.
packing defect A wrong answer where the right passage was retrieved and then did not survive into the packed prompt, usually because something else took the room.
pass^k Whether all k trials of the same task succeeded. An agent that works once is not an agent that works.
plan ledger A durable record of an orchestrator's plan, with every rewrite logged, so a stalled team has an address rather than a theory.
poisoned chunk A document carrying an instruction, planted deliberately and kept in the golden set permanently as a regression test.
prompt cache The provider's cache of a repeated prefix. Bought by ordering your prompt rather than by configuration, and on the published multipliers it pays from the second request.
recall at k The share of golden-set questions whose answering passage appears in the first k results. The metric that matters most for retrieval, because a generator cannot use what was never returned.
recall@k The share of golden-set questions whose answering passage appears in the top k. The generator cannot use what did not arrive, so it bounds everything downstream.
refusal path The route by which a system declines rather than answers. Only a feature if it is scored, which is why unanswerable questions enter the set.
reporting rule A number with no k, no named question set and no corpus version is not a number.
request shape Which of synchronous, streamed, queued or batch an endpoint is. Chosen by whether a caller waits and whether a partial answer is worth anything.
rerank A second, more expensive opinion over a shortlist. The last rung of the published ladder and the only one your users wait for.
retrieval defect A wrong answer where the passage that would have answered the question was never returned at all. No change to the prompt can repair one.
retrieval span The one span that records what the search returned: the query, the top k, and each document with its id and score. The two attributes that matter are Opt-In.
retrieval-augmented generation A search engine with a writer attached. The search decides which facts exist for a request; the writer decides the wording and nothing else.
RRF Reciprocal rank fusion: combining two ranked lists by position rather than by score, which is what makes hybrid search work without calibrating either scorer.
semantic cache A cache that serves a stored answer when a new question is close enough. The threshold is the whole design, and it trades hit rate against wrong answers.
shared state What two agents can both see. Its lifetime per key is a design decision, and it has to survive a restart.
span One recorded stage of a request, with a name, a duration and attributes. The GenAI conventions publish six kinds, of which three appear in the simplest retrieval request.
system card The honest version of a README's claims: what the system is for, how it was evaluated, and where it fails. You owe one even though you trained nothing.
taint map A turn split by who wrote each block. The model cannot tell them apart, so the boundary has to be a permission.
three test tiers Deterministic tests, tool contracts, and the golden set with a threshold. Only the first two run on every push.
time to first token How long the reader stares at nothing. Streaming changes it and changes no total duration, so a duration-only dashboard cannot see the improvement.
tool call The model emitting a name and a JSON object, then waiting. Nothing executes on its side; every capability is a function you wrote.
trace All the spans of one request, nested. What replaces the print statement the moment a request has more than one stage, which is immediately.
trajectory The sequence of tool calls a run actually made, compared against what you expected under a named match rule.
turn ceiling A cap on agent loop turns. Cost is quadratic in turns because each turn re-sends the history, and a ceiling with no degradation behind it is a crash with a nicer name.
unanswerable question A golden-set row whose correct behaviour is a refusal. Without them a refusal path is untested code.
