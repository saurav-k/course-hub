The figures this course reuses

2 figuresprint-friendly Two pictures that more than one page needs. They are drawn once, here, and every page that needs one links to it. Copied from the lesson that owns each rather than redrawn, because a figure redrawn slightly differently is two claims wearing one caption.

The rule this sheet exists to enforce. A figure lives on the page that develops it. It is copied here only when a second page needs the same picture, and the copy is byte-identical to the original. When the owning lesson changes its figure, this sheet changes with it in the same pull request. If the two ever disagree, the lesson is right and this sheet is stale.

1. The four request shapes

Owned by lesson 0600, which develops it. It is here because three later pages sort something into these four rows rather than re-explaining them: the health contract in 0610 sets a timeout per shape, the latency budget in 0620 is reported per shape, and the capstone page Ship it asks for the finished table.

The two questions that select a row are on the owning lesson and are not repeated here: does the caller wait, and is a partial answer worth anything.

2. The six-question design review

Not yet drawn. This figure is owned by lesson 0730, The design review: six questions, on your own system, which is not written yet. It is reserved here rather than drawn, because this sheet's own rule is that a figure is copied from the lesson that owns it and never invented ahead of it. The alternative - drawing it here first and having the lesson match a reference sheet - is how the two end up disagreeing. It arrives in the integrator pass that follows module 7.
