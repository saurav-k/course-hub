DESK EFFICIENCY Glossary Course Hub
FOR ML AND PLATFORM ENGINEERS WITH HARDWARE OF THEIR OWN

A 320B model can live on your desk - if you know which three levers to pull.

Every page earns one mechanism by arithmetic before it uses it: why token generation is bound by memory bandwidth, what quantization spends to shrink a model, how LoRA and QLoRA steer a frozen 320B network with adapters measured in megabytes, and how speculative decoding multiplies throughput on bandwidth-starved silicon. It ends with two worked deployments of GLM-5.3-Flash: a two-node DGX Spark cluster and a single 256 GB Mac Studio. Eleven pages, one sitting each.

Start with the first page, keep the Glossary open in a tab, and read LLM Inference Optimization when you need the serving-side depth.
