Glossary

24 terms Every term this course introduces, linked to the page that develops it. Print it and cover the right-hand column.

TermWhat it means here
PrefillThe compute-bound pass that reads the whole prompt once and fills the KV cache before decoding starts.
Decode loopThe one-token-per-step phase whose cost is dominated by reading the active weights from memory.
Memory bandwidthBytes the hardware can read per second; the numerator of this course's most important division.
Bytes per tokenActive parameters times bytes per weight - the amount read to produce one token.
KV cachePer-token cached attention state that makes conversation possible and spends the memory left after the weights.
Mixture-of-experts (MoE)An architecture holding many expert networks but routing each token through only a few.
Total parametersEverything in the file, experts included; decides what must be stored.
Active parametersThe parameters one token actually touches; decides what must be read per token.
RouterThe small network that picks which experts serve each token, per layer.
QuantizationMapping continuous weights onto a small grid of representable values, spending rounding error for bytes.
ScaleOne group's grid spacing: the group's largest magnitude divided by the grid's steps.
Outlier channelA weight channel of unusual magnitude that forces coarse grids on its neighbours under a shared scale.
GGUFThe llama.cpp single-file container with a choice of quantization schemes, runnable from CPU upward.
FP8Vendor-native 8-bit floating format on Hopper-class and newer NVIDIA silicon; the course model's shipped format.
NVFP4Blackwell's native 4-bit floating format; roughly halves the FP8 file and doubles the bandwidth ceiling.
LoRATraining two thin low-rank matrices per adapted layer while the base weights stay frozen.
RankThe thin dimension of the LoRA pair; the dial trading adapter capacity against size.
NF4A 4-bit grid placed at a normal distribution's quantiles, so resolution sits where weights live.
Double quantizationQuantizing the quantization scales themselves, recovering a few percent of the file.
Paged optimizersSpilling transient optimizer state to disk during training memory spikes instead of crashing.
MergingBaking a trained adapter into the base weights once, so inference pays nothing for it.
Speculative decodingDrafting several tokens cheaply and certifying them in one target weight pass.
Acceptance rateThe probability the target keeps a drafted token; the variable that decides the speedup.
MTPMulti-token prediction: a draft layer trained into the model itself, removing the second model from memory.
