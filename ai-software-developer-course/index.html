For engineers who drive agents

You have been driving an agent loop for two years without seeing it.

This is the practitioner's track: what you do at the keyboard and in the repository to make coding agents useful, safe and many. The loop and the four tools it dispatches, context as a budget you spend, skills and repository contracts, what makes a codebase agent-ready and how to score one, AI review, where prompt injection enters, and running ten unattended agents with a ceiling. Eighty-six pages across ten modules, 900 to 1,400 words each, built around one repository you make agent-ready as you go.

Start with You are already running one, keep the Glossary open in a tab, and read Coding Harness Engineering when your question turns from how to drive one into how one is built.

  • Lesson 0120The core four tools - Read, list, edit and bash are enough to do the job, because a filesystem plus a shell is a universal interface.
  • Lesson 0130Reading a tool-call trace - The trace answers “why did it do that” faster than any prompt change.

  • Lesson 0160Two hundred lines - The whole loop fits on one screen, and building it once removes the magic permanently.
