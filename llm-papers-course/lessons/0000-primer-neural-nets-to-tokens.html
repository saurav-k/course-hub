Primer: From Neural Nets to Tokens

No paper this time. This is the ground floor. If the words token, embedding, softmax, loss and gradient descent are fuzzy, do this lesson first. Everything after assumes it.

The one-minute version

  • A language model is a machine that reads a list of tokens and predicts the next token.
  • Text becomes numbers: tokens → integer ids → embedding vectors the model can do math on.
  • The model outputs logits (one score per possible token); softmax turns them into probabilities.
  • Training measures wrongness with a loss, then gradient descent nudges every weight to lower it. Repeat billions of times.

1. What a language model actually does

Strip away the hype and a large language model does exactly one thing: given some text so far, it guesses what comes next. That is it. "The cat sat on the ___" and it puts high probability on mat, lower on roof, near-zero on photosynthesis. Every capability - answering questions, writing code, translating - is this next-token guess, done over and over.

2. Text is turned into numbers

Models cannot read letters. Before anything, text is chopped into tokens by a tokenizer. A token is usually a sub-word piece, not a whole word: common words are one token, rare words split into several. Each distinct token has an integer id, and the full set of possible tokens is the vocabulary (tens of thousands of them).

An embedding is a learned vector - a list of numbers, say 768 of them - that represents a token. The magic is that these vectors are learned so that related tokens land near each other in space. The vector for king sits near queen; Paris near London. The model builds all of its understanding on top of this geometry.

3. Inside: a neural network

Between the input embeddings and the output prediction sits the neural network - the model proper. At its simplest, a neural network is layers of two operations repeated: a linear step (multiply by a matrix of weights, add a bias) and a non-linear step (a simple bend like ReLU that lets the network represent curves, not just straight lines).

The numbers inside all those matrices are the parameters (or weights). "A 7B model" means 7 billion of these numbers. Training is the process of finding good values for every one of them.

4. Logits and softmax: from scores to probabilities

The network's final layer produces one raw score - a logit - for every token in the vocabulary. Big logit means "likely next". But raw scores are not probabilities: they can be negative, and they do not sum to anything tidy. Softmax fixes that. It exponentiates each score (making it positive and amplifying differences) then divides by the total, so the result is a clean probability distribution.

softmax(z)i = e^{zi} / Σj e^{zj} For token i: take e to the power of its logit, divide by the sum of e-to-the-logit over every token. Output is between 0 and 1, and all outputs add to 1.

5. Loss: measuring how wrong the model is

During training we know the true next token. The model gave it some probability. If it gave the right token 0.9 probability, good; if 0.01, bad. Cross-entropy loss turns this into a single number to minimise: it is the negative log of the probability the model assigned to the correct token.

loss = − log( pcorrect token ) Assign 1.0 to the right token and loss is 0 (perfect). Assign something tiny and −log makes the loss large. The model is punished in proportion to how surprised it was by the truth.
Intuition Loss is a "surprise meter". Low loss = the truth was unsurprising to the model = it predicted well. All of training is one goal: make the average surprise small.

6. Gradient descent: how learning happens

We have a knob for every parameter (billions of them) and a loss we want to shrink. Gradient descent is the method: for each parameter, compute the gradient - which direction and how strongly changing that parameter would raise the loss - then step every parameter a little in the opposite direction. Backpropagation is the efficient algorithm that computes all those gradients in one backward sweep through the network.

7. See it in code

Here is the whole idea - softmax, cross-entropy loss, and a single gradient step - in a few lines of NumPy, with no deep-learning framework hiding the machinery. Run it; watch the loss drop.

primer.py · runnable with just numpy
import numpy as np

# One training example: input vector x, correct next-token id = 2
x = np.array([0.5, -1.2, 3.3])          # a (tiny) input "embedding"
y_true = 2                               # the token that actually comes next
vocab = 4                                # pretend vocabulary of 4 tokens

# Model = one linear layer W (vocab x 3). These are the parameters we learn.
rng = np.random.default_rng(0)
W = rng.normal(size=(vocab, 3)) * 0.1

def softmax(z):
    z = z - z.max()                      # subtract max for numerical stability
    e = np.exp(z)
    return e / e.sum()

lr = 0.5
for step in range(50):
    # ---- forward ----
    logits = W @ x                       # raw scores, one per token
    probs  = softmax(logits)             # -> probabilities
    loss   = -np.log(probs[y_true])      # cross-entropy on the correct token

    # ---- backward (gradient of cross-entropy through softmax) ----
    dlogits = probs.copy()
    dlogits[y_true] -= 1                 # the famous (softmax - onehot) gradient
    dW = np.outer(dlogits, x)            # chain rule to the weights

    # ---- update ----
    W -= lr * dW

    if step % 10 == 0:
        print(f"step {step:2d}  loss {loss:.3f}  p(correct) {probs[y_true]:.3f}")

print("final p(correct):", softmax(W @ x)[y_true])

That dlogits = probs; dlogits[y_true] -= 1 line is the single most reused gradient in all of deep learning: the gradient of softmax-cross-entropy is just predicted probabilities minus the one-hot truth. Every LLM trains on exactly this signal, scaled up to billions of parameters and trillions of tokens.

What does a language model fundamentally predict?
Everything an LLM does is repeated next-token prediction, left to right.
What is the job of the softmax function?
Softmax exponentiates and normalises logits so they are positive and sum to 1.
In gradient descent, each weight is moved how?
The gradient points uphill on the loss, so we step the opposite way, scaled by the learning rate.

How this connects

You now have the whole vocabulary of learning: tokens in, embeddings, a network of linear-and-bend layers, logits out, softmax to probabilities, cross-entropy loss, gradient descent to improve.
