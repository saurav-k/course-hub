LLaMA

2023 Touvron, Lavril, Izacard, Martinet, Lachaux, Lacroix, et al. (Meta AI). · arXiv:2302.13971 · "LLaMA: Open and Efficient Foundation Language Models"

The one-minute version

  • Take Chinchilla's lesson further: train smaller models on far more tokens than "optimal", because a model is trained once but served forever.
  • Sizes 7B, 13B, 33B, 65B, trained only on publicly available data (no proprietary corpora).
  • Three now-standard architecture tweaks: RMSNorm pre-normalisation, SwiGLU activation, RoPE positions.
  • LLaMA-13B beat GPT-3 175B on most benchmarks; 65B rivalled PaLM-540B. It became the open-source default that everything after builds on.

1. Why this paper exists

Chinchilla (Lesson 08) optimised for training compute. LLaMA changed the objective: also count the inference cost, which you pay on every single query for the life of the model. Under that lens, it is worth over-training a small model well past 20 tokens/param, because a smaller model is cheaper to run billions of times later. The other goal was openness: use only public data so the whole research community can build on it.

2. Trained on public data only

LLaMA deliberately used only openly available sources, mixed in fixed proportions. This is what made the weights (once leaked, then formally opened in later versions) so influential.

3. The three architecture changes

LLaMA keeps the decoder-only Transformer from GPT but swaps three components. Each is a small change that improves stability or quality, and together they define the modern LLM block.

RMSNorm - a cheaper LayerNorm

LayerNorm re-centres (subtract the mean) and re-scales (divide by standard deviation). RMSNorm drops the re-centring and just divides by the root-mean-square. Fewer operations, same stabilising effect in practice.

RMSNorm(x) = x / sqrt( mean(x2) + ε ) · g Square every element, average them, take the square root: that is the vector's "typical size". Divide the vector by it so its scale is normalised, then multiply by a learned gain g. No mean subtraction, unlike LayerNorm.

SwiGLU - a gated activation

Instead of the plain Linear -> ReLU -> Linear feed-forward, SwiGLU splits into two projections and lets one gate the other through a smooth Swish function. It reliably improves quality per parameter.

SwiGLU(x) = ( Swish(x W1) ⊙ (x W3) ) W2 Project x two ways. Pass one through Swish (a smooth, slightly-negative-allowing bend), and use it to element-wise multiply (⊙, the gate) the other projection. A third matrix projects back down. The gate lets the network modulate information more flexibly than a single ReLU.

4. Build the LLaMA block

Here are RMSNorm and SwiGLU in PyTorch, the two pieces you have not seen yet (RoPE gets its own lesson next module). Read them against the equations above.

llama_block.py · runnable with torch
import torch, torch.nn as nn, torch.nn.functional as F

class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.g = nn.Parameter(torch.ones(dim))     # learned gain
    def forward(self, x):
        rms = x.pow(2).mean(-1, keepdim=True).add(self.eps).rsqrt()
        return x * rms * self.g                     # normalise, then scale

class SwiGLU(nn.Module):
    def __init__(self, dim, hidden):
        super().__init__()
        self.w1 = nn.Linear(dim, hidden, bias=False)   # gate branch
        self.w3 = nn.Linear(dim, hidden, bias=False)   # value branch
        self.w2 = nn.Linear(hidden, dim, bias=False)   # project back down
    def forward(self, x):
        return self.w2(F.silu(self.w1(x)) * self.w3(x))  # silu == Swish

# smoke test
x = torch.randn(2, 8, 512)
h = RMSNorm(512)(x)
y = SwiGLU(512, 1376)(h)     # LLaMA sizes the hidden dim to ~ (8/3)*dim
print(y.shape)               # torch.Size([2, 8, 512])

A 13B model on public data beating the 175B GPT-3 was a shock. It proved the frontier was reachable without secret data or thousand-billion-parameter budgets, and it kicked off the open-weights era: LLaMA-2/3, Mistral, and most open models inherit exactly this block.

Why does LLaMA over-train small models past compute-optimal?
Counting lifetime inference cost, a smaller over-trained model is cheaper to serve forever.
How does RMSNorm differ from LayerNorm?
RMSNorm drops re-centring, keeping only the RMS re-scaling plus a learned gain. Cheaper, equally stable.
What does the gate in SwiGLU do?
SwiGLU passes one branch through Swish and uses it to gate (multiply) the other branch.
What made LLaMA especially influential?
LLaMA-13B beating GPT-3 175B on public data launched the open-weights ecosystem.

How this connects

  • Applies Chinchilla and pushes past it by weighing inference cost.
  • Uses RoPE (next lesson) for positions, replacing sinusoidal encodings.
  • LLaMA-2/3 add Grouped-Query Attention for faster serving.
  • Its openness makes it the base for LoRA / QLoRA fine-tuning.
