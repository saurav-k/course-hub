Glossary

The canonical vocabulary of the course. Every lesson uses these terms exactly as defined here. Skim it once now; come back whenever a word feels slippery.

How to read this Terms are grouped by theme, roughly in the order the course introduces them. Bold word = the term. Plain English first, symbols second.

Foundations

Token - the atomic chunk of text a model reads and writes. Not always a word; often a sub-word piece (like "ing" or "▁the"). Text is turned into tokens by a tokenizer.

Vocabulary - the fixed set of all possible tokens (e.g. 32,000 or 50,257 of them). Each token has an integer id.

Embedding - a learned vector (list of numbers, e.g. length 768) that stands in for a token. Similar tokens get similar vectors. The model works on vectors, never on raw text.

Logits - the raw, un-normalised scores the model outputs, one per vocabulary token, saying how likely each is to come next.

Softmax - the function that turns a list of logits into a probability distribution (all positive, sums to 1). softmax(x)_i = e^{x_i} / Σ_j e^{x_j}

Parameters (weights) - the numbers inside the model that get tuned during training. "7B parameters" means 7 billion of them.

Loss - a single number measuring how wrong the model is. Training = making loss go down. LLMs use cross-entropy loss on next-token prediction.

Gradient descent / backprop - the algorithm that nudges every parameter in the direction that lowers loss. Backpropagation computes those directions efficiently.

The Transformer

Attention - the mechanism that lets each token look at other tokens and pull in information from them, weighted by relevance.

Query, Key, Value (Q, K, V) - three vectors derived from each token. A query asks "what am I looking for?", keys advertise "what do I offer?", values carry the actual content. Match query to keys, use the match to blend values.

Self-attention - attention where queries, keys, and values all come from the same sequence (tokens attending to each other).

Scaled dot-product attention - the exact recipe: Attention(Q,K,V) = softmax(QKᵀ / √dₖ) Vscore every query against every key, divide by √(key dim) to keep numbers tame, softmax into weights, blend the values.

Multi-head attention - run attention several times in parallel with different learned projections ("heads"), then concatenate. Each head can specialise (syntax, coreference, etc.).

Causal / masked attention - a token may only attend to earlier tokens (and itself), never the future. This is what makes generation left-to-right possible.

Feed-forward network (FFN / MLP) - the per-token two-layer network applied after attention. Where a lot of the model's "knowledge" is stored.

Residual connection - add a layer's input to its output (x + f(x)). Lets gradients flow and lets layers make small edits rather than rebuild from scratch.

Layer normalisation - rescales a vector to a stable mean/variance so training does not blow up. Pre-norm (norm before the sublayer) is now standard.

Positional encoding - extra signal that tells the model the order of tokens, since raw attention is order-blind. Variants: sinusoidal, learned, RoPE, ALiBi.

Context length / window - how many tokens the model can attend to at once (e.g. 2k, 8k, 128k).

Architectures

Encoder-only - reads a whole input bidirectionally, outputs representations. Good for understanding/classification. Example: BERT.

Decoder-only - generates left-to-right with causal attention. The shape of essentially every modern LLM. Example: GPT, LLaMA.

Encoder-decoder - an encoder reads the input, a decoder writes the output attending to it. Good for translation. The original Transformer.

Training regime

Pre-training - the big, expensive phase: learn language by predicting next tokens (or masked tokens) on a huge corpus.

Fine-tuning - a smaller phase that adapts a pre-trained model to a task or behaviour.

Self-supervised learning - training with labels made from the data itself (the next token is the label). No human annotation needed.

Zero-shot / few-shot / in-context learning - solving a task from just an instruction (zero-shot) or a few examples placed in the prompt (few-shot), with no weight updates. Discovered at scale by GPT-3.

Instruction tuning - fine-tuning on (instruction, response) pairs so the model follows requests.

RLHF - Reinforcement Learning from Human Feedback: train a reward model on human preference comparisons, then optimise the LLM against it (classically with PPO). Introduced for LLMs by InstructGPT.

Reward model - a model that scores how good a response is, learned from humans ranking pairs of responses.

Alignment - making a model helpful, honest, and harmless / follow human intent.

Scaling

Scaling law - an empirical power-law: loss falls predictably as parameters, data, and compute grow. Lets you forecast a big model from small ones.

Compute (FLOPs) - floating-point operations; the currency of training cost. Rough rule: C ≈ 6 · N · DC = compute, N = parameters, D = training tokens.

Compute-optimal - the best split of a fixed compute budget between model size and data. Chinchilla found models were too big and under-trained; ~20 tokens per parameter is a better balance.

Emergence - abilities that appear only past a certain scale and are absent in smaller models.

Efficient attention & inference

KV cache - during generation, the keys and values of past tokens are stored and reused so you do not recompute them each step. Fast, but memory-hungry.

Multi-Query Attention (MQA) - all heads share one key/value head. Shrinks the KV cache a lot, small quality cost.

Grouped-Query Attention (GQA) - a middle ground: groups of heads share K/V. The modern default (LLaMA-2/3).

FlashAttention - an exact attention algorithm that avoids writing the big attention matrix to slow memory, tiling the work in fast on-chip memory. Faster and lower-memory.

PagedAttention - manages the KV cache like virtual-memory pages, cutting waste and enabling high-throughput serving (vLLM).

Speculative decoding - a small "draft" model proposes several tokens, the big model verifies them in one pass. Same output, fewer big-model steps.

Quantization - storing weights/activations in fewer bits (e.g. 4-bit) to save memory and speed up, with minimal quality loss. See QLoRA.

Adaptation & preference optimisation

PEFT - Parameter-Efficient Fine-Tuning: adapt a model by training a tiny number of new parameters, freezing the rest.

LoRA - inject small low-rank matrices into layers and train only those. Cheap, composable adapters.

DPO - Direct Preference Optimization: get RLHF-style alignment directly from preference pairs with a simple classification-style loss, no reward model or RL loop.

Mixture of Experts (MoE) - replace one FFN with many "expert" FFNs and a router that sends each token to a few. More parameters, similar compute per token.

Router / gating - the small network that decides which experts each token goes to.

Reasoning & agents

Chain-of-Thought (CoT) - prompting the model to write intermediate reasoning steps before the answer, which boosts hard-problem accuracy.

RAG - Retrieval-Augmented Generation: fetch relevant documents and put them in the prompt so the model answers from real sources.

ReAct - interleave reasoning and actions (tool calls) so a model can look things up and act step by step.

Test-time scaling - spend more compute at inference (longer/more reasoning, search) to get better answers, instead of only scaling training.
