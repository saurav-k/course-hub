Azure has seven opinions, and knowing them predicts most of the catalogue

foundation 10 min The map for the thirteen modules that follow. · Resource Manager overview

The one-minute version

  • Azure's catalogue is large, but it is opinionated in seven specific ways, and the opinions repeat from service to service.
  • The biggest is that identity is directory-first: one Entra tenant anchors everything, and a subscription belongs to it as a directory relationship rather than a billing artefact.
  • The second biggest is that one query language runs across the estate: logs, inventory, change history and analytics are all KQL.
  • A handful of service names collide with older names for the same job. Knowing which name is the go-forward one saves more time than any other reading you can do early.
  • Where Azure ships no product for a capability, it usually lives inside another service. Reading that as an absence is the most expensive mistake a newcomer makes.

The seven opinions

The opinionWhat it means in practice
Identity is directory-first One Entra tenant anchors everything; a subscription belongs to exactly one directory, and moving it between directories is a real operation rather than a billing change.
Authorisation is additive only Role assignments union. Subtraction exists solely as platform-created deny assignments, which customers cannot author.
The hierarchy is governance-first Management groups exist to inherit policy and roles; subscriptions act as quota and billing cells, issued by automation rather than used as isolation walls.
Telemetry is KQL everywhere Log Analytics, Resource Graph inventory, change history and Data Explorer analytics share one query language.
Pricing leans on capacity abstractions Request units per second in Cosmos DB, vCore or DTU in Azure SQL Database, provisioned throughput units in Foundry Models - a unit of work, not a unit of hardware.
Redundancy is a replication choice Survival is bought as an account-level letter - LRS, ZRS, GRS, GZRS - against a paired-region topology, with newer regions deliberately unpaired.
Hybrid is a projection Azure Arc pulls machines and clusters that live elsewhere into Resource Manager, so they receive policy, extensions and monitoring. It does not extend a tunnel outwards.
The reframing Six of the seven are consequences of the first two pages of this module. Azure put a single control plane in front of everything and a single directory above it, and then expressed every other platform concern as something attached to that plane - a role, a policy, a diagnostic setting, a redundancy letter, an Arc projection. The catalogue is wide; the attachment points are few.

The catalogue, as the rest of this course walks it

Reading a service name

Six name collisions are worth knowing before you meet them in a design review. Azure Managed Redis is the go-forward cache and Azure Cache for Redis is the one with a published retirement schedule. Microsoft Fabric is where warehouse and lakehouse innovation lands, and Synapse dedicated SQL pools are the previous flagship. Azure Front Door is the content delivery answer, and the separately branded Azure CDN products are a transition story. Virtual network flow logs supersede the NSG-scoped ones. For the community databases, only Flexible Server is current - MySQL Single Server is gone. And Basic Load Balancer has been retired, leaving the Standard and Gateway forms.

When there is no product, name the service it lives in

Some capabilities that are separate products elsewhere are, on Azure, a feature of something else. Reading those as absences produces designs that solve problems Azure has already solved.

The capabilityWhere it lives on Azure
A scheduled job runnerTimer-triggered Functions, Logic Apps recurrence, or Automation schedules. There is no standalone cron service.
Change data captureThe online mode of Database Migration Service, plus Data Factory and Fabric change data capture.
Application error reportingThe failures view inside Application Insights, which groups exceptions by problem identifier.
Just-in-time Kubernetes nodesNode autoprovisioning inside AKS, which is a mode of the cluster rather than a separate product.
Sharing one network across teamsA hub subscription owns the virtual network and workload subscriptions peer into it or receive roles on its subnets.
Genuine absences do exist and the honest ones are worth naming too. Azure has no managed private certificate authority: Key Vault issues certificates through integrated public authorities, and a private hierarchy runs on your own Active Directory Certificate Services. Likewise there is no first-class permission-boundary object; the nearest tools are platform-created deny assignments, the policy DenyAction effect and custom-role NotActions, each narrower than a true boundary. The difference between this paragraph and the table above it is the whole discipline: one names a service, the other names a gap.

Check yourself

Retrieval practice

Answer from memory before revealing.

A design document says "Azure cannot run a scheduled job, so we will host our own cron server." What is wrong with it?
There is no standalone scheduler service, and the capability is delivered inside three others. The second and third options invent scheduling in layers that do not have it, and the fourth turns a hybrid projection service into a prerequisite it never was.
Which pair correctly names the go-forward Azure service and the one it supersedes?
Flow logging moved from the network security group to the virtual network. The other three options each reverse a real succession, which is precisely how these names trap people: both halves of every pair are genuine Azure services, so only the direction is wrong.
What does "end of sale" mean when Azure applies it to a service?
End of sale closes the door to new customers and leaves existing ones supported, which is a different state from retirement. The first option describes retirement, the third describes preview, and the fourth invents a pricing consequence that does not follow.

Practice about 15 minutes, with paper

Practice 1foundation

You are handed a migration plan written by someone who knows another cloud well. It contains four assertions: that Azure has no way to share one network between teams, that a permission boundary should be applied to every workload subscription, that a private certificate authority should be provisioned, and that Azure CDN should front the public site.

Mark each assertion as one of three verdicts - wrong because the capability lives inside another service, correct because it is a genuine absence, or wrong because the named product is not the go-forward one - and say what you would write instead.

Hint

Three different failure shapes appear on this page: a capability delivered elsewhere, a real gap, and a superseded name. Each assertion is one of them, and one of the four is two of them at once.

Show the worked solution
  1. Sharing one network. Delivered elsewhere. There is no network-sharing construct, but a hub subscription owns the virtual network and workload subscriptions peer into it or receive roles on its subnets. Write the hub-and-spoke arrangement, not a gap.
  2. Permission boundaries. A genuine absence. No first-class boundary object exists. Write the nearest tools instead and say plainly that each is narrower: platform-created deny assignments, the policy DenyAction effect, and custom-role NotActions.
  3. Private certificate authority. Also a genuine absence. Key Vault issues certificates through integrated public authorities, so a private hierarchy remains yours to run on Active Directory Certificate Services. Write that, and note the operational cost it adds.
  4. Azure CDN. A superseded name. Front Door is where the content delivery capability is, and the separately branded CDN products are the transition story. Write Front Door, and check nothing else in the plan depends on the older product's feature list.

Sanity check. Exactly two of the four should end as genuine absences. If you marked three or more, you are reading missing product names as missing capabilities, which is the error this page exists to prevent - and if you marked none, the two real gaps have been wished away.
