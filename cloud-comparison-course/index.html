Comparing the Four Clouds

Every vendor teaches its own platform in its own words. This course refuses that: one capability at a time, all four major clouds answer side by side, each answer linked to its vendor's own documentation. It opens with the capability matrix below.

Start with the matrix: pick an area, or type the one service name you already know, and meet its four counterparts. The comparison lessons then take the rows you will actually design against and explain the differences that names hide. Every cell states which cloud it describes and links that vendor's docs; where a cloud has no equivalent it says so plainly, because an absence is a finding.

The lessons are being built module by module, and only from verified research: no comparison reaches a page until every cloud in it has been checked against its vendor's own documentation. The modules below are the plan.

  • Module 01How to read a four-way comparison - method before findings
  • Module 02Compute: placement, scaling, containers
  • Module 03Storage and data
  • Module 04Analytics
  • Module 05Networking, delivery and edge
  • Module 06Identity and access
  • Module 07Governance, tenancy and telemetry
  • Module 08Delivery, integration and intelligence
  • Module 09Resilience and migration
Your teacher. Ask for the capability you are deciding about - "object storage, four clouds" - rather than a product name, and read the row before the lesson that explains it.
