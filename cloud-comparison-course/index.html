Comparing the Four Clouds

Every vendor teaches its own platform in its own words. This course refuses that: one capability at a time, all four major clouds answer side by side, each answer linked to its vendor's own documentation. It opens with the capability matrix below.

Start with the matrix: pick an area, or type the one service name you already know, and meet its four counterparts. The comparison lessons then take the rows you will actually design against and explain the differences that names hide. Every cell states which cloud it describes and links that vendor's docs. Where a cloud has no equivalent it says so plainly, because an absence is a finding. Where it has the capability but sells no product for it, the cell says that instead and points at the service the capability lives inside, because that is a different finding and reading it as an absence would be wrong.
