Module 02 · Compute: placement, scaling, containers · Lesson 0200

Two decisions come before you rent a machine, and the four clouds package them differently

working 10 min Capability area compute-iaas, nine rows of the matrix: vm-instances, vm-instances-simplified, vm-images, bare-metal, dedicated-hosts, confidential-compute, gpu-compute, spot-capacity and batch-compute.

The one-minute version

  • Every cloud rents you a virtual machine. The first real decision is how the size is chosen: Google Cloud and OCI let you pick processors and memory independently, AWS and Azure sell fixed types from a catalogue.
  • The second is who else is on the host. All four sell the same three rungs - shared host, dedicated host, bare metal - but they sell them at very different widths.
  • Confidential compute is the one rung where the packaging genuinely differs: three clouds make it a property of the machine, and AWS makes it a walled room beside the machine.
  • Host maintenance is the divergence a design feels first. Google Cloud live-migrates a running virtual machine by default. The other three reboot or pause it.
  • One row in this area is a genuine absence on three clouds: the bundled fixed-price virtual private server. Only AWS sells that shape.

Decision one: a catalogue, or a dial

On Amazon EC2 and on Azure Virtual Machines a size is a name from a list, and the list encodes the ratio: Azure's series letters are the ratio written down - B for burstable, D for general, E for memory, F for compute, L for storage. On Compute Engine and on OCI Compute you set the two numbers yourself.

OCI adds a unit trap on top of the dial. Its unit is the OCPU, which is a physical core with simultaneous multithreading enabled, so one OCPU is about two x86 vCPUs. A price or a size read across clouds without that conversion is out by a factor of two.

The dial also moves something a catalogue keeps separate. On OCI the network bandwidth and the count of virtual network cards scale with the OCPU count rather than being chosen alongside it.

Decision two: who else is on the host

Every cloud sells the same three rungs. What differs is how wide each rung is, and that width is the finding.

Read the third row twice. OCI treats bare metal as one more shape you launch the way you launch anything else, so it carries advanced firmware options and dense local storage variants. On Azure the same rung is a separate ordering path aimed at certified SAP HANA workloads. Same rung, very different door.

The reframing Dedicated capacity is a billing and licensing decision before it is a security decision. All four rungs above bill for the whole host whether or not you fill it, so the break-even is a density calculation you do on paper before you touch a console.

Confidential compute is the rung that is packaged differently

Azure Confidential Computing, Confidential VMs on Google Cloud and OCI Confidential Computing are all selected at launch time as a property of the size or shape, so the constraint is which families support it. AWS Nitro Enclaves is the different shape: the root user of the parent instance cannot read enclave memory, and the enclave's attestation can be named in a key policy so that a key only unwraps for one measured image.

What the guest sees when the host needs maintenance

Capacity you can be asked to give back

All four sell deeply discounted reclaimable capacity, and the interruption contract is where the detail lives. EC2 Spot Instances give a two-minute interruption notice, and AWS documents that the notice is best-effort rather than guaranteed. Azure Spot Virtual Machines add a choice the others do not have: an eviction policy of Deallocate, which leaves the machine restartable, or Delete. Google Cloud Spot VMs have no maximum runtime, unlike the legacy preemptible form they replaced, which capped at twenty-four hours. OCI Preemptible Instances emit an event through the Events service two minutes before termination begins.

The trap here is not the notice period, it is what a reclaimable instance may be part of. On OCI, preemptible instances cannot be used in instance configurations or in instance pools, and are unavailable on bare metal, burstable and confidential shapes - though OKE node pools do support them. An AWS design that puts Spot inside a launch template and an Auto Scaling group has no direct OCI translation, and the next page is where that bites.

The one genuine absence in this area

Eight of the nine rows here are answered by a service on all four clouds. The ninth is vm-instances-simplified, the bundled virtual private server sold at one predictable monthly price with compute, storage and transfer included. Amazon Lightsail is that shape, and the verified inventories record a real absence on the other three, each with its own reason: on Azure a hand-sized B-series machine is the nearest thing and bills per component, on Google Cloud an E2 machine type with committed use discounts is, and on OCI the Always Free micro shapes cover the smallest cases while everything else bills per OCPU and per gigabyte.

That is an absence of a packaging, not of a capability. All four clouds will happily rent you a small machine. Only one will sell it to you as a single bundled price.

What this certification tests Only one of the four professional blueprints carves compute out as a domain of its own. AZ-305 weights Design infrastructure solutions at 30 to 35 per cent, and its own objective list names compute selection across virtual machines, containers, serverless and batch. Below it, AZ-104 weights Deploy and manage Azure compute resources at 20 to 25 per cent. The other three blueprints cut the same material a different way: SAA-C03 splits by quality (Secure 30 per cent, Resilient 26, High-Performing 24, Cost-Optimized 20), the Professional Cloud Architect guide splits by lifecycle activity, and the OCI Architect Professional blueprint splits by solution type. So compute questions on three of the four exams arrive dressed as something else, and the skill being tested is recognising them.

Check yourself

Retrieval practice

Answer from memory before revealing.

A workload needs 6 processors and 96 GB of memory, a ratio no named instance type offers. Which pair of clouds lets you set both numbers independently?
Compute Engine custom machine types and OCI flexible shapes both take the two numbers separately. AWS and Azure sell fixed named sizes, so the first option has neither of the two, and the second and fourth each pair one catalogue cloud with one dial cloud.
Which statement about confidential compute matches how the four clouds actually package it?
Nitro Enclaves is a hardened room reachable only over a local socket, while Azure, Google Cloud and OCI make memory encryption a property of the size or shape. Option two reverses that. Option three is wrong because three of the four select it at launch rather than buying it. Option four is the failure this whole course guards against: OCI and AWS both ship the capability, so calling it absent would be a false negative.
Routine host maintenance is scheduled. On which cloud does a running virtual machine keep running by default?
Compute Engine live migration copies a running machine to another host and the guest sees a brief slowdown rather than a stop. The other three options each describe a real behaviour and attach it to the wrong outcome: reboot migration, a pause and a reboot all stop the guest, which is precisely why the default matters.

Practice about 15 minutes, with paper

Practice 1working

A batch renderer runs on AWS today. Each worker is an EC2 Spot instance sized at 8 vCPUs and 32 GB, launched from a launch template inside an Auto Scaling group, and the pipeline needs about 40 Gbps of aggregate read bandwidth from shared storage.

Port the worker to OCI on paper. Give the OCPU count you would ask for, say what happens to the bandwidth requirement, and name the one structural piece of the AWS design that has no OCI translation.

Hint

Convert the processor unit first, then check the bandwidth against OCI's shape reference, then ask what a preemptible instance on OCI is allowed to be a member of.

Show the worked solution
  1. Convert the processor unit. One OCPU is a physical core with multithreading, which is about 2 x86 vCPUs. So 8 vCPUs is about 4 OCPUs, and asking for 8 OCPUs would buy roughly twice the machine and roughly twice the price.
  2. Check the bandwidth against the shape. OCI bandwidth rises at about 1 Gbps per OCPU. A 4-OCPU worker therefore gets about 4 Gbps, so 40 Gbps aggregate needs about ten workers running at once rather than being a property you can buy on one of them.
  3. Find the piece with no translation. Preemptible instances on OCI cannot be used in instance configurations, and an instance pool is built from an instance configuration. The AWS shape of "Spot inside a launch template inside an Auto Scaling group" has no direct OCI equivalent, so the fleet is either not preemptible or not an instance pool.
  4. State the resulting design. Either run on-demand instances in an instance pool and lose the discount, or drive preemptible instances from your own launcher and lose the pool's replacement behaviour - or move the workload onto OKE, whose node pools do support preemptible capacity.

Sanity check. The OCPU answer should be smaller than the vCPU number, never larger, and the bandwidth answer should force a fleet rather than a bigger box. If your port ended up with 8 OCPUs and one very large machine, the unit conversion went the wrong way.

Your teacher. If the sizing model is still fuzzy, ask an agent to price one workload two ways on the same cloud - once from the named catalogue and once from the dial - and to show which knob moved the bill. If the tenancy ladder is fuzzy, ask instead for the density calculation that makes a dedicated host cheaper than shared capacity.

Primary source to go deeper

Read one vendor's own shape reference end to end rather than four summaries of it. OCI Compute Shapes is the shortest of the four and the one that states the processor unit, the bandwidth rule and the bare-metal families on a single page.
