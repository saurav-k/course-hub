Formula sheet

reference grows with the course Every expression the course uses, with each symbol named in plain English. Print it and cover the right-hand column.

This sheet is a skeleton and it grows with the course. A formula is added on the day the page that derives it lands. Nothing appears here that has not been taught, because a formula sheet is a memory aid and not a syllabus.

How to use this

  • Cover the gloss and say what each symbol means before uncovering it. A formula you cannot read aloud in plain English is one you have recognised rather than learned.
  • Every entry links the page that derives it. If an entry surprises you, the page is where the surprise is resolved.
  • Notation is the companion sheet: this one holds expressions, that one holds symbols.
