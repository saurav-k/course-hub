reference grows with the course The same pages as the course map, grouped by subject rather than by the order they are taught in. For revising one topic rather than reading the spine.

This sheet is a skeleton and it grows with the course. An entry appears here when its page lands. The course is a single route; this index is a second way to find a page, not a second order to read them in.

Why this index exists

The course is read in one order, because mathematics has real prerequisites and a page that uses an eigenvector before eigenvectors are defined is not a worse experience but an unreadable one. That order is the course map.

Revising is a different activity from learning. When you already know the material and want the page on norms, you do not want to know which module it sits in. This index is for that.
