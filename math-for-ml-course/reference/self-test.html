reference grows with the course Questions drawn from across the whole course, for checking what stuck rather than what felt familiar.

This sheet is a skeleton and it grows with the course. Questions are added as modules land, and each one is drawn from a page rather than written fresh, so nothing here tests something the course did not teach.

How to use this

  • Take it cold, without re-reading first. A test you revise for measures your revision.
  • Every question links the page it came from. A wrong answer is a page to re-read, not a score.
  • The practice problems on each page are the harder test. This one checks recall; those check whether you can use it.
