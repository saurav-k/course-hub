reference print-friendly A reader who meets x as a vector on one page and a scalar on the next has been taught nothing. This page is the contract every module keeps.

How to use this

  • Keep it open in a second tab while you read. It is meant to be glanced at, not learned.
  • Cover the right-hand column and say what each symbol means before uncovering it. Retrieval beats re-reading.
  • If a page ever uses a symbol this sheet does not carry, that is a defect in the page. Every symbol is named in words where it is introduced, and it appears here.

The one that matters most The data matrix is X, with n rows and d columns: one row per sample, one column per feature. This is the single most common source of transposed confusion in a maths-for-ML course, and it is settled here rather than per page. It is the machine learning convention and it is what you will meet in a paper. A page that genuinely needs the transpose writes XT and says why in words.
ŷ = X w Read as: X is the data matrix with one row per sample. w is a column vector of one weight per feature. Their product is a column vector holding one prediction per sample. Because vectors are columns, a single prediction for one sample x is written wTx, and never xw.

Conventions this course holds

  • log means natural log. Any other base is written out, as log2. Where the base changes an answer rather than a constant, the page says so.
  • Vectors are columns. Nothing switches to row vectors to make an expression look tidier.
  • Sample variance divides by n - 1, and the page that first uses it explains why rather than asserting it.
  • A hat means estimated, a bar means averaged. Both are things you computed; the bare Greek letter is the thing you cannot see.
Your teacher. If a symbol here is one you can read but not hear, ask an agent to read a formula containing it aloud in plain English, then to write a second formula using the same symbol differently. Recognising a symbol and knowing it are different, and the gap only shows up when the symbol moves.
