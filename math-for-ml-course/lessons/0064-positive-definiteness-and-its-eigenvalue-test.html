The matrix version of a positive number

working 13 min Module 06 owns what this does to optimisation. Module 08 owns covariance as a statistical object.

The one-minute version

  • xTAx > 0 for every non-zero x makes a matrix positive definite. With ≥ it is semidefinite.
  • The usable test is the spectrum: positive definite exactly when every eigenvalue is positive.
  • Every Gram matrix XTX is semidefinite in one line, so every covariance and kernel matrix is too.
  • An eigenvalue of exactly zero means a direction with no spread, which is an exact linear dependence in the features.
  • det > 0 does not mean positive definite. Two negative eigenvalues multiply to a positive number.

1. The definition, and why it is unusable as written

xTAx > 0 for every x ≠ 0 Read as: whatever non-zero vector you feed in, the quadratic form of lesson 63 comes back strictly positive. Replacing the strict inequality with ≥ gives positive semidefinite, which allows the value zero in some direction.

Two names first. Parts of the mathematics literature call the semidefinite case simply "positive". This course always writes definite or semidefinite and never bare "positive" of a matrix, because the difference is exactly what sections 4 and 5 are about.

As written the definition quantifies over infinitely many vectors, so it cannot be checked directly. Sampling a million of them can only ever fail to find a counterexample, which is not the same as there being none. The eigenvalue test replaces "check every vector" with "check n numbers".

2. The test, and its proof

The eigenvalue test A real symmetric matrix is positive definite if and only if every one of its eigenvalues is strictly positive. The same statement holds with "semidefinite" and "non-negative".

If all eigenvalues are positive, the matrix is positive definite. By lesson 62, write A = QΛQT. Take any x ≠ 0 and set y = QTx. Because Q is orthogonal it is invertible, so y ≠ 0 as well. By lesson 63's principal-axes result, xTAx = ∑λiyi2. At least one yi is non-zero, its square is strictly positive, every eigenvalue is strictly positive, and no term is negative. So the sum is strictly positive.

If the matrix is positive definite, all eigenvalues are positive. Let lambda be an eigenvalue with unit eigenvector q, which lesson 62 guarantees is real. Then

0 < qTAq = qT(λq) = λ(qTq) = λ Read as: the first inequality is the definition applied to the particular vector q. The next step uses that q is an eigenvector, and the last uses that it has unit length, so qTq is 1. What is left is that lambda itself is positive.
The step that does the real work In the forward direction, that y ≠ 0 whenever x ≠ 0. Without it the sum could be empty of positive terms and the argument would collapse. In the reverse direction, the real trick is noticing that a statement about every vector may be applied to an eigenvector in particular. That is the whole proof.

3. Every Gram matrix, free

xT(XTX)x = (Xx)T(Xx) = ‖Xx‖2 ≥ 0 Read as: regroup the product so that X acts on x first. What is left is a vector dotted with itself, which is a squared length. A squared length is never negative, whatever X and x are.

Three symbols and no machinery, and it settles a whole family at once. Every covariance matrix and every kernel matrix is of this form, so all of them are positive semidefinite before anyone computes anything. Whether they are definite rather than merely semidefinite is the subject of the next section.

4. The three cases, seen

5. What a zero eigenvalue is telling you

A zero eigenvalue means some direction has no spread whatsoever: every data point takes the same value along it. That is an exact linear dependence among the features, and the cheapest way to create one is to duplicate a column.

The measured smallest eigenvalue with the duplicate present is -1.735e-18, which is zero plus floating-point dust, and the condition number is infinite. After adding 0.0005I the smallest becomes exactly 0.000500 and the condition number drops to 622. Module 06 owns why anyone would want that; this page owns only the spectral fact that the shift is uniform.

6. The determinant trap

7. Worked in full

  1. Take two matrices differing in one entry. A1 = [[9, 6], [6, 5]] and A2 = [[9, 6], [6, 3]].
  2. Invariants. A1: trace 14, determinant 45 - 36 = 9. A2: trace 12, determinant 27 - 36 = -9.
  3. Settle the second immediately. A negative determinant in two dimensions forces one eigenvalue of each sign, so A2 is indefinite and no further work is needed.
  4. Eigenvalues of the first. λ2 - 14λ + 9 = 0, discriminant 196 - 36 = 160, roots 13.3246 and 0.6754. Both positive, so A1 is positive definite.
  5. A second route, by completing the square. 9x12 + 12x1x2 + 5x22 = (3x1 + 2x2)2 + x22, a sum of two squares, zero only at the origin. Positive definite with no eigenvalue computed at all.
  6. The same attempt on the second. 9x12 + 12x1x2 + 3x22 = (3x1 + 2x2)2 - x22. The minus sign hands you a counterexample directly: set 3x1 + 2x2 = 0 with x2 = 1, giving x = (-2/3, 1).
  7. Sanity check. Evaluate that vector on the original A2: 9(4/9) + 12(-2/3) + 3 = 4 - 8 + 3 = -1, negative as predicted. The same vector on A1 gives 4 - 8 + 5 = 1, positive, as a definite matrix must.
  8. What changes if. Set the lower-right entry to exactly 4, giving [[9, 6], [6, 4]] with determinant zero. The square now completes as (3x1 + 2x2)2 with nothing left over, which is zero along the whole line 3x1 + 2x2 = 0. Semidefinite, not definite, and its eigenvalues are 13 and 0.

8. Why sampling is not a proof

code/0064-positive-definiteness.py · runnable Python, NumPy and Pandas only
# 200,000 random unit vectors against the rank-deficient covariance
assert sampled_dup > 1e-6          # sampling still sees only positive values
assert abs(smallest_dup) < 1e-12   # but the smallest eigenvalue is zero

# build the null direction on purpose and the form vanishes on it
null = np.zeros(25); null[0], null[-1] = 1.0, -1.0
assert abs(null @ cov_dup @ null) < 1e-12

Two hundred thousand random directions all came back positive, with the smallest at 3.9e-04, while the true answer was zero the whole time. A random vector in twenty-five dimensions essentially never lands on one particular line, so sampling cannot find the direction that matters. One eigenvalue found it immediately, and constructing the null direction by hand confirms it.

Check yourself

Retrieval practice

Answer from memory before revealing.

A symmetric two-by-two matrix has determinant plus 4. Is it positive definite?
The matrix with minus one twice on its diagonal has determinant plus one and is negative definite, so a positive determinant is not sufficient. The first option is the trap. The second overcorrects, since a negative determinant does settle it in two dimensions. The fourth adds nothing, because a positive determinant already gives invertibility.
A covariance matrix has an eigenvalue of exactly zero. What does that say about the data?
Zero variance along an eigendirection means every point takes the same value there, which is an exact linear dependence. The second confuses variance with mean, and centring sets every mean to zero without creating a zero eigenvalue. The third names one cause of the symptom rather than its meaning, since duplicating a column does it at any size. The fourth would put a zero off the diagonal, not a zero eigenvalue.

Practice about 15 minutes, with paper

Practice 1working

Decide whether the matrix below is positive definite, twice: once from its eigenvalues and once by completing the square.

A = [[4, 2], [2, 3]] Read as: a symmetric two-by-two matrix with diagonal entries 4 and 3 and repeated off-diagonal entry 2.
Hint

For the second route, pull the whole cross term inside a single squared bracket and see what is left over. If what remains is a positive multiple of a square, you are done.

Show the worked solution
  1. Invariants. trace = 7, det = 12 - 4 = 8.
  2. Eigenvalues. λ2 - 7λ + 8 = 0, discriminant 49 - 32 = 17, roots 5.5616 and 1.4384. Both positive.
  3. Write the form. 4x12 + 4x1x2 + 3x22.
  4. Complete the square. (2x1 + x2)2 + 2x22, a sum of squares that vanishes only when x2 = 0 and 2x1 = 0, that is only at the origin.

Sanity check. 5.5616 + 1.4384 = 7.0000 and 5.5616 × 1.4384 = 8.0000, so both invariants are reproduced. The two routes must agree that it is definite, and they do. If your completed square had left a negative term, the eigenvalues would have had to disagree, which is the check working.

Your teacher. If section 8 felt like a technicality, ask an agent to sample random unit vectors against a matrix you know is semidefinite and count how many land within a degree of the null direction. The answer in twenty-five dimensions is essentially none, and that number is the reason the eigenvalue test exists.
