Module 03 · Vectors, matrices, and linear maps · Lesson 02

A vector is a list and an arrow, and there are only two operations

foundation 8 min Add two vectors, or scale one. Everything else in this module is those two moves in a longer sentence.

The one-minute version

  • A vector is both a list of numbers and a displacement from the origin, and the two readings never disagree.
  • There are exactly two operations: add two vectors, and multiply one by a number.
  • Doing both at once gives the linear combination, which is the single construction the rest of this module is made of.
  • The 2-D pictures are drawn so that the 300-D case can be reasoned about. Nothing in the algebra changes with the dimension.

The same object, read two ways

Write down three numbers, say 2.83, 4 and 2. Read as a list, they are the area in thousands of square feet, the bedroom count and the bathroom count of one house. Read as a position, they are a single point in a three-dimensional space whose axes are those three measurements.

Neither reading is the true one. The list is what a computer stores and the point is what lets you ask whether two houses are similar, and the whole value of linear algebra to machine learning comes from having both at once. A table of numbers has no notion of nearness. A space of points does.

The pictures on this page are drawn in two dimensions because a page is flat. That is the only reason. A house described by five measurements is a point in five-dimensional space, an embedded word is a point in several hundred, and every rule below is written so that it never mentions the dimension.

Operation one: addition

Two vectors of the same length add entry by entry. Geometrically, that is the head-to-tail construction: place the tail of the second arrow at the head of the first, and the sum runs from the original origin to where you end up.

The two descriptions are the same statement. Walking two units east and then three units north leaves you where walking five units along the diagonal would, and the entries are what record how far each walk went in each direction.

Operation two: scaling

Multiplying a vector by a number multiplies every entry by it. Geometrically the arrow keeps its direction and changes its length by the size of that number, and reverses if the number is negative.

The sign is where people slip. A negative scalar does two things at once, and only one of them is about length. Scaling by −0.5 makes the arrow half as long and points it the opposite way.

Both at once: the linear combination

Take several vectors, scale each by its own number, and add the results. That is a linear combination, and it deserves its own name because almost everything in this module turns out to be one.

c1a1 + c2a2 + … + ckak Read as: each ai is a vector of the same length, each ci is a single number called a coefficient or a weight, and the whole expression is one vector of that same length. The coefficients may be negative and they may be fractions.

A linear regression's prediction is a linear combination of the feature values. A neural network layer's output, before it is bent, is a linear combination of its inputs. The average of a dataset is a linear combination with every coefficient equal to one over the number of samples. A gradient descent step is a linear combination of exactly two vectors, the current weights and the gradient.

The reframing There is no third operation waiting later in the subject. Matrix multiplication, span, rank, projection and least squares are all linear combinations organised in different ways.

A worked example, in eight steps

Three houses from housing.csv, each as a vector of area in thousands of square feet, bedrooms and bathrooms.

  1. Name the objects. a, b and c are the first three rows: a = (2.830, 4, 2), b = (2.217, 4, 2), c = (2.368, 3, 2).
  2. Add two of them. a + b = (5.047, 8, 4), entry by entry. Note that this is not a house. Adding two houses is arithmetic, not real estate, and the vector space does not care.
  3. Scale one. 2a = (5.660, 8, 4), which doubles every measurement.
  4. Subtract. a − b = (0.613, 0, 0), which is a + (−1)b. The two houses differ only in area, by 613 square feet.
  5. Build a genuine combination. 0.5a + 0.3b + 0.2c = (2.5536, 3.8, 2). Because the coefficients are non-negative and sum to one, this one is a plausible house: a weighted average of the three.
  6. Check it by definition. Computing the same combination with a plain loop over the entries, with no vectorised arithmetic at all, gives the identical three numbers.
  7. Read a gradient step as a combination. With weights w, gradient g and learning rate 0.1, the update w − 0.1g is the linear combination with coefficients 1 and −0.1. Nothing else is happening.
  8. Say what would change. Nothing above mentioned the number of entries. With all five measurements instead of three, every step reads the same and only the printed tuples get longer.
m03-l02-linear-combination.py · runnable Python, numpy and pandas only
import numpy as np
import pandas as pd

frame = pd.read_csv("../datasets/housing.csv")
houses = frame[["area_k_sqft", "bedrooms", "bathrooms"]].to_numpy(float)
a, b, c = houses[0], houses[1], houses[2]

print(a + b)                 # entry by entry
print(2 * a)                 # every entry doubled
print(0.5 * a + 0.3 * b + 0.2 * c)

w = np.array([0.06, -0.07, 0.32])
g = np.array([0.10, -0.54, 0.36])
print(w - 0.1 * g)           # one scale, one subtraction

The full program also recomputes the combination with an explicit loop and asserts the two agree, which is the check that the vectorised form really is the definition and not something else that usually matches it.

Check yourself

Retrieval practice

Answer from memory before revealing.

Which one of these is not a linear combination of the vectors a and b?
A linear combination scales each vector and adds the results, and there is no multiplication of two vectors anywhere in it. The first and fourth use negative coefficients, which are allowed. The third is the zero vector, which is the combination with both coefficients zero and is perfectly legal.
Multiplying a vector by −0.5 does what to the arrow?
The length scales by the size of the number and the sign decides the direction, so the arrow is half as long and points the opposite way. The first ignores the sign entirely. The second inverts the length rule. The third confuses scaling with rotation, which needs a matrix and is four lessons away.
Practice

A model's weight vector is w = (0.8, −0.4, 0.2) and the gradient at the current step is g = (0.2, 0.6, −0.1), with learning rate 0.5.

  1. Write the update w − ηg as a linear combination, naming both coefficients.
  2. Compute the updated weights.
  3. Did the update move the weights further from the origin or closer to it?
Hint

For part 1 there is nothing to compute: read the expression and say what multiplies each of the two vectors. For part 3 you need the length of a vector, which is the square root of the sum of the squares of its entries.

Solution
  1. Coefficient 1 on w and −0.5 on g. The learning rate is the second coefficient with a minus sign on it, and nothing else in the step is doing anything.
  2. 0.5g = (0.1, 0.3, −0.05), so w − 0.5g = (0.8 − 0.1, −0.4 − 0.3, 0.2 + 0.05) = (0.7, −0.7, 0.25).
  3. Before: the sum of squares is 0.64 + 0.16 + 0.04 = 0.84, so the length is 0.9165. After: 0.49 + 0.49 + 0.0625 = 1.0425, so the length is 1.0210. The weights moved further from the origin.

Sanity check: the third entry of your answer to part 2 should be larger than the third entry of w, because that entry of the gradient was negative and subtracting a negative adds.

Your teacher. If the head-to-tail picture and the entry-by-entry sum still feel like two separate facts, ask an agent to plot the two arrows and their sum for three or four pairs you choose, printing the entries beside each arrow. Seeing the same numbers appear in both places a few times is what joins them.
