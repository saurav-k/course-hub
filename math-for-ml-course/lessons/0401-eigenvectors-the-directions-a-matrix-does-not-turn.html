Some directions a matrix only stretches

working 12 min The first page of the module. Everything after it is a consequence of this one idea.

The one-minute version

  • A matrix normally does two things at once to a vector: it turns it and stretches it.
  • A few special directions come out pointing exactly where they went in, only longer or shorter.
  • Those directions are the eigenvectors, and the amount each is stretched by is its eigenvalue.
  • An eigenvector is a direction, not a particular arrow: any non-zero multiple of it is the same eigenvector.
  • Some matrices have no real eigenvector at all, which is the honest limit that the rest of this module repairs.

1. What a matrix normally does

Take the matrix A = [[4, 1], [2, 3]] and feed it the vector (0, 1), which points straight up. The result is (1, 3). It is longer, which is unsurprising, but it is also no longer pointing straight up: it has swung round to about 72 degrees. The matrix turned it.

That is the ordinary case, and it is worth sitting with for a moment. Almost every vector you hand to a matrix comes back pointing somewhere else. If that were true of every vector without exception there would be very little to say about the matrix beyond its four numbers.

2. The definition

A non-zero vector v is an eigenvector of a square matrix A when multiplying by A only scales it. The scaling factor is a single number called the eigenvalue, written with the Greek letter lambda.

A v = λ v,  v ≠ 0 Read as: A is the square matrix, v is the direction that survives, and λ is the single number saying how much v is stretched. The condition that v is not the zero vector is part of the definition and is doing real work, as the next paragraph explains.

The requirement that v is not zero looks like a technicality and is not. The zero vector satisfies the equation for absolutely every number lambda, because both sides are zero whatever lambda is. Admit it and every number becomes an eigenvalue of every matrix, and the definition stops saying anything at all. Ruling it out is what leaves the definition with content.

The eigenvalue carries a physical meaning worth reading off directly. A lambda greater than one stretches, a lambda between zero and one shrinks, a negative lambda flips the vector end over end while scaling it, and a lambda of exactly zero collapses that whole direction onto the origin. That last case is the interesting one: a matrix with a zero eigenvalue destroys information, and no inverse can bring it back.

3. An eigenvector is a direction, not an arrow

If v is an eigenvector then so is every non-zero multiple of it, with the same eigenvalue. The check is one line: if A v = λ v and c is any non-zero number, then A(cv) = c(Av) = c(λv) = λ(cv). Doubling the arrow doubles both sides and changes nothing.

This matters more than it looks. When a textbook prints an eigenvector as (1, 1) and a library hands you (-0.7071, -0.7071), they have not disagreed. They have chosen a different length and a different sign for the same direction. Any code that tests the sign of an eigenvector component is testing an arbitrary choice, and it will pass on your machine and fail on someone else's.

4. Finding them, on one small matrix

For A = [[4, 1], [2, 3]] we want every v and lambda with Av = λv. Rearranged, (A - λI)v = 0 must have a non-zero solution, which happens exactly when A - λI squashes some direction to zero.

  1. Write the shifted matrix. A - λI = [[4 - λ, 1], [2, 3 - λ]].
  2. Ask when it collapses a direction. That is when its determinant is zero: (4 - λ)(3 - λ) - 2 = 0.
  3. Expand. 12 - 7λ + λ2 - 2, so λ2 - 7λ + 10 = 0.
  4. Solve. The roots are 5 and 2.
  5. Back-substitute the first. A - 5I = [[-1, 1], [2, -2]]. Both rows say the same thing, v1 = v2, so v = (1, 1).
  6. Back-substitute the second. A - 2I = [[2, 1], [2, 1]], so 2v1 + v2 = 0 and v = (1, -2).
  7. Check both. A(1, 1) = (5, 5), which is 5 × (1, 1). A(1, -2) = (2, -4), which is 2 × (1, -2). Both exact.
  8. Check again, for free. The eigenvalues should add to the trace and multiply to the determinant: 5 + 2 = 7 = 4 + 3 and 5 × 2 = 10 = 12 - 2. Both hold. The next page explains why this always works.
What changes if. Change the lower-left entry from 2 to -2. Step 3 becomes λ2 - 7λ + 14 = 0, whose discriminant is 49 - 56 = -7. There is no real root, so no real eigenvector. The method did not fail. The honest answer is that this matrix leaves no real direction unturned.

5. The matrix that has none

The clearest example of that is a quarter-turn. Rotating the plane by ninety degrees sends every single vector to a new direction, by construction, so there is no direction it leaves alone and there is nothing for an eigenvector to be.

6. Where this shows up

Three places, named now and earned later. A link matrix over web pages has a dominant eigenvector whose entries rank the pages, which is the original idea behind PageRank. The eigenvectors of a covariance matrix are the directions the data spreads along, which is the whole of principal component analysis and arrives at the end of this module. And the number of zero eigenvalues of a graph Laplacian counts the connected pieces of the graph.

7. The same thing at a scale you cannot do by hand

code/0401-eigenvectors.py · runnable Python, NumPy and Pandas only
def dominant_by_power_iteration(matrix, steps=500):
    # The definition, run by hand: multiply, normalise, repeat.
    vector = np.ones(matrix.shape[0])
    vector /= np.linalg.norm(vector)
    for _ in range(steps):
        vector = matrix @ vector
        vector /= np.linalg.norm(vector)
    return float(vector @ matrix @ vector), vector

power_value, power_vector = dominant_by_power_iteration(cov)
eigenvalues, eigenvectors = np.linalg.eigh(cov)
top = int(np.argmax(eigenvalues))

# The eigenvalues must match exactly. The eigenvectors match only up to sign,
# because if A v = lambda v then A (-v) = lambda (-v) just as truly.
assert np.isclose(power_value, float(eigenvalues[top]))
assert np.isclose(abs(power_vector @ eigenvectors[:, top]), 1.0)

Run against the 24-channel dataset, both routes return the dominant eigenvalue 0.302209686774, agreeing to twelve digits. The two routes returned opposite signs for the eigenvector, which is section 3 happening in front of you rather than being claimed. The program asserts on the magnitude of the dot product for exactly that reason.

Retrieval practice

Answer from memory before revealing.

A textbook prints an eigenvector as (1, 1) and a library returns (-0.7071, -0.7071) for the same matrix. Which one is correct?
Any non-zero multiple of an eigenvector is the same eigenvector with the same eigenvalue, and these two differ by the factor -0.7071. The first two options each state something true about how one of the vectors was written, but a true fact about a formatting choice is not what makes it correct. The fourth invents a rule that does not exist.
A two-by-two matrix has trace 7 and determinant 12. What are its eigenvalues?
The eigenvalues add to the trace and multiply to the determinant, so they solve lambda squared minus 7 lambda plus 12, giving 3 and 4. The second option confuses the two invariants with the eigenvalues themselves. The third would need the two to be equal, which needs a zero discriminant, and here it is 49 minus 48. The fourth is false for a two-by-two, where those two numbers pin the answer down.

Practice problem

For A = [[2, 1], [1, 2]], find both eigenvalues and one eigenvector for each, then check your answer against the trace and the determinant.

Hint

You need A - λI to collapse a direction, so start from its determinant. Every number in this problem stays whole.

Show the worked solution
  1. Shift and take the determinant. (2 - λ)2 - 1 = λ2 - 4λ + 3.
  2. Solve. The roots are 3 and 1.
  3. First eigenvector. A - 3I = [[-1, 1], [1, -1]] says v1 = v2, so v = (1, 1).
  4. Second eigenvector. A - I = [[1, 1], [1, 1]] says v1 + v2 = 0, so v = (1, -1).

Sanity check. 3 + 1 = 4, which is the trace, and 3 × 1 = 3, which is the determinant. If your two eigenvalues fail to reproduce both, the error is in the quadratic rather than in the eigenvectors. Notice also that (1, 1) and (1, -1) are perpendicular, which is not luck: this matrix is symmetric, and lesson 03 explains why that guarantees it.

Your teacher. If step 5 of the worked example did not land, ask an agent to show you (A - 5I)v = 0 written out as two ordinary simultaneous equations, and to point out why the two equations say the same thing. That redundancy is the whole reason a non-zero solution exists.
