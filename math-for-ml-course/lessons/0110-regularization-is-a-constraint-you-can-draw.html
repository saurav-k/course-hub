Regularization is a constraint you can draw

working 13 min The two mechanisms are Goodfellow et al. chapter 7, equations 7.13 and 7.23. · Deep Learning, ch. 7

The one-minute version

  • Adding a norm penalty to the loss is the same problem as forbidding the weights from leaving a ball. Lesson 109's Lagrangian is what makes that a statement rather than an analogy.
  • The L2 ball is round and the L1 ball has corners on the axes. A growing contour meets a corner before a flat face, and a corner is a coefficient that is exactly zero.
  • The algebra agrees: L2 multiplies each eigendirection by λ/(λ+α), which is never zero. L1 soft-thresholds, which is exactly zero below a cutoff.
  • L1 buys sparsity and pays in stability. Among correlated predictors the choice moves with the sample.

1. Penalty and constraint are the same problem

Constrain the weights: minimise J(θ) subject to Ω(θ) ≤ k, for some norm Ω and radius k. Build the Lagrangian exactly as the previous page did:

  1. Write it. L(θ, α) = J(θ) + α(Ω(θ) − k), with α ≥ 0.
  2. Fix α at its optimal value α⋆ and look at the problem as a function of θ alone.
  3. Expand. θ⋆ = argmin J(θ) + α⋆Ω(θ) − α⋆k.
  4. Drop the constant. The term α⋆k does not depend on θ, so removing it changes no minimiser.
  5. Read the result. θ⋆ = argmin J(θ) + α⋆Ω(θ). That is exactly the penalised problem you have been writing since Lesson 100.
The caveat is part of the result. You do not know which radius k your coefficient α corresponds to, because the relationship depends on the shape of J. You control it only in direction: larger α means a smaller region. So the ball in the next figure is real, and you cannot put a number on its radius from your hyperparameter alone.

3. The algebra under the picture

The picture is persuasive and it is not proof. Here are both mechanisms in closed form, under a quadratic approximation to the loss around its unregularised minimiser w⋆.

L2 rescales, and never zeroes

  1. Stationarity of the regularised objective. αw-tilde + H(w-tilde − w⋆) = 0.
  2. Rearrange. (H + αI)w-tilde = Hw⋆, so w-tilde = (H + αI)-1Hw⋆.
  3. Diagonalise. H is real symmetric, so H = QΛQT with Q orthonormal.
  4. Substitute and cancel. Using αI = Q(αI)QT, the expression becomes Q(Λ + αI)-1ΛQTw⋆.
  5. Read one direction. The component along eigenvector i is multiplied by λi/(λi + α).
  6. Note the crucial clause. For any finite α and any λi > 0, that factor is strictly positive. It shrinks and it never reaches zero.

Read the factor: where λi is much larger than α, the data pins that direction down and regularization barely touches it. Where λi is much smaller, the component is nearly erased. Regularization spends its budget on the directions the data does not constrain.

L1 soft-thresholds, and zeroes exactly

Assume additionally that H is diagonal, which holds once the features are decorrelated. The objective then separates across coordinates and each one can be minimised alone.

  1. For wi > 0 the derivative is Hii(wi − w⋆i) + α, zero at wi = w⋆i − α/Hii, which is only a valid positive answer when w⋆i exceeds α/Hii.
  2. For wi < 0 the mirror argument gives wi = w⋆i + α/Hii, valid only when w⋆i is below −α/Hii.
  3. In between, the absolute value has no derivative at zero. Its subgradient there is the whole interval from −α to α, and stationarity can be satisfied precisely when the size of w⋆i is at most α/Hii. That interval is the step that does the real work: a kink can hold a solution at zero in a way a smooth curve cannot.
  4. Collect all three cases. wi = sign(w⋆i) × max( |w⋆i| − α/Hii, 0 ).

That is the soft-thresholding operator, and it appears independently as S(z, γ) = sign(z)(|z| − γ)+ in the glmnet paper, where it is the inner loop of the algorithm that actually fits a lasso.

4. Why L1 and not L0

If you want exactly-zero coefficients, why not penalise the count of non-zeros directly? Because that problem is combinatorial and intractable. Tibshirani puts the answer in one sentence: among penalties of the form (∑|βj|q)1/q, the lasso "uses the smallest value of q (i.e. closest to subset selection) that yields a convex problem".

Lesson 101 is why that sentence is the whole answer. Below q = 1 the constraint region stops being convex, and every guarantee this module has built goes with it.

Read rows two and three first. They are the entire point: L1 sends small coefficients to exactly zero, L2 to small but non-zero values. Sparsity is a fact about the arithmetic, not a tendency.

Sanity check. The L2 column contains no zeros and cannot, because the factor λ/(λ+α) is strictly positive. If a zero ever appeared there, the derivation in section 3 would be wrong.

What changes with the curvature? Compare row one against a hypothetical Hii = 10 with the same w⋆ = 3.0: the threshold drops to 0.05 and the L1 answer becomes 2.95. Where the data pins a direction down, both penalties barely move it, which is the same statement the shrinkage factor makes.

What it means. Row four is a coincidence worth noticing: both methods return −1.000. It is arithmetic rather than a rule, and the practice problem asks you to say why.

6. The costs

Measured on a synthetic pair of predictors correlated at 0.919 with equal true coefficients, at a penalty in the transition zone, across 80 bootstrap resamples: 32 kept only the first, 6 kept only the second, 42 kept both. The two are interchangeable by construction, and which one survives is decided by the resample. A sparse answer is not automatically a stable one, so report selection frequency rather than a single fitted set.

On the credit data the lasso behaves better than its reputation: emi_to_income correlates with utilisation_ratio at 0.921 but does not enter the target, and the path drops it at the lowest penalty while keeping the real predictor to a hundredfold higher one. Correlation alone does not fool it. Two genuinely predictive twins do.

This page's equivalence is stated for gradient descent and must not be carried to Adam. Once the optimizer is adaptive, an L2 term in the loss is no longer weight decay, because parameters with large gradient history get regularised less than they would be. That is what AdamW fixes, and it is why the modern recipe is AdamW rather than Adam with weight decay in the loss. def soft_threshold(value, amount):
    """S(z, g) = sign(z) * max(|z| - g, 0). The page derives this."""
    return np.sign(value) * np.maximum(np.abs(value) - amount, 0.0)

The program fits the whole lasso path twice, once by coordinate descent using that operator and once by proximal gradient descent, and checks they agree. It then turns section 3's claim into a test: count the coefficients that are exactly zero at each penalty under each method. The L2 count is zero at every penalty from 102 to 106, while its smallest coefficient shrinks from 0.84 to 0.000086 without ever arriving. If that column ever showed a zero, this page would be wrong.

Why does L1 produce exact zeros where L2 does not?
An expanding contour meets a corner before a smooth arc, and the corners sit where a coefficient is zero. The first is false at any matched strength, since the two differ in shape rather than magnitude. The second is the near-miss worth naming: non-differentiability at zero is real and related, but it is a consequence of the corner rather than the cause of the sparsity, and no rounding happens anywhere. The fourth is false for both.
L2 rescales the coefficient along a Hessian eigendirection by
Where the data pins a direction down, λ is much larger than α and the factor is near 1. The second has it inverted, which would regularise the well-determined directions hardest. The third is what "shrinkage" sounds like and is wrong because L2 is anisotropic, which is the whole point of the eigenbasis. The fourth has the shape of L1's soft threshold, so choosing it means the two mechanisms this page separates have run together.

Practice about 20 minutes, with paper

Practice 1working

Four unregularised coefficients, with the Hessian's diagonal entries beside them:

w* = ( 3.0, 0.4, −0.2, −2.0 )     H = ( 1.0, 1.0, 1.0, 0.5 ) Read as: what each coefficient would have been with no penalty, and how sharply the loss curves along each of those directions. A large H means the data has a strong opinion about that coefficient.

At α = 0.5, find the L1 and L2 results for each. Then find the smallest α that zeroes exactly three of them, and explain the coincidence in the fourth row.

Hint

For the second part, do not search. Each coefficient has its own threshold and you can write all four down directly from the L1 formula, so the question is really "sort four numbers and read off the third".

Show the worked solution
  1. The two formulas. L1 is sign(w*) max(|w*| − α/H, 0). L2 is H w* / (H + α).
  2. Thresholds at α = 0.5. α/H = 0.5, 0.5, 0.5, 1.0.
  3. L1 column. 3.0 − 0.5 = 2.5; 0.4 < 0.5 so 0; 0.2 < 0.5 so 0; −(2.0 − 1.0) = −1.0.
  4. L2 column. 3.0/1.5 = 2.0; 0.4/1.5 = 0.267; −0.2/1.5 = −0.133; 0.5(−2.0)/1.0 = −1.0.
  5. When is a coefficient zeroed? When α/Hii ≥ |w*i|, that is when α ≥ |w*i| × Hii.
  6. The four thresholds. 3.0, 0.4, 0.2 and 1.0. Sorted: 0.2, 0.4, 1.0, 3.0.
  7. Three are zeroed once α passes 1.0, the third smallest.
  8. The coincidence. In row four, L1 gives −(2.0 − 0.5/0.5) = −1.0 and L2 gives 0.5(−2.0)/(0.5 + 0.5) = −1.0. The two formulas happen to agree at these particular numbers. It is arithmetic, not a rule, and moving α even slightly separates them again.

Sanity check. Your L2 column must contain no zeros at any α you try. If one appears, you have applied the L1 formula twice. Check also that every L1 result has the same sign as its input or is zero: soft thresholding shrinks a coefficient towards zero and never past it, so a sign flip means you subtracted the threshold without taking the maximum against zero.
