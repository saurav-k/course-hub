HARNESS ENGINEERING Glossary Course Hub
For engineers who use an agent every day and have never read one

The tool you code with is software you have never read.

A coding harness is not a wrapper around a model API - it is a loop, a context assembler, a tool surface, a trust gate, an extension system, a model adapter, and a process identity, and every one of them makes decisions you can learn to read. Twenty-eight diagram-led pages build that reading skill across fifteen harnesses: ten taken apart at a pinned commit in their own source, five covered from official documentation because they are closed, plus one study of the model layer beneath them all.

Start with What a coding harness is, keep the Glossary open in a tab, and read Production Agent Engineering when your question becomes how to run what this course takes apart.
