Glossary

Every term this course introduces, defined once. A lesson that has to be readable in four different orders cannot rely on a term having been introduced earlier, so it links here instead.

How this page is used

A lesson introduces a term in its own prose the first time that lesson needs it, and links the term here as well. That is what makes a lesson safe to read out of order. When you write a lesson, add every term you introduce to this page in the same pull request.

This page is a starter, not a finished glossary

It carries the terms the lesson briefs already name. It grows with every lesson written. Keep entries to one or two sentences: this is a reminder for someone who met the idea an hour ago, not a replacement for the lesson that teaches it.

A to G

active parameters
The parameters actually used to compute one token. In a sparse model this is far smaller than the total, which is what makes the two numbers worth keeping apart.
agent
A model run in a loop with tools: it is given a goal, decides on an action, something runs that action, the result is appended to its context, and it decides again until it stops. Nothing in the model changes; the loop is the agent.
attention
A learned weighting over a set of positions, recomputed for each output step, used to draw a single summary from all of them rather than from a fixed compression.
backpropagation
The procedure that assigns blame for an error backwards through the layers of a network, so every weight learns how much it contributed.
BLEU
A score for a machine translation, counting how many short runs of words it shares with a human reference translation, with a penalty for being too short. Higher is better. It measures overlap, not understanding.
byte-pair encoding
The tokenizer training algorithm that repeatedly merges the most frequent adjacent pair of symbols until the vocabulary reaches a target size.
context window
The number of tokens a model will accept in one request. It is a capacity, and it is not a promise about how well the model uses them.
decoder
The half of a sequence model that produces output, one position at a time, where each position may see only what came before it.
embedding
A list of numbers standing for a token, learned so that tokens used in similar company end up near each other.
early fusion
Turning every kind of input into tokens at the very start, so images, audio and text share one sequence and one model, rather than joining two separately trained models afterwards.
encoder
The half of a sequence model that reads input, where every position may see every other position.
fine-tuning
Continuing to train an already-trained model on a smaller, more specific dataset.
encoder-decoder
A model in two halves: one reads an input sequence, the other writes an output sequence of a different length. Invented for translation, where the two sentences do not line up word for word.
gradient descent
Adjusting every weight a small step in the direction that reduces the measured error, and repeating.

H to R

in-context learning
The observation that a model with frozen weights performs better when worked examples are placed in its input. It is a description of a behaviour, not an explanation of one.
key-value cache
The stored keys and values for every token already processed, one entry per token per layer, re-read on every subsequent generated token.
language model
A function that reads some text and produces a probability for every possible next token. That is the whole definition.
loss
One number saying how wrong a prediction was, chosen so that making it smaller makes the model better at the thing you want.
masked language modelling
A training task that hides a fraction of the tokens in a passage and asks the model to predict them from both sides of each hole. It is what makes training a model that reads in both directions possible at all.
mixture of experts
A layer holding many small networks and a router that sends each token to a few of them, so storage and computation stop being the same number.
pass@1 and pass^k
Two different measurements. The first asks whether one attempt at a task succeeded, which is capability. The second asks whether all k repeats of the same task succeeded, which is reliability. A number reported for the first says nothing about the second.
perplexity
An informal measure of how surprised a language model is by real text. Lower is better.
pretraining
The one expensive training run over a large body of unlabelled text, done once, before any task-specific work.
positional encoding
A pattern of numbers added to each position's vector to say where in the sequence it sits. Attention compares everything with everything and so has no notion of order; this puts the order back as data.
query, key and value
The three roles in one attention step. The query is what a position is looking for, the key is what each position advertises, and the value is what it hands over when chosen.
process reward model
A model trained to score each intermediate step of a piece of reasoning rather than only the final answer. Widely expected to be the basis of reasoning training, and reported unsuccessful at scale by two laboratories in January 2025.
prompt injection
Text that a model reads as an instruction when it was supposed to be data. It is indirect when the attacker never talks to the model and instead plants the text somewhere the model will fetch it, such as a web page or a tool result.
reward model
A model trained to predict which of two answers a human would prefer, used as a stand-in for a human rater during reinforcement learning.
reinforcement learning from human feedback
Training a model against a reward model learned from human comparisons, with a penalty for drifting too far from where it started.
reinforcement learning from verifiable rewards
The same idea with a program rather than a person deciding whether the answer was right.
router
The small learned component in a sparse layer that scores each expert for each token and picks a few.

S to Z

scaling law
An empirical fit describing how loss falls as size, data or compute grows. It holds over the range it was measured on and promises nothing outside it.
self-attention
Attention pointed at the same sequence it belongs to, so every position draws a summary of all the others.
softmax
The step that turns a list of raw scores into positive weights that add up to one. It makes attention weights readable as proportions, and, because it is smooth, it is what makes attention trainable.
synthetic data
Training data written by a model rather than by a person. Central to current practice, and the subject of a specific worry about what happens when generated text replaces rather than supplements human text.
token
The unit a model actually reads and writes: a piece of text chosen by the tokenizer, usually smaller than a word.
Transformer
The 2017 architecture that keeps attention and removes recurrence, so every position in a sequence is computed at the same time.
transfer learning
Training one model on a large general task, then reusing it for a smaller specific one instead of starting from scratch. For text the general task is predicting the next word, so the training data needs no labels.
word alignment
A statement of which source words correspond to which target words in a translation. Statistical systems estimated one explicitly; attention produces one as a by-product of choosing where to look.
zero-shot
Asking a model to do a task described only in the prompt, with no worked examples and no training on it.
