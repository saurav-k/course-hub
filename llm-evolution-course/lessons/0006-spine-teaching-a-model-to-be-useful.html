Where this lesson starts

The scaling bet left a model that could predict text extremely well and was still awkward to use. This chapter explains the gap between predicting text and answering a question, and the three-stage recipe that closed it.

1. Where this lesson sits

What you need first

  • The scaling bet Between 2018 and 2022 the field discovered that the loss of a language model falls along a straight line as you spend more, which turned model building from a craft into a budgeting exercise, and then discovered the first version of that line was wrong.

The one tight idea

A model trained only to continue text is not trying to answer you, and the work of 2021 and 2022 was inventing a training stage whose whole job is to make it try.

4. Where this hands off

This course owns chronology, causation, people and dates. It hands off for mechanism, maths and code rather than re-deriving them.

  • Deep dive: Teaching a model to answer A model trained to continue text is not trying to be helpful, so you add a stage whose only job is preference: show it demonstrations, learn a stand-in for human taste, and let it practise against that on a short leash.
  • Deep dive: Chain of thought: prompting becomes a lever Asking a large model to write out its working before answering improves its accuracy on multi-step problems, which means the prompt is not just a request but a control on how much computation the model spends.
  • Deep dive: A text box changes everything The breakthrough of late 2022 was distribution rather than research: an existing recipe, tuned for conversation, put behind a free text box that anyone could use without reading anything first.
