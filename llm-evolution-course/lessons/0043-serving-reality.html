Serving reality: the cache, and what it costs

Generating a token requires re-reading everything the model has already seen, so serving is a memory problem before it is an arithmetic problem, and most of the engineering since 2022 is about that memory.

Where this lesson starts

Most of this course is about training a model. This one is about the other half of the bill, which is paid every time anyone uses it. It assumes you know what attention computes.

1. Where this lesson sits

What you need first

  • The Transformer: what dropping recurrence unlocked Delete the recurrence and keep only attention, and every position in a sentence can be computed at the same time with a constant number of operations between any two words.

The one tight idea

Generating a token requires re-reading everything the model has already seen, so serving is a memory problem before it is an arithmetic problem, and most of the engineering since 2022 is about that memory.

2. What this lesson must cover

To write. Full prose, complete sentences, 1,400 to 2,000 words. Every bullet below is a beat the finished lesson owes the reader, in this order.

  • Why generation is sequential even though training is parallel.
  • The key-value cache: what is stored, one entry per token per layer, and how fast it grows.
  • Why memory bandwidth rather than arithmetic is usually the limit.
  • The families of fix, one paragraph each: fewer key and value heads, better memory layout, a faster attention kernel, and guessing ahead.
  • The economic consequence: the cost of a request grows with the conversation, which shapes every product built on top.
Do not overclaim

Give cache-size arithmetic only for a configuration whose layer count, head count and precision you state. A number without its configuration is meaningless.
