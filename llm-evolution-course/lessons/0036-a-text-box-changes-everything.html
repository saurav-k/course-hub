A text box changes everything

The breakthrough of late 2022 was distribution rather than research: an existing recipe, tuned for conversation, put behind a free text box that anyone could use without reading anything first.

1. Where this lesson sits

What you need first

  • Teaching a model to answer A model trained to continue text is not trying to be helpful, so you add a stage whose only job is preference: show it demonstrations, learn a stand-in for human taste, and let it practise against that on a short leash.

The one tight idea

The breakthrough of late 2022 was distribution rather than research: an existing recipe, tuned for conversation, put behind a free text box that anyone could use without reading anything first.

2. What this lesson must cover

To write. Full prose, complete sentences, 1,400 to 2,000 words. Every bullet below is a beat the finished lesson owes the reader, in this order.

  • What was technically new, honestly assessed: conversational data and a chat format, on an existing recipe.
  • What was new about the delivery: free, no waiting list, no documentation to read, a familiar interface.
  • The adoption curve, described qualitatively unless you have a source you can open for the numbers.
  • The second-order effects: a race, a funding wave, and a change in what the public thought was possible.
  • The lesson to carry forward: interface and price are capabilities too.
Do not overclaim

The identity, size and training data of the model behind the launch were never disclosed. Do not name a parameter count, and do not assert which base model it was.
