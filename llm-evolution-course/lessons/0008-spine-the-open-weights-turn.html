Where this lesson starts

When the record closed left the frontier labs disclosing less. This chapter is about the counter-movement that formed in the same months, what it produced, and how the meaning of open has drifted since.

4. Where this hands off

This course owns chronology, causation, people and dates. It hands off for mechanism, maths and code rather than re-deriving them.

  • Deep dive: The leak that started an ecosystem A research-only model release leaked within a week, and the tooling that appeared in the following month showed there had been enormous unmet demand for weights anyone could run.
  • Deep dive: Four axes of open: weights, code, data, licence Open is not one question but four independent ones, almost nothing scores well on all four, and the word is now used for releases that would fail three of them.
  • Deep dive: Who ships open weights now The set of organisations publishing frontier-adjacent open weights has changed completely since 2023, and the change is a fact about release artefacts rather than a story about intentions.
