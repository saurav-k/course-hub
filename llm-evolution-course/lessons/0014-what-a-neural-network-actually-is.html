What a neural network actually is

A network is a stack of two operations, multiply by a table of numbers and then bend the result, and training is nudging those numbers until a measured error gets smaller.

Settled Accurate as of 21 August 2026. Interpretation is stable. Corrected by appending, never rewritten to fit a new event.
Where this lesson starts

Every lesson after this one assumes this one. It is the load-bearing page of the course. It assumes no calculus and no programming, only that you accept a number can be adjusted a little at a time.

1. Where this lesson sits

What you need first

  • The statistical turn: guessing the next word Language is predictable, predictability can be measured, and a machine that counts what usually follows what beats a machine that reasons about grammar.

The one tight idea

A network is a stack of two operations, multiply by a table of numbers and then bend the result, and training is nudging those numbers until a measured error gets smaller.

2. Everything in here is a list of numbers

A neural network has exactly one kind of data in it, and that is a list of numbers.

Four numbers written in a fixed order, say 2, 1, 4, 0, is a list of four numbers. The order matters and the length is fixed, so the third slot always means the same thing as the third slot in every other list of that shape. The usual word for such a list is a vector, and it is worth learning the word only because everyone uses it. It carries no extra idea beyond "a fixed-length list of numbers, in a fixed order".

Whatever the network is working on has to be turned into such a list before it goes in. A greyscale image becomes one number of brightness per pixel. A word becomes a list of a few hundred numbers, which is a whole story of its own and is Meaning as a direction in space. Whatever comes out is also a list of numbers, which somebody then chooses how to read: as one score per category, or as one probability per word in a vocabulary. The network itself never knows what any of its numbers are about.

3. A layer is a table of numbers, applied by multiplying

Take the list 2, 1, 4, 0 coming in. Give it a second list of the same length, 0.3, 0.5, 0.2, -0.4, called the weights. Multiply the two lists position by position and add up the results:

0.3×2 + 0.5×1 + 0.2×4 + (-0.4)×0 = 0.6 + 0.5 + 0.8 + 0 = 1.9

One number out. That is called a weighted sum, and it is the only arithmetic operation in this entire course that matters.

Now do it again with a different set of weights, -0.6, 0.1, 0.2, 0.7, against the same input:

(-0.6)×2 + 0.1×1 + 0.2×4 + 0.7×0 = -1.2 + 0.1 + 0.8 + 0 = -0.3

A second number out. Line up as many sets of weights as you want outputs and you have turned a list of four numbers into a list of however many you like. That collection of weight sets, written as a rectangle of numbers, is called a matrix, and doing all the weighted sums at once is called a matrix multiply. Those two words describe the picture below and nothing more than the picture below.

The rectangle is the layer. It is not a program and it contains no logic; it is a block of numbers, and applying it means doing one weighted sum per output. A large language model is mostly a few hundred of these rectangles, some of them with tens of millions of numbers in them.

4. The bend, which is not optional

Notice the last step in the figure. After each weighted sum, the number goes through one more operation, and the simplest one in common use is "if it is negative, make it zero". That is why -0.3 left the layer as 0. This step is called an activation function; this course will call it the bend, because that is what it does to the shape of the function the layer computes.

It looks like a detail. It is the reason depth buys anything at all.

Suppose there were no bend, and put two layers back to back. The first multiplies its input by 3, and the second multiplies by 2. Feed in 5: the first gives 15, the second gives 30. But multiplying by 3 and then by 2 is the same as multiplying by 6, so those two layers are one layer wearing a disguise. The same is true of a stack a hundred deep: a weighted sum of weighted sums is still just a weighted sum, so the whole tower collapses into a single equivalent layer and all that depth was wasted.

Now put the bend between them. Feed in -1. The first layer gives -3, the bend turns that into 0, and the second layer gives 0. With no bend, the same input would have come out as -6. The two arrangements now disagree, which means the pair can no longer be rewritten as one layer. The bend is what makes the second layer a genuinely new thing rather than a rescaling of the first.

5. Loss: reducing the disagreement to one number

Run an input through the whole stack and you get an output. That single pass, input to output, is called the forward pass.

Now you need to know how wrong it was, and you need to know it as a single number, because a single number is the only thing you can push downwards. That number is called the loss.

How it is computed depends on the task, but the flavour is always the same. If the network was meant to output 1.0 and produced 0.7, one reasonable loss is the difference squared, 0.09. For a language model, whose output is a probability for every word in the vocabulary, the loss at each position depends on how much probability the model put on the word that actually came next. Put 60 per cent on it and the loss at that position is small. Put 0.5 per cent on it and the loss is large. Average that across every position in a lot of text and you have one number describing how badly the model predicts language.

That number is what perplexity is a repackaging of, and it is the number that every claim of the form "this model is better" ultimately rests on.

6. Which way is downhill

Training means changing the weights so the loss gets smaller. There are millions or billions of them, so the only question that matters is: for this particular weight, would nudging it up or nudging it down make the loss smaller?

The honest way to picture the answer requires no calculus. Take one weight. Hold every other number in the model still. Ask what would happen to the loss if this one weight were a tiny bit larger. If the loss would go up, then this weight should be a tiny bit smaller; if the loss would go down, it should be a tiny bit larger. Do that for every weight and you know, for the whole model, which way is downhill. Then take a small step in that direction: not all the way, just a fraction, set by a number called the learning rate. That whole procedure is gradient descent, and the small step is called the update.

Two cautions belong here, because they explain most of what goes wrong later.

The step has to be small. "Downhill from here" is only true right here; take too large a step and you can end up somewhere worse than where you started, and a model that does this repeatedly does not converge at all.

And nobody actually holds every other weight still and re-runs the model once per weight, because with a billion weights that would take a billion forward passes per update. There is a procedure that works out the whole answer in one backward sweep through the layers, which is called backpropagation, and it is exactly as important as it sounds. It also has a failure mode of its own, which stalled the entire field for years. Backpropagation, and the two winters is that story.

7. Five words this course will keep using

That is the whole mechanism. The vocabulary attached to it is small, and every one of these terms appears in later lessons without further explanation.

The five terms every later lesson assumes
TermWhat it actually means
WeightsAll the numbers in all the layer rectangles. They are what training changes and what a downloaded model consists of.
Forward passRunning an input through the stack once to get an output. This is also all that happens when you use a trained model.
LossOne number saying how wrong the output was.
UpdateOne small change to every weight, in the direction that would reduce the loss.
EpochOne complete pass over the training data. The largest models see much of their data only once.

A model with a hundred billion weights is doing nothing that the two sums in figure 1 do not do. It is doing them a very great many times, with numbers that were arrived at by running figure 3 for months.

8. Why it is called a neuron, and why you should ignore that

The name is historical. In 1943 Warren McCulloch and Walter Pitts described a model of a nerve cell as something that adds up its inputs and fires if the total passes a threshold, and showed such things could compute logical functions. In 1958 Frank Rosenblatt built a learning version, the perceptron, and published it in a psychology journal. The vocabulary of the field was set by people trying to model brains, and it stuck.

It is a bad guide to what is happening. A unit in one of these networks computes a weighted sum and then bends the result. It does not fire, it has no timing, it does not do anything a biological neuron does, and reasoning about it as though it did will mislead you every time. The useful mental model is the one in figure 1: a row of numbers, a multiplication, an addition, and a bend.

This is also the border of this course. Everything above is stated in words on purpose; the same ground with the equations, the softmax step that turns output numbers into probabilities, and runnable code is the primer in the papers course. Nothing later in this course will need more mathematics than the two sums you did in section 3.

9. What it owes the next step

One question was deferred and it is the important one. Section 6 said that for every weight you need to know which way is downhill, and admitted that finding out one weight at a time is impossible at any real size. A network with three layers has an output error, but the weights in the first layer are two layers away from where the error was measured, and nothing observes them directly. Working out how much of the error each of them is responsible for is called credit assignment, and it is the problem that had to be solved before any of this could work. Backpropagation, and the two winters is how it was solved, why it took until 1986 to become common practice, and the second obstacle that appeared the moment it did.

Retrieval practice

What is a layer of a neural network, concretely?
A layer holds no logic at all: it is a rectangle of weights, and applying it means multiplying and adding.
What goes wrong if you stack layers with no bend between them?
A weighted sum of weighted sums is still a weighted sum, so without a bend a hundred layers compute exactly what one layer could.
Why must the loss be reduced to a single number?
Training is the act of making one quantity smaller, so the disagreement between output and answer has to become one quantity first.
Why is calling a unit a "neuron" a poor guide to what it does?
The name is a historical inheritance from people modelling brains, and reasoning about a unit as though it fired will mislead you.
