Problem sets: find out whether you own it

Reading a good explanation produces a feeling of understanding that survives right up until the moment you have to produce the argument yourself. Each set below forces that moment for one concept: a short recap to warm up, problems graded from warm-up to genuinely hard with the difficulty stated honestly, and a fully worked solution behind a collapsed block so you try before you read. The 18 sets come to about 13 hours of work on paper: one set costs 30 to 55 minutes, so a set is a sitting.

Attempt on paper first. Open a solution only when you have an answer to check against, right or wrong - a wrong answer you have caught teaches more than a right answer you have read.
