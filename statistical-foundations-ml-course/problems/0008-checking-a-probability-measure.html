Problem set 9 · Lecture 2 · the probability space, part three

A probability is any function that survives all three axioms, and only those

55 min frontier Eight problems on candidates that break in three different ways, and the properties the axioms force once they hold. Attempt each before opening its solution.

How to use this set

  • The measure P is the third pillar of the probability space (Ω, F, P): a function from events to [0, 1] obeying three axioms.
  • The checking skill from the sigma-field set repeats here with a new failure mode: a candidate can pass two axioms cleanly and die on the third.
  • The last two problems run the axioms in reverse, deriving the properties the lecture quoted - the empty set, monotonicity, the bounds on an intersection - rather than assuming them.

The recap

A probability measure P on (Ω, F) is a function P: F → [0, 1] satisfying three axioms: (1) P(∅) = 0; (2) P(Ω) = 1; (3) for any sequence of pairwise disjoint sets A1, A2, ... in F, P(∪n An) = Σn P(An). The lecture's own example assigns the four outcomes of a website visit, mobile-purchase, mobile-no-purchase, desktop-purchase, desktop-no-purchase, the weights 0.18, 0.42, 0.12 and 0.28, and every other probability on that space is then forced by additivity: joining from mobile is 0.18 + 0.42 = 0.6, making a purchase is 0.18 + 0.12 = 0.3. On a countable space the singleton weights are the whole story: if they are non-negative and sum to exactly one, they define a measure, and if not, no patching will save one.

Check the recap

Answer from memory before revealing.

On Ω = {H, T}, a candidate sets P({H}) = 0.7. What must P({T}) be, and why?
The two singletons are disjoint and their union is Ω, so additivity gives P({H}) + P({T}) = P(Ω) = 1, forcing 0.3. Option B smuggles in a fairness assumption the axioms never make; a biased coin is a perfectly good measure. Option C quotes the range axiom, which is real but is not the thing that pins the value. Option D contradicts additivity: the outcomes are disjoint pieces of one space, and together they must account for all of it.
A candidate assigns every singleton of Ω = {1, 2, 3} the value 0.5, extended by additivity. Which axiom fails?
The three singletons sum to 1.5, so P(Ω) = 1.5 and normalisation, which demands exactly 1, fails. Option A is defeated by immediate arithmetic. Option B misdescribes the candidate, since every value is positive. Option D is not it either: the candidate extends by additivity faithfully, and the breakdown is that its pieces already sum to more than the whole is allowed to weigh.

The problems paper and pen; open each solution only after committing to an answer

Problem 1warm-up

On Ω = {H, T} with the full power set as F, a candidate measure has P({H}) = 0.7. (a) What is P({T})? (b) Could a candidate have P({H}) = 1.2 and P({T}) = −0.2, so that the pair still sums to one? Which axiom or axioms kill it?

Show the worked solution
  1. (a). The singletons are disjoint with union Ω, so 0.7 + P({T}) = P(Ω) = 1, giving P({T}) = 0.3. The biased coin is a valid measure; nothing in the axioms prefers fair coins.
  2. (b). The pair sums to one, so normalisation and additivity would be respected. But P({H}) = 1.2 is outside the range [0, 1] that defines a probability measure, and P({T}) = −0.2 is negative. Both failures are range failures: the definition demands every event land in [0, 1], and negative probability is not a smaller kind of probability but a different object.

Sanity check. The range condition is doing real work here: without it, the signed pair of (b) would pass every other check, which is why the range is stated as part of the definition and not left to be derived.

Problem 2warm-up

The lecture's user example has Ω = {MP, MN, DP, DN} with weights 0.18, 0.42, 0.12, 0.28. (a) Verify all three axioms. (b) Compute P(joins from mobile), P(makes a purchase), and P(joins from mobile OR makes a purchase). (c) Check the last answer against the addition rule P(A ∪ B) = P(A) + P(B) − P(A ∩ B).

Show the worked solution
  1. The axioms. Each weight lies in [0, 1], so events land in [0, 1] by addition. The four weights sum to 0.18 + 0.42 + 0.12 + 0.28 = 1, so P(Ω) = 1. Additivity holds by construction on singletons and extends to all events, since every event is a disjoint union of singletons.
  2. Mobile. {MP, MN} has probability 0.18 + 0.42 = 0.6.
  3. Purchase. {MP, DP} has probability 0.18 + 0.12 = 0.3.
  4. Mobile or purchase. {MP, MN, DP} has probability 0.18 + 0.42 + 0.12 = 0.72. Note MP is counted once, not twice.
  5. The addition-rule check. P(A) + P(B) − P(A ∩ B) = 0.6 + 0.3 − P({MP}) = 0.9 − 0.18 = 0.72. The two routes agree, and the subtraction is exactly the un-counting of the shared outcome.

Sanity check. The union's probability must sit between the larger of the two, 0.6, and their sum, 0.9; 0.72 does, closer to the bottom because the events overlap by 0.18.

Problem 3working

On Ω = {1, 2, 3} with the full power set, three candidates define their singleton values and extend by additivity. For each, name the axiom that fails, or certify the candidate: (a) 0.5, 0.5, 0.5; (b) 0.5, 0.4, 0.2; (c) −0.2, 0.7, 0.5.

Show the worked solution
  1. (a). The values are non-negative, but they sum to 1.5, so P(Ω) = 1.5 ≠ 1. Normalisation fails, and no event's value can be repaired without breaking additivity.
  2. (b). Non-negative, but the sum is 1.1 ≠ 1. Normalisation fails again, by less, which changes nothing: the axiom is exact.
  3. (c). The sum is −0.2 + 0.7 + 0.5 = 1 exactly, so normalisation and additivity are fine. But −0.2 is not in [0, 1]. The range requirement fails, and it fails for the event {1} itself, before any union is taken.
  4. The pattern. Each candidate dies on exactly one axiom. The checking discipline is the same as the sigma-field set's: run all three, every time, because passing two is the normal condition of the failing third.

Sanity check. Candidate (c) is the instructive one: it shows the three axioms are logically independent, since satisfying two does not force the third.

Problem 4working

The uniform measure on Ω = {1, 2, 3, 4, 5, 6} sets P(A) = |A| ÷ 6 for every event A. (a) Verify the three axioms. (b) Compute P(even), P(greater than 4), and P(even or greater than 4). (c) Confirm the third answer with the addition rule.

Show the worked solution
  1. The axioms. P(∅) = 0 ÷ 6 = 0. P(Ω) = 6 ÷ 6 = 1. For disjoint A and B, |A ∪ B| = |A| + |B|, so the probabilities add; the countable version follows since a countable union of finite sets adds the same way. All three hold.
  2. Even. {2, 4, 6} has 3 elements, so P = 3 ÷ 6 = 0.5.
  3. Greater than 4. {5, 6} has 2 elements, so P = 2 ÷ 6 = 1/3.
  4. Either. {2, 4, 5, 6} has 4 elements, so P = 2/3.
  5. The check. The events overlap on {6}, worth 1/6. Addition rule: 0.5 + 1/3 − 1/6 = 3/6 + 2/6 − 1/6 = 4/6 = 2/3. Agrees.

Sanity check. The union must sit between 0.5 and 0.5 + 1/3 ≈ 0.83; 0.667 does, and the overlap subtracted, 1/6, is visibly the shared face of the die.

Problem 5working

A loaded die gives the face k the weight k/21, so P({k}) = k/21. (a) Verify the three axioms. (b) Compute P(even), P(greater than 4), and P(even or greater than 4), and check the third with the addition rule. (c) State in one sentence why the weights 1/21 through 6/21 were a safe choice to sum.

Show the worked solution
  1. The axioms. Every k/21 is positive and at most 6/21 < 1, so the range holds. The sum 1 + 2 + 3 + 4 + 5 + 6 = 21, so the weights total 21/21 = 1 and P(Ω) = 1. Additivity extends from singletons to all events as in Problem 4. All three hold: a valid measure.
  2. Even. (2 + 4 + 6) ÷ 21 = 12/21 = 4/7.
  3. Greater than 4. (5 + 6) ÷ 21 = 11/21.
  4. Either. {2, 4, 5, 6} weighs (2 + 4 + 5 + 6) ÷ 21 = 17/21. Check: 12/21 + 11/21 − 6/21 = 17/21, where the subtracted 6/21 is face six's double count. Agrees.
  5. (c). The weights 1/21 through 6/21 are positive and their sum is exactly 1 by the arithmetic of the first six integers, which is the whole licence needed; any positive weights summing to one define a measure the same way.

Sanity check. The loaded answers must all shift upward relative to the fair die's, since big faces carry more weight: 4/7 ≈ 0.571 against 0.5, and 11/21 ≈ 0.524 against 1/3. Both do.

Problem 6working

On Ω = {1, 2, 3, ...} with the full power set, define P(A) = 1 if 1 ∈ A and P(A) = 0 otherwise. (a) Verify all three axioms. (b) Compute P({1}), P(the even numbers), and P(the primes). (c) Two of those answers are zero while the corresponding events are infinite. Write the one sentence that resolves the apparent paradox.

Show the worked solution
  1. Axiom (1). 1 ∉ ∅, so P(∅) = 0.
  2. Axiom (2). 1 ∈ Ω, so P(Ω) = 1.
  3. Axiom (3). If A1, A2, ... are disjoint, at most one of them contains the number 1. If none does, every term is 0 and the union also misses 1, so both sides are 0. If exactly one does, that term is 1, all others are 0, and the union contains 1, so both sides are 1. Additivity holds.
  4. The values. P({1}) = 1; the even numbers exclude 1, so P = 0; the primes start at 2, so P = 0.
  5. The sentence. On an infinite space, probability zero does not mean impossible: this measure puts all its mass on the single outcome 1, so infinitely large events can weigh nothing. (The converse failure, an event of probability zero that still happens, is exactly what a continuous outcome looks like, which is the bridge to Lecture 6.)

Sanity check. This is a genuine measure, often called a point mass or Dirac measure: all three axioms pass, which is the licence that makes the strange answers official.

Problem 7genuinely hard

Run the axioms in reverse. (a) Prove P(∅) = 0 using only normalisation and additivity, by writing Ω as a disjoint union. (b) Prove monotonicity: if A ⊆ B then P(A) ≤ P(B), by writing B as a disjoint union involving A. (c) The lecture listed P(∅) = 0 as axiom (1); what does part (a) say about that listing?

Hint

For (a), write Ω = Ω ∪ ∅ ∪ ∅ ∪ ..., a disjoint sequence, and apply additivity to it. For (b), the missing piece of B is B \ A.

Show the worked solution
  1. (a). Write Ω = Ω ∪ ∅ ∪ ∅ ∪ ..., a sequence of pairwise disjoint sets. Additivity gives P(Ω) = P(Ω) + P(∅) + P(∅) + ... . Since P(Ω) = 1 is a finite number, the infinite tail must sum to zero, and each term is non-negative by the range, so P(∅) = 0. (With only finite additivity the same argument applied to Ω = Ω ∪ ∅ gives 1 = 1 + P(∅), so P(∅) = 0 again.)
  2. (b). If A ⊆ B, then B = A ∪ (B \ A), and the two pieces are disjoint. Additivity gives P(B) = P(A) + P(B \ A). The range makes P(B \ A) ≥ 0, so P(A) ≤ P(B).
  3. (c). Part (a) shows P(∅) = 0 is a theorem of the other axioms, not an independent requirement. Listing it as an axiom is harmless emphasis - the lecture's version makes the baseline explicit from the start - but a candidate that satisfied only normalisation and additivity would be forced to P(∅) = 0 anyway.

Sanity check. Monotonicity must agree with Problem 2: mobile, 0.6, contains mobile-and-purchase, 0.18, and 0.18 ≤ 0.6; every containment in that example prices out consistently.

Problem 8genuinely hard

You know only that P(A) = 0.6 and P(B) = 0.5. (a) Prove P(A ∩ B) ≥ 0.1. (b) Prove P(A ∩ B) ≤ 0.5. (c) Deduce the possible range of P(A ∪ B). (d) Show both extreme values of P(A ∩ B) are achievable, by building two measures on a ten-outcome space.

Hint

For (a), start from the addition rule and use P(A ∪ B) ≤ 1. For (b), use monotonicity from Problem 7 and the fact that A ∩ B sits inside both A and B.

Show the worked solution
  1. (a), the lower bound. The addition rule rearranges to P(A ∩ B) = P(A) + P(B) − P(A ∪ B). Since A ∪ B ⊆ Ω, monotonicity gives P(A ∪ B) ≤ P(Ω) = 1, so P(A ∩ B) ≥ 0.6 + 0.5 − 1 = 0.1. Intuition: two events weighing 0.6 and 0.5 cannot fit in a unit of space without overlapping by at least 0.1.
  2. (b), the upper bound. A ∩ B ⊆ B, so monotonicity gives P(A ∩ B) ≤ P(B) = 0.5. (It is also ≤ P(A) = 0.6, but 0.5 is the tighter of the two.)
  3. (c), the union. P(A ∪ B) = 1.1 − P(A ∩ B), and the intersection ranges over [0.1, 0.5], so P(A ∪ B) ranges over [0.6, 1.0]: at least the larger event alone, at most the whole space.
  4. (d), both extremes built. Take ten equally likely outcomes. Let A = {1, ..., 6} and B = {2, 3, 4, 5, 6, 7}: then P(A) = 0.6, P(B) = 0.5, and A ∩ B = {2, ..., 6} weighs 0.5, the upper extreme, with P(A ∪ B) = 0.7. Instead let B' = {6, 7, 8, 9, 10}: then A ∩ B' = {6} weighs 0.1, the lower extreme, with P(A ∪ B') = 1.0. Both extremes are real measures, so the bounds are tight.

Sanity check. The two bounds must be achievable for the question "what can be concluded" to have a definite answer, and the two constructions show they are; anything outside [0.1, 0.5] would contradict a proven bound.

Traps in this concept

  • Assuming fair means uniform. P({H}) = 0.7 is a perfectly valid measure; nothing in the axioms prefers balance. Fairness is an assumption about the world, not a theorem.
  • Adding probabilities of overlapping events. P(A) + P(B) double-counts the lens; the addition rule's subtraction is not decoration. Problem 2's check makes the double count visible.
  • Accepting a candidate on two axioms. Problem 3's three candidates each die on exactly one axiom, and the surviving two never rescue the third.
  • Reading P = 0 as impossible on infinite spaces. Problem 6's point mass weighs infinitely many infinite events at zero. The equivalence only holds the other way: impossible events always weigh zero.
  • Treating the axioms as a list of unrelated rules. Problem 7 derives P(∅) = 0 and monotonicity from the others, and Problem 8 turns them into bounds. The axioms are a machine, not a checklist of customs.
  • Forgetting the singleton weights decide everything. On a countable space, once the singleton weights are non-negative and total one, every event's probability is forced by addition; there are no further choices to get wrong.
Your teacher. The transferable habit is the three-check discipline: range, normalisation, additivity, in that order, out loud, on any candidate. The same discipline applied to a proposed metric definition - is it bounded, does it total correctly, do its pieces compose - catches a remarkable share of dashboard bugs.
