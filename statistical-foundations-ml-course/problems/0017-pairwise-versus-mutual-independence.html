Pairwise independence is not mutual independence

working 40 min Eight problems on paper. The tutorial's trap turned into a reflex, and independence permanently separated from disjointness.

The one-minute version

  • Two events are independent when P(A ∩ B) = P(A)·P(B): knowing one happened does not change the other's probability.
  • Mutual independence of n events demands the product rule for every subcollection, not just the pairs: 2n - n - 1 conditions.
  • Pairwise independence does not imply mutual independence. The tutorial's trap is a construction you can rebuild in one line.
  • Disjointness is about shared outcomes; independence is about shared probability. Disjoint events with positive probability are always dependent.

The concept in one paragraph

Independence is the statement that one event carries no information about another: P(A | B) = P(A), which multiplies out to P(A ∩ B) = P(A)·P(B) and, unlike the conditional form, survives even when P(B) = 0. For more than two events there are two different claims that both get called "independent". Pairwise independence asks the product rule for each pair separately. Mutual independence asks it for every subcollection: all the pairs, all the triples, all the quadruples, every non-empty proper subcollection, which is 2n - n - 1 conditions for n events. Mutual implies pairwise, but the converse fails, and the failure is not exotic: three events built from two coin tosses do it. Separately, disjointness is a relation between sets - no shared outcomes - while independence is a relation between probabilities, and the two ideas push against each other: two disjoint events of positive probability never satisfy the product rule, because P(A ∩ B) = 0 while P(A)·P(B) > 0.

The problems

Problem 1warm-up

In the lecture's ten-point space, A holds 5 points, B holds 4, and A ∩ B holds 2, all outcomes equally likely.

Verify that A and B are independent from the product rule, and confirm that the conditional form P(A | B) = P(A) gives the same verdict.

Show the worked solution
  1. Product rule. P(A ∩ B) = 2/10 = 1/5. P(A)·P(B) = (5/10) × (4/10) = (1/2) × (2/5) = 1/5. Equal: independent.
  2. Conditional form. P(A | B) = P(A ∩ B)/P(B) = (2/10)/(4/10) = 1/2, which equals P(A) = 5/10. Conditioning on B did not move A: independent.
  3. The two forms. They are the same statement rearranged, valid together whenever P(B) > 0. The product form is the one that still makes sense when the conditioning event has probability zero.

Sanity check. The overlap held exactly the proportional share of B: 2 of B's 4 points is the same fraction as 5 of Ω's 10. Proportional shares are what independence looks like in a uniform space.

Problem 2warm-up

A fair die is rolled once. A = {1, 2, 3} and B = {4, 5, 6}.

Show that A and B are disjoint but not independent, computing both sides of the product rule. Then state the general fact: which pairs of disjoint events would be independent?

Show the worked solution
  1. Disjoint. A ∩ B = ∅, so P(A ∩ B) = 0.
  2. Product side. P(A) = P(B) = 1/2, so P(A)·P(B) = 1/4.
  3. Verdict. 0 ≠ 1/4: not independent. Learning that A happened rules out B entirely, which is very strong information.
  4. General fact. Disjoint events are independent exactly when P(A)·P(B) = 0, that is, when at least one of them has probability zero. Every pair of disjoint events with positive probabilities is dependent.

Sanity check. Intuition check: if "the die lands in the first half" is true, "the die lands in the second half" must be false. Information that flips an event from possible to impossible is the opposite of no information.

Problem 3steady

Toss two fair coins. Let A = "the first coin is heads", B = "the second coin is heads", C = "both coins show the same face" (HH or TT).

Check all three pairwise product rules, then check the triple product rule, and conclude whether A, B, C are pairwise independent, mutually independent, or both. The recap figure draws the whole space.

Hint

Each of A, B, C holds exactly two of the four cells. Write out all four cells of each event before computing any intersection.

Show the worked solution
  1. The events. A = {HH, HT}, B = {HH, TH}, C = {HH, TT}. Each has probability 2/4 = 1/2.
  2. Pair A, B. A ∩ B = {HH}, probability 1/4 = (1/2)(1/2). Holds.
  3. Pair A, C. A ∩ C = {HH}, probability 1/4 = (1/2)(1/2). Holds.
  4. Pair B, C. B ∩ C = {HH}, probability 1/4 = (1/2)(1/2). Holds. All three pairs pass: pairwise independent.
  5. The triple. A ∩ B ∩ C = {HH}, probability 1/4. But P(A)·P(B)·P(C) = 1/8. Since 1/4 ≠ 1/8, the triple rule fails: not mutually independent.
  6. Conclusion. Pairwise independent and not mutually independent, the tutorial's trap in a two-coin costume.

Sanity check. C is a deterministic function of A and B: given whether the coins match, plus one face, the other face follows. A third event computed from two others is exactly the shape that breaks mutuality while sparing the pairs.

Problem 4steady

A fair coin is tossed three times. Let A, B, C be "the first, second, third toss is heads" respectively.

Verify every condition of mutual independence by explicit computation: the three pair rules and the triple rule. Then count how many product rules mutual independence demands for n = 4 events, and in general for n events.

Show the worked solution
  1. Singles. Each of A, B, C holds 4 of the 8 outcomes: P = 1/2 each.
  2. Pairs. A ∩ B = {HH*}: 2 outcomes, P = 1/4 = (1/2)(1/2). The same holds for A ∩ C and B ∩ C by symmetry. All three pair rules hold.
  3. Triple. A ∩ B ∩ C = {HHH}, P = 1/8 = (1/2)3. Holds.
  4. Verdict. All four conditions hold: A, B, C are mutually independent, as three physically separate tosses should be.
  5. The count. For n events the conditions are one product rule per non-empty proper subcollection: C(n, 2) pairs + C(n, 3) triples + ... + C(n, n-1) + the full n-fold rule. For n = 4: C(4,2) + C(4,3) + C(4,4) = 6 + 4 + 1 = 11 conditions. In general 2n - n - 1, since there are 2n subcollections, minus the n singletons and the empty one.

Sanity check. For n = 3 the count is 23 - 4 = 4: three pairs and one triple, exactly the four rules checked above.

Problem 5steady

Prove: if A and B are independent, then A and Bc are independent. This is the claim stated without proof in the course's independence notes.

Then use your result twice more to conclude that Ac and Bc are independent.

Hint

Split A into the part inside B and the part inside Bc: A = (A ∩ B) ∪ (A ∩ Bc), a disjoint union, so their probabilities add to P(A).

Show the worked solution
  1. Split A. A = (A ∩ B) ∪ (A ∩ Bc), disjoint, so P(A) = P(A ∩ B) + P(A ∩ Bc).
  2. Use the hypothesis. Independence gives P(A ∩ B) = P(A)P(B), so P(A ∩ Bc) = P(A) - P(A)P(B).
  3. Factor. P(A) - P(A)P(B) = P(A)(1 - P(B)) = P(A)·P(Bc). That is the product rule for A and Bc: independent.
  4. Run it again. A and Bc are independent by the result just proved; applying the same result to the pair (Bc, A) gives that Bc and Ac are independent. Two applications cover all four sign combinations: A/B, A/Bc, Ac/B, Ac/Bc.

Sanity check. Sense check: if a coin's landing heads tells you nothing about a die showing six, then it tells you nothing about the die not showing six either. No information about an event is no information about its complement.

Problem 6steady

Events A, B, C are mutually independent with P(A) = 0.5, P(B) = 0.4, P(C) = 0.3.

Compute: P(none of the three happens); P(exactly one happens); P(at least one happens). For the middle one, sum the three disjoint single-event cases, using mutual independence to factor each.

Show the worked solution
  1. None. Ac ∩ Bc ∩ Cc factors by mutual independence: (0.5)(0.6)(0.7) = 0.21.
  2. Exactly one, the three cases. Only A: (0.5)(0.6)(0.7) = 0.21. Only B: (0.5)(0.4)(0.7) = 0.14. Only C: (0.5)(0.6)(0.3) = 0.09. The three cases are disjoint.
  3. Exactly one. 0.21 + 0.14 + 0.09 = 0.44.
  4. At least one. The complement of "none": 1 - 0.21 = 0.79.

Sanity check. The four categories none, exactly one, exactly two, at-least-two must total 1: none 0.21 plus exactly one 0.44 leaves 0.35 for two-or-more, and a quick check of "exactly two" gives 0.5×0.4×0.7 + 0.5×0.6×0.3 + 0.5×0.4×0.3 = 0.14 + 0.09 + 0.06 = 0.29, with all-three at 0.06: 0.29 + 0.06 = 0.35. The books balance.

Problem 7hard

A fair die is rolled once. Consider B = {1, 3, 5}, A = {1, 2}, and C = {1, 4}.

Verify that A and B are independent and that B and C are independent. Then check A against C and conclude whether independence is transitive: if A is independent of B, and B of C, must A be independent of C?

Show the worked solution
  1. A with B. A ∩ B = {1}, P = 1/6. P(A)P(B) = (2/6)(3/6) = (1/3)(1/2) = 1/6. Equal: independent.
  2. C with B. C ∩ B = {1}, P = 1/6. P(C)P(B) = (1/3)(1/2) = 1/6. Equal: independent.
  3. A with C. A ∩ C = {1}, P = 1/6. P(A)P(C) = (1/3)(1/3) = 1/9. Since 1/6 ≠ 1/9: dependent.
  4. Conclusion. Independence is not transitive. Both A and C are independent of B while depending on each other through the outcome 1 that both share with B.

Sanity check. The mechanism is visible: B = {1, 3, 5} absorbs the correlation between A and C by containing their only overlap. Removing B's other members, or A's and C's, would break the delicate balance, which is why this is a constructed example rather than a generic situation.

Problem 8hard

In the two-coin space of the figure, prove that no two events A and B with 0 < P(A) < 1 and 0 < P(B) < 1 can be independent.

Strategy: first show every event probability is a multiple of 1/4, so the product P(A)·P(B) must be a multiple of 1/16; work out which multiples of 1/16 are achievable as products of two non-trivial probabilities, and conclude which pair of probabilities is the only candidate. Then enumerate the events with those probabilities and check every distinct pair.

Hint

The four outcome probabilities are 1/4, 1/4, 1/2, 0, so every event's probability is a sum of some of {0, 1/4, 1/4, 1/2}. Non-trivial means the total is in {1/4, 1/2, 3/4}.

Show the worked solution
  1. Every probability is a multiple of 1/4. An event is a subset of the four outcomes, and its probability is a sum of terms from {1/4, 1/4, 1/2, 0}: one of 0, 1/4, 1/2, 3/4, 1.
  2. Products of two non-trivial probabilities. With P(A) = k/4 and P(B) = m/4 for k, m ∈ {1, 2, 3}, the product is km/16 ∈ {1/16, 2/16, 3/16, 4/16, 6/16, 9/16}.
  3. The intersection must also be a multiple of 1/4. A ∩ B is itself an event, so P(A ∩ B) ∈ {0, 4/16, 8/16, 12/16, 16/16}. Independence demands P(A ∩ B) = km/16, so the product km/16 must be a multiple of 4/16. Among the achievable products only 4/16 qualifies, which forces k = m = 2: both events must have probability exactly 1/2.
  4. Enumerate the half-probability events. Subsets of the atoms (C1, H), (C1, T), (C2, H) with values 1/4, 1/4, 1/2 summing to 1/2: {(C1, H), (C1, T)} and {(C2, H)}, each optionally with the zero-weight (C2, T). Up to that free addition there are exactly two: call them E1 and E2.
  5. Check the only candidate pair. E1 ∩ E2 = ∅ (or, with the free additions, possibly {(C2, T)}): probability 0 either way. But independence would demand 1/4. The single candidate pair fails.
  6. Conclusion. No two non-trivial events in this space are independent. The uneven weights 1/4, 1/4, 1/2, 0 leave no room for the product rule.

Sanity check. The proof had to work hard only once, at step 3, where the arithmetic killed every probability pair except (1/2, 1/2); the enumeration that remains is two events, not sixteen, which is what makes the exhaustive check honest and short.

Traps in this concept

  • Concluding mutual independence from the pairs. The two-coin construction of Problem 3 passes three pair rules and fails the triple. For n events there are 2n - n - 1 rules, and every one of them needs its own check.
  • Using "disjoint" and "independent" as synonyms. Problem 2: disjoint positive-probability events are maximally dependent. Disjoint is geometry, independent is information.
  • Assuming independence transmits. Problem 7: A independent of B and B independent of C, with A and C dependent. Independence is a pairwise property of a probability distribution, not a relation that chains.
  • Forgetting the complement closure. Problem 5: independence of A and B silently delivers independence of all four sign combinations. Use it rather than re-deriving it, but know the derivation.
  • Testing independence on events of probability zero or one. Any event of probability 0 or 1 is independent of everything, including itself. The interesting question, and Problem 8's, is always about the non-trivial middle.
Your teacher. The exit test is rebuilding the Problem 3 construction from memory: two fair coins, A and B the two faces, C the match. If you can draw the four cells and recite which three rules pass and which one fails, the tutorial's trap can never surprise you again.
