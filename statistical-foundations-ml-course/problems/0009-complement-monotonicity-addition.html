Three working tools fall straight out of the three axioms

working 30 min Seven problems on paper. The complement rule, monotonicity, and the addition rule, each derived once and then used until it sticks.

The one-minute version

  • The axioms say P(∅) = 0, P(Ω) = 1, and that probabilities add over disjoint sets.
  • Everything on this page is a consequence of those three lines, derived rather than memorised.
  • The workhorse is the addition rule: P(A ∪ B) = P(A) + P(B) - P(A ∩ B). The overlap is where every mistake lives.
  • Use the Lecture 2 user example and the Lecture 3 two-coin example as your numerical playground, because you already trust their numbers.

The concept in one paragraph

A probability measure P assigns to each event A a number P(A) between 0 and 1, gives the empty set ∅ the value 0 and the whole sample space Ω the value 1, and adds across disjoint events: if A and B share no outcome, P(A ∪ B) = P(A) + P(B). From those three lines the lecture derives three tools you will use constantly: the complement rule P(Ac) = 1 - P(A), where Ac is the event that A does not happen; monotonicity, which says A ⊆ B forces P(A) ≤ P(B); and the addition rule, which repairs the naive sum whenever A and B do overlap. This set makes you derive each one, because a rule you have derived is a rule you can rebuild under exam pressure.

The problems

Attempt each one on paper before opening its solution. The Lecture 2 numbers you will reuse: a user arrives as MP (mobile and purchases, .18), MN (mobile, no purchase, .42), DP (desktop and purchases, .12), or DN (desktop, no purchase, .28). The Lecture 3 numbers you will reuse: pick one of two coins and toss it once, where coin C1 is fair and coin C2 always shows heads.

Problem 1warm-up

In the user example, let A be the event that the user joins from mobile, so A = {MP, MN}. The lecture computes P(A) = .18 + .42 = .6.

Derive the complement rule P(Ac) = 1 - P(A) from the axioms, then compute P(Ac) two ways: by the rule, and by adding outcome probabilities directly from the four outcomes above.

Show the worked solution
  1. Write A and its complement as a disjoint pair. Every outcome is in exactly one of A or Ac, so the two events are disjoint and their union is the whole space: A ∪ Ac = Ω.
  2. Apply the additivity axiom to that disjoint pair. P(A ∪ Ac) = P(A) + P(Ac).
  3. Use the whole-space axiom. The left side is P(Ω) = 1, so P(A) + P(Ac) = 1, which rearranges to P(Ac) = 1 - P(A).
  4. Compute by the rule. P(Ac) = 1 - .6 = 0.4.
  5. Compute directly. Ac = {DP, DN}, so P(Ac) = .12 + .28 = 0.4. The two routes agree.

Sanity check. The complement should always be the "everything else" share of the outcomes: .12 and .28 are indeed the two non-mobile outcomes, and they sum to 0.4.

Problem 2warm-up

Derive monotonicity: if A ⊆ B then P(A) ≤ P(B). Then check it on the user example with A = "makes a purchase" = {MP, DP} and B = "mobile or purchases" = {MP, MN, DP}, and state the one situation in which equality holds.

Hint

Split B into two disjoint pieces: A itself, and the difference B \ A, the outcomes in B but not in A. The additivity axiom applies to disjoint pieces.

Show the worked solution
  1. Split B into disjoint pieces. B = A ∪ (B \ A), and A and B \ A are disjoint by construction, since B \ A keeps only the outcomes of B that are not in A.
  2. Apply additivity. P(B) = P(A) + P(B \ A).
  3. Drop the non-negative term. Every probability is at least 0, so P(B \ A) ≥ 0 and therefore P(B) ≥ P(A).
  4. Check the numbers. P(A) = .18 + .12 = 0.3. P(B) = .18 + .42 + .12 = 0.72. Indeed 0.3 ≤ 0.72, and the gap is P(B \ A) = P({MN}) = 0.42.
  5. Equality condition. Equality P(A) = P(B) holds exactly when P(B \ A) = 0, that is, when the outcomes B adds beyond A carry no probability.

Sanity check. The gap 0.72 - 0.3 = 0.42 should equal the probability of the piece B holds beyond A, which is the single outcome MN at .42.

Problem 3steady

Derive the difference rule: P(A \ B) = P(A) - P(A ∩ B), where A \ B is the event "A happens and B does not". Then use it to find P(the user purchases but not from mobile) in the user example, and verify the answer against the outcome table.

Hint

A splits into two disjoint pieces: the part inside B, which is A ∩ B, and the part outside B, which is A \ B.

Show the worked solution
  1. Split A into disjoint pieces. A = (A ∩ B) ∪ (A \ B), a disjoint union: an outcome of A either also lies in B or it does not, never both.
  2. Apply additivity. P(A) = P(A ∩ B) + P(A \ B).
  3. Rearrange. P(A \ B) = P(A) - P(A ∩ B). This is the difference rule.
  4. Apply it. A = "makes a purchase" = {MP, DP} with P(A) = 0.3. A ∩ B = {MP} with P(A ∩ B) = .18, taking B = "joins from mobile". So P(A \ B) = 0.3 - 0.18 = 0.12.
  5. Verify directly. "Purchases but not from mobile" is exactly the outcome DP, whose probability is .12. The routes agree.

Sanity check. Purchases split into mobile purchases (.18) and desktop purchases (.12), and .18 + .12 = .30, which is P(A). Nothing is lost.

Problem 4steady

In the two-coin space the four outcomes carry probabilities P({(C1, H)}) = 1/4, P({(C1, T)}) = 1/4, P({(C2, H)}) = 1/2, P({(C2, T)}) = 0. Let A1 = "picked coin 1" and E = "observed tails".

Compute P(A1 ∪ E) using the addition rule, then verify the answer by listing the outcomes of the union and adding their probabilities.

Show the worked solution
  1. Name the three ingredients. A1 = {(C1, H), (C1, T)}, so P(A1) = 1/4 + 1/4 = 1/2. E = {(C1, T), (C2, T)}, so P(E) = 1/4 + 0 = 1/4. The overlap A1 ∩ E = {(C1, T)}, so P(A1 ∩ E) = 1/4.
  2. Apply the addition rule. P(A1 ∪ E) = 1/2 + 1/4 - 1/4 = 1/2.
  3. Verify by enumeration. A1 ∪ E = {(C1, H), (C1, T), (C2, T)}, and its probability is 1/4 + 1/4 + 0 = 1/2. The routes agree.

Sanity check. The union covers three of the four outcomes, but the fourth outcome (C2, H) alone carries probability 1/2, so the three remaining outcomes must also total 1/2. They do.

Problem 5steady

For two events A and B you are given P(A ∪ B) = 0.7, P(A) = 0.4, and P(A ∩ B) = 0.15.

Find P(B). Then find P(exactly one of A and B happens), two ways: once as P(A ∪ B) - P(A ∩ B), and once as P(A \ B) + P(B \ A).

Hint

The addition rule has three knowns once you read it carefully: it contains P(B) as the only unknown. For the second part, "exactly one" means inside the union but outside the overlap.

Show the worked solution
  1. Solve the addition rule for P(B). P(A ∪ B) = P(A) + P(B) - P(A ∩ B), so P(B) = 0.7 - 0.4 + 0.15 = 0.45.
  2. First route to "exactly one". The union counts the overlap once, and adding P(A) + P(B) counts it twice, so P(exactly one) = P(A ∪ B) - P(A ∩ B) = 0.7 - 0.15 = 0.55.
  3. Second route. P(A \ B) = P(A) - P(A ∩ B) = 0.4 - 0.15 = 0.25. P(B \ A) = P(B) - P(A ∩ B) = 0.45 - 0.15 = 0.30. These two pieces are disjoint, so P(exactly one) = 0.25 + 0.30 = 0.55. The routes agree.

Sanity check. The three disjoint regions should sum to 1: only A (0.25) plus the overlap (0.15) plus only B (0.30) plus outside (0.30) = 1.00, so P(outside) = 0.30 as a bonus.

Problem 6hard

You know only P(A) = 0.5 and P(B) = 0.6 for two events on a common sample space.

Find the smallest and largest values P(A ∩ B) can take, with a one-line justification for each bound. Then find the smallest and largest values of P(A ∪ B). Finally, build both extremes concretely on a ten-point space with all outcomes equally likely, naming the points of A and B.

Hint

The upper bound on the overlap is monotonicity. The lower bound comes from insisting that P(A ∪ B) cannot exceed 1. The ten-point space then lets you draw both extremes with actual dots.

Show the worked solution
  1. Largest overlap. A ∩ B ⊆ A, so by monotonicity P(A ∩ B) ≤ P(A) = 0.5. The value 0.5 is reachable: take B ⊇ A with room to spare, that is A ⊆ B.
  2. Smallest overlap. The addition rule gives P(A ∪ B) = P(A) + P(B) - P(A ∩ B). Probabilities never exceed 1, so 0.5 + 0.6 - P(A ∩ B) ≤ 1, which forces P(A ∩ B) ≥ 0.1. In words: two events of size more than half must share something.
  3. Range of the union. From the same rule, P(A ∪ B) is smallest when the overlap is largest: 0.5 + 0.6 - 0.5 = 0.6. It is largest when the overlap is smallest: 0.5 + 0.6 - 0.1 = 1.0. So 0.6 ≤ P(A ∪ B) ≤ 1.
  4. Build the small-union extreme. Let Ω = {1, 2, ..., 10}, A = {1, 2, 3, 4, 5}, B = {1, 2, 3, 4, 5, 6}. Then A ⊆ B, the overlap is all of A with probability 0.5, and the union is B with probability 0.6.
  5. Build the large-union extreme. Let A = {1, 2, 3, 4, 5} and B = {5, 6, 7, 8, 9, 10}. The overlap is the single point {5}, probability 0.1, and the union is all ten points, probability 1. Both extremes are real events, so neither bound can be tightened without more information.

Sanity check. Five plus six is eleven points but the space only has ten, so at least one point must be shared: that is the 0.1 floor, seen by counting dots instead of by algebra.

Problem 7hard

Prove that complements reverse inclusion: if A ⊆ B then Bc ⊆ Ac, and therefore P(Bc) ≤ P(Ac). Then check the chain on the user example with A = "makes a purchase" and B = "mobile or purchases", the two events from Problem 2.

Hint

Take an outcome in Bc, meaning it is outside B, and ask where it can sit relative to A, given that A hides inside B.

Show the worked solution
  1. Chase an outcome. Let ω be any outcome in Bc. Then ω ∉ B. Since A ⊆ B, no outcome of A can lie outside B, so ω ∉ A either. That is exactly the statement ω ∈ Ac.
  2. Conclude the set inclusion. Every outcome of Bc lies in Ac, so Bc ⊆ Ac.
  3. Apply monotonicity, already derived in Problem 2. Bc ⊆ Ac gives P(Bc) ≤ P(Ac).
  4. Check the numbers. A = {MP, DP} with P(A) = 0.3 sits inside B = {MP, MN, DP} with P(B) = 0.72. The complements are Ac = {MN, DN} with probability 0.42 + 0.28 = 0.7, and Bc = {DN} with probability 0.28. Indeed Bc = {DN} ⊆ {MN, DN} = Ac, and 0.28 ≤ 0.7.

Sanity check. Bigger event, smaller complement: P(Ac) = 1 - 0.3 = 0.7 and P(Bc) = 1 - 0.72 = 0.28, and the order flipped exactly as the theorem demands.

Traps in this concept

  • Adding without subtracting. P(A) + P(B) is almost never P(A ∪ B). The reflex to build is: overlap first, then add.
  • Subtracting the overlap twice. P(A ∩ B) appears with a minus in the union rule and with a plus in P(exactly one) = P(A) + P(B) - 2P(A ∩ B). Write the three regions and label them before computing.
  • Reading A ⊆ B backwards. Monotonicity says the bigger set carries at least as much probability. If your P(small event) exceeds P(big event), one of the two is wrong.
  • Treating 1 - P(A) as needing an assumption. The complement rule holds for every event in every probability space; the only input is P(Ω) = 1 and disjointness of A and Ac.
  • Believing bounds are answers. With only P(A) and P(B) known, P(A ∪ B) is a range, not a number. Problem 6 is the antidote: build both extremes.
Your teacher. If any solution did not land, ask for the derivation of the addition rule from a picture of three regions: only A, the lens, only B. Being able to rebuild P(A ∪ B) = P(A) + P(B) - P(A ∩ B) from that picture, without memory, is the exit test for this set.
