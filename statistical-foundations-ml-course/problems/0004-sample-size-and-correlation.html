Problem set 5 · Lecture 1 · after Parts 6 and 7

More data buys resolution, never truth: sizing n and weighing r

50 min problem set Seven problems on what larger n actually buys and how much weight a correlation can carry. Attempt each before opening its solution.

How to use this set

  • The first half runs on one proportionality, SE ∝ 1/√n, with the deck's own numbers as reference points: SEs of 0.0145 and 0.0150 at n = 1,000, falling to 0.0065 and 0.0067 at n = 5,000.
  • The second half runs on Pearson's r, the deck's 0.71 for session time and −0.03 for brightness.
  • Both halves end in the same question: what is this number evidence for, and what would change my mind?

The recap

The spread of an estimated rate is √( p(1 − p)/n ), so precision improves only as the square root of the sample size: four times the users buy half the error, sixteen times buy a quarter. That square-root law is why studies are sized in advance - the last doubling of precision always costs four times the last one. Pearson's r is a different instrument for a different question: it centres two columns, multiplies the centred values pairwise, sums, and rescales, producing a number from −1 to +1 that measures straight-line co-movement in this sample. The deck's session time earns r ≈ 0.71 against spend; screen brightness manages −0.03. The square root law says what more data is worth; r says which candidates are worth collecting more data about. Neither number vouches for cause.

Check the recap

Answer from memory before revealing.

An experiment grows from 1,000 to 4,000 users per group. What happens to the standard error of the rate?
Four times the users divides the variance by four, and the standard error is the square root of the variance, so it halves. Option A mistakes the variance for the standard error. Option C would hold only if the error fell with one over n squared, which would make experiments vastly cheaper than they are. Option D contradicts the formula, which falls steadily with n; it just falls more slowly than n itself.
A dashboard reports r = −0.9 between two product metrics. What does that number establish?
An r near minus one says the two columns sit almost on a downward straight line in this sample. Option B is the classic overreach: r ranks association and is silent about mechanism, since a third factor can move both columns. Option C gets the sign backwards, because minus 0.9 is about as strongly related as r ever gets. Option D confuses the size of a number with the evidence behind it: a small sample produces striking r values by accident routinely, which is why n travels with the coefficient.

The problems paper and pen; open each solution only after committing to an answer

Problem 1warm-up

A rate estimated from n = 100 coin flips at p̂ = 0.5 has a standard error of 0.05. What is the standard error at n = 900, and by what factor did it fall? Confirm the factor by computing the second standard error directly.

Show the worked solution
  1. By the square root law. The sample grew ninefold, so the standard error falls by √9 = 3, from 0.05 to 0.0167.
  2. Directly. p̂(1 − p̂) = 0.25, and 0.25 ÷ 900 = 0.000278, so SE = √0.000278 = 0.0167. The two routes agree.
  3. Read the shape. Nine times the data bought a third of the error. The first factor of three in data bought as much precision as the next six combined, which is the steep-then-flat curve of the recap figure in numbers.

Sanity check. The new error must be smaller than 0.05 but larger than 0.05 ÷ 9 ≈ 0.0056, because the payoff is a square root: 0.0167 sits between them.

Problem 2warm-up

An experiment at n = 400 has SE = 0.02. What sample size halves the error to 0.01, and what size quarters it to 0.005? Express the multipliers as a rule connecting the precision factor to the sample factor.

Show the worked solution
  1. Halving. Halving the SE doubles √n, and doubling a square root means multiplying n by four: 400 × 4 = 1,600.
  2. Quartering. A quarter of the SE needs √n multiplied by four, so n multiplied by sixteen: 400 × 16 = 6,400.
  3. The rule. The sample factor is the square of the precision factor. Half the error costs 4×, a tenth costs 100×, a hundredth costs 10,000×. Every precision conversation is a squared conversation about money.

Sanity check. Scaling the original error by the square root of the sample ratio: 0.02 × √(400/1600) = 0.02 × 0.5 = 0.01, and 0.02 × √(400/6400) = 0.02 × 0.25 = 0.005.

Problem 3working

Each user in your experiment costs Rs 2, and the budget is Rs 20,000, so n = 10,000. With an expected rate near 0.30, what 95 percent interval half-width, using the multiplier 2, does that buy? The sponsor asks for half that width: what budget should you quote them?

Show the worked solution
  1. The standard error at the budget. p(1 − p) ≈ 0.21, and 0.21 ÷ 10,000 = 0.000021, so SE = √0.000021 = 0.00458.
  2. The half-width. 2 × 0.00458 = 0.0092, a bit under one percentage point either way.
  3. The sponsor's ask. Half the width needs four times the users: 40,000 of them, which at Rs 2 each is Rs 80,000, four times the budget.
  4. What to say. The honest quote is the square law itself: precision is bought in squares of money. If Rs 80,000 is unaffordable, the choice is a wider interval, a cheaper measurement, or a different question, not a discount.

Sanity check. Doubling the sample to 20,000 would have halved the variance and cut the width only by a factor of √2 ≈ 1.41, clearly short of the sponsor's ask; only the full factor of four reaches it.

Problem 4working

Compute Pearson's r from scratch for five users: session time X = 1, 2, 3, 4, 5 minutes, and spend Y = 2, 4, 5, 4, 5 rupees (tens, for arithmetic comfort). Centre both columns, sum the products of the centred pairs, rescale, and interpret the result.

Hint

The means are x̄ = 3 and ȳ = 4. The centred X column must sum to zero, which is a free check before any products are taken.

Show the worked solution
  1. Centre both columns. X − 3 gives −2, −1, 0, 1, 2, which sums to zero as it must. Y − 4 gives −2, 0, 1, 0, 1, also summing to zero.
  2. Multiply pairwise and add. The products are 4, 0, 0, 0, 2, and the sum is 6. Four of the five users vote positive or not at all; nobody votes negative.
  3. Rescale. The centred X squares sum to 4 + 1 + 0 + 1 + 4 = 10. The centred Y squares sum to 4 + 0 + 1 + 0 + 1 = 6. So r = 6 ÷ √(10 × 6) = 6 ÷ √60 = 6 ÷ 7.746 = 0.77, to two decimal places.
  4. Interpret. A strong positive straight-line association in this sample of five: users above average on session time are above average on spend, with no dissenter. What it does not say is whether longer sessions cause the spend, the spend causes the sessions, or both ride on a third factor.

Sanity check. Every product in the sum was non-negative, so r must be positive, and it must fall short of 1 because the points do not sit exactly on a line; 0.77 clears both tests.

Problem 5working

Over 36 months, a dashboard reports r = 0.85 between emails sent by the sales team and monthly revenue, and recommends hiring more sales staff to send more email. Give three distinct checks you would run before acting, and say what each check could find that would change the story.

Show the worked solution
  1. Check the confounder first. Both columns ride on company growth: a growing company sends more email and books more revenue, so two series that both trend upward correlate strongly while sharing no mechanism. Detrend both series, or correlate their month-on-month changes, and see whether r survives; if it collapses toward zero, the 0.85 was the trend introducing itself.
  2. Draw the scatter and look. Thirty-six points can hide a story: two clusters, one influential month, or a curved relationship that a single straight-line number flattens. Anscombe's classic four datasets, identical in summary and unrecognisable in scatter, exist precisely because this step gets skipped.
  3. Test the direction of time. The recommendation assumes email drives revenue. Correlate this month's email with next month's revenue, and next month's email with this month's revenue. If revenue predicts email at least as well as email predicts revenue, the causal arrow in the recommendation is an assumption, not a finding.
  4. What the checks protect. The 0.85 may be perfectly real as co-movement and still be useless as a lever: hiring to send more email moves the first column, and nothing in r promises the second follows. Correlation nominates candidates for an experiment; it does not run the experiment.

Sanity check. Each check names a mechanism that leaves r untouched - a shared trend, a curved shape, a reversed arrow - which is exactly the kind of thing a single coefficient cannot see.

Problem 6genuinely hard

The deck computes r = 0.71 from five users and calls session time a leading indicator; Part 7 warns that five points is five points. Put a magnitude on the warning with this rule of thumb: when the true correlation is zero and the data is roughly bell-shaped, a sample r typically wanders within about ±1/√(n − 1) of zero. How many typical wanderings is 0.71 away from zero at n = 5? At n = 100? What does the comparison say about when a correlation is remarkable?

Hint

Compute 1/√(n − 1) for both sample sizes, then divide 0.71 by each. The rule of thumb and its assumptions are stated in the problem; treat the outputs as typical sizes, not guarantees.

Show the worked solution
  1. At n = 5. The typical size of a no-signal r is 1/√4 = 0.5. The observed 0.71 is 0.71 ÷ 0.5 ≈ 1.4 typical wanderings from zero. Values that size or larger turn up by accident often; the deck's number, on its own five rows, is not remarkable.
  2. At n = 100. The typical size is 1/√99 ≈ 0.10. The same 0.71 is now 0.71 ÷ 0.10 ≈ 7 typical wanderings from zero, which accident essentially never produces.
  3. The comparison. The identical coefficient is unremarkable at n = 5 and decisive at n = 100. A correlation is remarkable only relative to the sample it came from, which is why the coefficient and the sample size are one piece of information, never two.
  4. The assumptions, named. The rule of thumb assumes the true correlation is zero and roughly bell-shaped data; it is an approximation used for sizing surprise, not a probability statement. Both the number and its caveats travel together.

Sanity check. The wander size must shrink as n grows: 0.5 at five points and 0.1 at a hundred, a factor of five from a tenfold sample, which is the same square-root law the first half of this set was about.

Problem 7genuinely hard

Construct a dataset of five points where Y is exactly determined by X, with no noise at all, and yet Pearson's r comes out as exactly zero. Compute r to prove it, draw the picture in your head, and write the one-sentence moral about what r measures.

Hint

Let the points sit on a parabola: X = −2, −1, 0, 1, 2 and Y = X². Centre both columns and watch the products cancel.

Show the worked solution
  1. The data. X = −2, −1, 0, 1, 2 and Y = X² = 4, 1, 0, 1, 4. Every Y is a deterministic function of its X: zero noise, perfect dependence.
  2. Centre. x̄ = 0 and ȳ = (4 + 1 + 0 + 1 + 4) ÷ 5 = 2. The centred columns are X: −2, −1, 0, 1, 2 and Y: 2, −1, −2, −1, 2.
  3. Multiply and sum. The products are −4, 1, 0, −1, 4, and the sum is 0. The users above average in X are below average in Y as often as not, because the parabola turns.
  4. Rescale. r = 0 ÷ (anything positive) = 0 exactly.
  5. The moral. r measures straight-line co-movement only. A perfect relationship that bends earns r near zero, so a small r is a statement about lines, never about dependence. Before trusting any r, look at the scatter; before reporting one, say what shape it assumes.

Sanity check. The centred products must sum to zero by symmetry, since each positive product on the right arm of the parabola has an equal negative partner on the left; the sum 0 is forced, not lucky.

Traps in this concept

  • Expecting linear returns on sample size. Half the error costs four times the sample, every time. Budgets and promises should be quoted in squares.
  • Using more data to fix a confounder. Growth, seasonality and paydays move whole columns together; a bigger sample re-measures the confounder with more precision and changes nothing else.
  • Reading |r| as strength of relationship. It is strength of straight-line co-movement in this sample. Problem 7's parabola is the standing counterexample.
  • Trusting a striking r from a tiny sample. At five points the typical accidental r is already about 0.5 in size. The coefficient and the n are one fact, not two.
  • Letting a correlation carry a causal verb. "Email drives revenue" is a claim about an intervention; r is a claim about co-movement. The bridge between them is an experiment, and Problem 5 is how to ask for one.
Your teacher. Pick one correlation in a report you receive. Ask three questions of it: what is n, what does the scatter look like, and what else moves both columns? If the report cannot answer, treat the number as a nomination for study, not as a finding.
