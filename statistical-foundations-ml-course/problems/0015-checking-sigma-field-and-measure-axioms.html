Check every axiom, not just the convenient one

foundation 40 min Eight problems on paper. Candidate sigma-fields and candidate measures where the easy axiom passes and a different one fails.

The one-minute version

  • A sigma-field F on Ω must contain Ω, be closed under complements, and be closed under countable unions. All three, every member.
  • A probability measure P: F → [0, 1] must satisfy P(∅) = 0, P(Ω) = 1, and add over disjoint sequences. All three, every sequence.
  • The tutorial's trap is selective checking: the axiom you verified is rarely the axiom that fails. A candidate is valid only after every axiom has been tested.
  • On a finite sample space, sigma-fields are exactly the ways of grouping outcomes into blocks, which makes exhaustive checking concrete.

The concept in one paragraph

A probability space is a triple (Ω, F, P): the sample space Ω of all outcomes, a sigma-field F which is the collection of subsets of Ω that count as events, and a probability measure P assigning each event its number. The definition is deliberately demanding. F must contain Ω itself, must contain the complement of every one of its members, and must contain the union of every countable sequence of its members. P must map into [0, 1], must give ∅ the value 0 and Ω the value 1, and must add across every countable sequence of disjoint events. The point of this set is the habit: verifying one axiom, or two, or even all three on a convenient example, proves nothing about the candidate in front of you until each axiom has been tested against it.

The problems

Problem 1warm-up

Let Ω = {H, T} and let F1 = {∅, {H}, {T}, {H, T}}, the collection of all four subsets.

Verify all three sigma-field axioms for F1, writing out every complement and every union the finite space allows.

Show the worked solution
  1. Gate 1. {H, T} ∈ F1. Passes.
  2. Gate 2, every member. ∅c = {H, T} ∈ F1. {H}c = {T} ∈ F1. {T}c = {H} ∈ F1. {H, T}c = ∅ ∈ F1. All four complements are present. Passes.
  3. Gate 3, every union. Any union involving ∅ returns the other set, which is in F1. {H} ∪ {T} = {H, T} ∈ F1. Any union involving {H, T} is {H, T} ∈ F1. Every union of members is a member, and countable unions of a finite collection reduce to finite ones. Passes.
  4. Verdict. F1 is a sigma-field: it is the power set of Ω, which is always a sigma-field.

Sanity check. On a two-point space there are only 4 subsets and 16 possible collections; the full power set is the largest collection anyone will ever propose here, and it must pass.

Problem 2warm-up

Let F2 = {∅, {H}, {H, T}} on the same Ω = {H, T}. Check all three sigma-field axioms, and state precisely which one fails and why. This is the tutorial's trap in miniature.

Show the worked solution
  1. Gate 1. {H, T} ∈ F2. Passes.
  2. Gate 2. ∅c = {H, T} ∈ F2. {H, T}c = ∅ ∈ F2. But {H}c = {T}, and {T} ∉ F2, which holds only three sets. Fails.
  3. Gate 3, for completeness. The unions of members: ∅ ∪ anything is that thing; {H} ∪ {H, T} = {H, T}; all results are in F2. Passes, which is exactly what makes the failure easy to miss.
  4. Verdict. F2 is not a sigma-field. The complement axiom fails, and the failure is visible only if that gate is actually tested.

Sanity check. A collection closed under complements must have an even number of non-trivial members paired with their complements: F2 holds the unpaired singleton {H}, which is the smell of the failure.

Problem 3steady

Let Ω = {1, 2, 3} and let F = {∅, {1}, {2, 3}, Ω}. Verify that F is a sigma-field by testing all three gates exhaustively. Then list every sigma-field on {1, 2, 3} and explain why there are exactly five.

Hint

For the count: once a sigma-field contains {1}, complement closure forces {2, 3} in, and union closure forces all four unions of the pair. Every sigma-field is generated by such blocks.

Show the worked solution
  1. Gate 1. Ω = {1, 2, 3} ∈ F. Passes.
  2. Gate 2. ∅c = Ω ∈ F. {1}c = {2, 3} ∈ F. {2, 3}c = {1} ∈ F. Ωc = ∅ ∈ F. Passes.
  3. Gate 3. Unions of the four members, pairwise: ∅ ∪ X = X; {1} ∪ {2, 3} = Ω ∈ F; {1} ∪ Ω = Ω; {2, 3} ∪ Ω = Ω. Every union lands in F, and longer unions reduce to these. Passes. F is a sigma-field.
  4. The five. Group the points into blocks, and let the sigma-field be all unions of blocks: one block, {123}: F = {∅, Ω}. Blocks {1}{23}: F = {∅, {1}, {2, 3}, Ω}. Blocks {2}{13}: F = {∅, {2}, {1, 3}, Ω}. Blocks {3}{12}: F = {∅, {3}, {1, 2}, Ω}. Blocks {1}{2}{3}: the full power set of 8 subsets. Five sigma-fields in total.
  5. Why exactly five. Every grouping gives a sigma-field, and conversely every sigma-field on a finite space is the set of all unions of its minimal non-empty members, which partition Ω. The groupings of 3 points are exactly 5, so the sigma-fields are exactly 5.

Sanity check. The full power set of 8 subsets and the trivial {∅, Ω} are the two extremes, and the three mixed ones each hold exactly 4 sets: 8, 4, 4, 4, 2 members respectively, all divisors-shaped by the block structure.

Problem 4steady

Let Ω = {1, 2, 3} with F its power set. A candidate measure is proposed by P({1}) = 0.5, P({2}) = 0.4, P({3}) = 0.2, extended to every event by adding outcome values.

Check all three measure axioms, in order, and state which fails and how you noticed.

Show the worked solution
  1. Axiom 1: P(∅) = 0. The empty sum is 0 by construction. Passes.
  2. Axiom 2: P(Ω) = 1. P(Ω) = 0.5 + 0.4 + 0.2 = 1.1 ≠ 1. Fails.
  3. Axiom 3, for completeness. Additivity over disjoint events holds automatically for any additive extension, so it is not the problem here.
  4. Verdict. Not a probability measure: the outcomes claim 110 percent of the probability. The repair is to scale every value by 1/1.1, giving 5/11, 4/11, 2/11, which does satisfy all three axioms.

Sanity check. The single quickest test on any candidate with named outcome weights is the sum: if it is not exactly 1, stop there.

Problem 5steady

Let Ω = {1, 2} with F its power set. A candidate measure is proposed by P(∅) = 0, P({1}) = 0.3, P({2}) = 0.3, P(Ω) = 1.

Check all three measure axioms, state which fails, and explain why this failure is more dangerous than Problem 4's.

Show the worked solution
  1. Axiom 1. P(∅) = 0, as proposed. Passes.
  2. Axiom 2. P(Ω) = 1, as proposed. Passes.
  3. Axiom 3. {1} and {2} are disjoint with union Ω, so additivity demands P(Ω) = P({1}) + P({2}) = 0.6. The proposal says 1. Fails.
  4. Why more dangerous. Problems 4's failure trips the two-second check "do the weights sum to 1". This one passes that check: both named values look innocent, and the contradiction only appears when a disjoint union is actually tested. The trap rewards exactly the reader who stops after the convenient axioms.

Sanity check. On a finite space with outcome values named, consistency means every event's value equals the sum of its outcomes: here Ω would need value 0.6 to be consistent, not 1.

Problem 6steady

The lecture's coin space: Ω = {H, T}, F = {∅, {H, T}, {H}, {T}}, and P is proposed by P(∅) = 0, P({H, T}) = 1, P({H}) = p, P({T}) = 1 - p.

Verify all three measure axioms for an arbitrary p in [0, 1]. Then state what goes wrong for p = 1.2 and for p = -0.4, and explain why p = 1 and p = 0 are still perfectly valid.

Show the worked solution
  1. Axiom 1. P(∅) = 0 by proposal. Passes for every p.
  2. Axiom 2. P(Ω) = P({H, T}) = 1 by proposal. Passes for every p.
  3. Axiom 3. The only disjoint pair with non-empty union is {H} and {T}: P({H} ∪ {T}) = P({H, T}) = 1, and P({H}) + P({T}) = p + (1 - p) = 1. Equal, for every p. Passes.
  4. Range requirement. The measure must map into [0, 1]: P({H}) = p needs 0 ≤ p ≤ 1, and P({T}) = 1 - p needs the same. At p = 1.2 the value 1.2 lies outside the range, and at p = -0.4 the value -0.4 does. Both proposals are invalid, each for a different half of the range condition.
  5. The extremes. At p = 1 the coin always shows heads and P({T}) = 0; at p = 0 it always shows tails. Zero-probability events are allowed, so both extremes are valid measures. Certainty is not a violation.

Sanity check. Additivity forced p + (1 - p) = 1 with no condition on p: the entire constraint on p comes from the range [0, 1], which is why the axiom list says P: F → [0, 1] rather than P: F → R.

Problem 7hard

On the countable sample space Ω = {1, 2, 3, ...}, three candidates propose outcome weights:

(a) p(i) = 2-i.   (b) p(i) = 1/(i(i + 1)).   (c) p(i) = c/i2 for a constant c to choose.

For each: decide whether it can define a probability measure via P(S) = Σi∈S p(i), and justify the total. For (b), use the telescoping identity 1/(i(i + 1)) = 1/i - 1/(i + 1). For (c), use the given fact Σi≥1 1/i2 = π2/6.

Show the worked solution
  1. What must hold. The weights are non-negative in all three candidates. The one question is the total: axiom 2 needs Σi≥1 p(i) = 1 exactly.
  2. Candidate (a). Σi≥1 2-i is the geometric series with ratio 1/2, summing to (1/2)/(1 - 1/2) = 1. Valid.
  3. Candidate (b). The partial sum telescopes: Σi=1..n (1/i - 1/(i + 1)) = 1 - 1/(n + 1) → 1. Valid.
  4. Candidate (c). The total is c × π2/6, so axiom 2 forces c = 6/π2 ≈ 0.608. With that choice the weights are non-negative and total exactly 1. Valid, and the choice is forced: no other c works.
  5. The measure itself. For any valid candidate, P(S) = Σi∈S p(i) is non-negative, gives P(Ω) = 1, and is additive over disjoint sets because the series can be re-indexed and merged: a countable union of disjoint events is a countable disjoint union of outcomes. All three axioms hold.

Sanity check. Candidate (b)'s first three weights are 1/2, 1/6, 1/12, summing to 3/4 with the same halving-gap behaviour as (a); both series must land on exactly 1, and both do, by two different mechanisms.

Problem 8hard

The lecture's discrete construction in general: Ω is finite or countably infinite, and numbers pi ≥ 0 with Σi pi = 1 are given. Define P(S) = Σi∈S pi for every subset S of Ω.

Prove that this P is a valid probability measure on the power set of Ω, checking all three axioms. Then apply it: with the pi = 2-i weights, compute P(even outcomes) and P(outcomes divisible by 3).

Hint

The additivity check is a statement about re-indexing a doubly infinite sum of non-negative terms. Non-negativity is what lets you rearrange freely.

Show the worked solution
  1. Axiom 1. P(∅) is the empty sum, which is 0. Holds.
  2. Axiom 2. P(Ω) = Σi∈Ω pi = 1, which is the hypothesis of the construction. Holds.
  3. Axiom 3. Let A1, A2, ... be disjoint subsets of Ω. Every outcome i lies in at most one of them, so grouping the sum by which Ak contains i re-indexes the same non-negative terms without changing the total: Σi∈∪k A_k pi = Σk Σi∈A_k pi, which says P(∪k Ak) = Σk P(Ak). Holds.
  4. The event space. The argument never used finiteness of the collection, so every subset of Ω is an event: the power set is a sigma-field on a countable space, and P lives on all of it.
  5. Apply to even outcomes. P(even) = Σk≥1 2-2k = Σk≥1 1/4k = (1/4)/(1 - 1/4) = 1/3.
  6. Apply to multiples of 3. P(divisible by 3) = Σk≥1 2-3k = Σk≥1 1/8k = (1/8)/(1 - 1/8) = 1/7.

Sanity check. Both answers are positive and comfortably below 1, and the even outcomes being twice as likely in total as the multiples of 3 matches the intuition that divisibility by 2 is a weaker constraint than divisibility by 3.

Traps in this concept

  • Checking the axioms you already passed. Once gate 1 passes, the remaining work is gates 2 and 3, not gate 1 again. Problem 2 is the shape of the trap: the failing gate is the one nobody looked at.
  • Testing unions on one example and generalising. Gate 3 is a "for every sequence" statement. On a finite collection you can enumerate; beyond that you must argue structurally, as Problem 8 does.
  • Reading P: F → [0, 1] as decoration. The range is part of the definition: Problem 6's p = 1.2 fails on range even though all three named axioms hold.
  • Forgetting that additivity needs disjointness. P(A ∪ B) = P(A) + P(B) is claimed only when A ∩ B = ∅. Problem 5's candidate is inconsistent precisely because Ω is the disjoint union of {1} and {2}.
  • Assuming the power set is the only choice. On finite and countable spaces it is available and usual, but Problem 3 shows smaller sigma-fields are legal too: an event space is whatever passes the three gates, not whatever is biggest.
Your teacher. The exit test is Problems 2 and 5 together: in each, name the failing axiom before naming anything else. If your first sentence in an axiom check is not the name of a gate, you are describing the candidate rather than testing it.
