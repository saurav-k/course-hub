Lecture 5 · Part 2 of 10 · the two-class board

There are two ways for a batch to be useless and many ways for it to be fine, so price the two

10 min the complement, cleanly The same hundred examples, now split into two classes, and the question a training loop actually cares about.

The one-minute version

  • Of the 100 examples, 60 belong to class A and 40 to class B. On every draw, Pr(A) = 60/100 = 0.6 and Pr(B) = 40/100 = 0.4.
  • The event we want, at least one example from each class, is a large and awkward set. Its complement is two clean cases: all five from A, or all five from B.
  • Those two cases cannot both happen, so their probabilities simply add: (0.6)5 + (0.4)5. The class notes write the same thing as (3/5)5 + (2/5)5.
  • Subtract from one: Pr(both classes represented) = 1 − (0.6)5 − (0.4)5.
  • The direct route, adding up the good batches instead of subtracting the bad ones, was attempted in the room and left open. It needs a tool this lecture only reaches on Part 5.

1. The question, and why it is the practical one

The dataset now carries labels. Sixty of the hundred examples are class A and the other forty are class B, and the mini-batch is built exactly as in Part 1: five draws, independent, uniform, with replacement.

The problem. What is the probability that the mini-batch contains at least one example from each of the two classes?

Because the draws are independent and each one sees the whole dataset, the class of a single draw is a simple thing: it is A with probability 0.6 and B with probability 0.4, every time, whatever the other draws did.

Pr(A) = 60/100 = 0.6   and   Pr(B) = 40/100 = 0.4 Pr(A) is the probability that one draw lands on a class-A example, which is the share of the dataset that carries that label. The two numbers add to one because every example carries exactly one of the two labels. Neither number changes from draw to draw, because the example goes back and the dataset is the same object each time.

2. Why the complement is the right move here

Try the question head on for a moment. A batch containing both classes could be four A's and one B, or three A's and two B's, or one A and four B's, and each of those descriptions covers many different batches. Adding all of that up is possible, and it is done at the end of this lecture, but it is not the short road.

Now look at the failure. A batch fails to contain both classes only if it contains just one of them, which means all five draws landed on the same class. There are exactly two ways for that to happen, and each is a single product.

Two facts license the move, and both are worth naming.

  1. The complement rule. Lecture 3, Part 1 derived P(E) = 1 − P(Ec) from the axioms. E is the event that both classes appear, and Ec, read "E complement", is the event that they do not. Every batch is in exactly one of the two, so their probabilities add to one.
  2. The two bad cases are disjoint. A batch of five cannot be all A and all B at the same time, because that would need at least one draw to carry both labels. Disjoint events add with no correction term, so there is no inclusion-exclusion overlap to subtract here.

3. Pricing the two bad cases

Each bad case is five independent draws all landing on the same side, so independence multiplies five identical factors.

  1. All five from A. Each draw is A with probability 0.6, and the draws are independent, so the probability of five in a row is (0.6)5. The class notes also write this as (3/5)5, which is the same number in fractional form because 60/100 reduces to 3/5.
  2. All five from B. The same argument with 0.4 in place of 0.6, giving (0.4)5, written as (2/5)5 on the class notes.
  3. Add them. Disjoint, so Pr(only one class is represented) = (0.6)5 + (0.4)5.
  4. Take the complement. Pr(both classes are represented) = 1 − (0.6)5 − (0.4)5.
Pr(both classes represented) = 1 − (0.6)5 − (0.4)5 The 1 is the whole probability of the sample space, from the second axiom. The two subtracted terms are the two disjoint ways the batch can hold a single class: (0.6)5 is five class-A draws in a row and (0.4)5 is five class-B draws in a row. The exponent is 5, the batch size, and it appears as an exponent rather than a multiplier because independent events multiply.
This course's arithmeticThe lecture stops at the expression, so the decimal below is this course's own and carries no key-number mark. (0.6)5 = 0.07776 and (0.4)5 = 0.01024, so the two bad cases together come to 0.088 and the answer is 0.912 exactly. The fractional form the class notes use makes the exactness visible: (3/5)5 + (2/5)5 = 243/3125 + 32/3125 = 11/125, so the answer is 114/125. About nine mini-batches in ten carry both classes, and roughly one in eleven does not.

4. The direct route, which the room started and did not finish

The lecturer also tried the question from the front, adding up the good batches rather than subtracting the bad ones, and left it there. It is worth seeing exactly where that road runs out, because the rest of this lecture is the tool that finishes it.

A batch holding both classes has some number of class-A draws between one and four. Splitting on that number gives four disjoint cases, which is legal and is the same partition move as the law of total probability. The obstacle arrives immediately after.

  1. Fix the number of class-A draws, call it k, with k anywhere from 1 to 4. Every batch in that case has k draws of class A and 5 − k of class B.
  2. Price one such batch. By independence it is (0.6)k(0.4)5−k, whatever order the A's and B's arrive in, because multiplication does not care about order.
  3. Count how many such batches there are. This is the step with no tool yet. It asks how many ways k slots out of five can be the class-A ones, and that count is exactly what Part 5 supplies.
  4. Add the four cases. Only once step 3 has an answer.
Left open in the room, on purposeThe direct route was attempted in the class and not finished, and the lecturer moved on to the complement. That is the right call at that moment: the missing piece is the count in step 3, and the lecture has not yet reached the shape that supplies it. This course carries the road as open rather than quietly finishing it here, and closes it on Part 10 once the binomial is on the board, where the two routes are checked against each other. The four-case breakdown above is this course's own reading of where the road stops; the notes show the attempt, not this analysis.

5. A warning you will need in four pages' time

Describing a batch by its class pattern rather than by its example indices is a tempting simplification. There are only two labels and five slots, so there are 25 = 32 patterns, and exactly two of them are pure. It is very tempting to answer 2 out of 32.

That answer is wrong, and it is wrong for a reason worth meeting early: the 32 patterns do not carry equal probability. Class A is more common than class B, so a pattern with more A's in it is more likely than one with fewer.

The lecture's own route sidesteps this entirely by never counting patterns: it prices the two pure ones directly and subtracts. The pattern space becomes usable only when a count is paired with the weight each counted thing carries, which is exactly the repair on Part 7.

6. Check yourself

Why may the two bad cases simply be added rather than combined with inclusion-exclusion?
A batch of five cannot be entirely class A and entirely class B at once, so the intersection is empty and the addition rule applies with no correction term. Their probabilities are not equal, 0.07776 against 0.01024, and equality would not license adding anyway. Independence is a different relation entirely, and two disjoint events with positive probability are in fact never independent. And the two are not complements of each other: their union is the complement of the event we want, which is a third thing.
Why can the answer not be read off as 2 pure patterns out of 32 class patterns?
Dividing a count by a count needs every outcome to weigh the same, and with a 60 to 40 split a pattern with more A's is more likely than one with fewer, so the 32 patterns cannot be divided over. Describing a batch by its pattern rather than by its example indices is perfectly legal in itself, and would be fine if the classes were 50 to 50. Replacement is what makes the draws independent and identically weighted, which helps rather than hinders. And the two pure patterns are different patterns with no overlap at all.
Your teacher. Build the habit of asking, before anything else, which side of this question has fewer shapes? Here the failure has two shapes and the success has four, so the complement wins easily. On the quality-check problem two pages from now, the failure has exactly one shape and the success has twenty, so it wins by even more. The complement is not a trick reserved for hard problems; it is the first thing to try whenever the words "at least" appear anywhere in the question.
