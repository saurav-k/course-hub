Lecture 5 · Part 1 of 10 · the mini-batch board

A mini-batch is drawn with replacement, so "all five different" is a thing that has to be priced

9 min the first problem Lecture 4's with-replacement box, put straight to work on the first thing a training loop actually does.

The one-minute version

  • A training set holds 100 examples. A mini-batch of 5 is built by drawing examples independently and uniformly at random, with replacement, so the same example may be selected more than once.
  • That single phrase settles the sample space. It is case 1 of the four boxes: ordered, with replacement, giving 1005 equally likely outcomes.
  • The lecture prices "all five distinct" as a falling product: 1 · (99/100) · (98/100) · (97/100) · (96/100), and writes the same thing as (100 · 99 · 98 · 97 · 96) / 1005.
  • Every factor is a conditional probability, and the numerators fall by one each time because each new draw has one more example it is not allowed to match.

1. What the problem actually says

The board states it in machine-learning language, and every clause of it is load-bearing, so read it once slowly.

The problem. A training dataset consists of 100 examples. A mini-batch of size 5 is constructed by sampling examples independently and uniformly at random from the dataset with replacement. Thus, the same training example may be selected more than once. What is the probability that all five examples in the mini-batch are distinct?

Three phrases do all the work.

  • Uniformly at random means every one of the hundred examples is as likely to be picked as any other, on every draw. Nothing is weighted, nothing is skipped.
  • Independently means what came out on an earlier draw does not change the odds on a later one. The dataset has no memory.
  • With replacement means the example goes back before the next draw. The pool is a hundred every single time, which is exactly why a repeat is possible at all.

If any one of those three were dropped the problem would be a different problem with a different answer. A sampler that removed each chosen example would make "all five distinct" certain and the question empty.

2. The sample space, and why its outcomes weigh the same

Before any counting, name one outcome. Here an outcome is the ordered list of the five examples that came out, first draw to fifth. Write it as a five-slot sequence, one example index in each slot.

Each slot can hold any of the hundred examples, and the slots do not constrain each other, so the basic counting rule multiplies five hundreds together.

|Ω| = 100 × 100 × 100 × 100 × 100 = 1005 Ω, omega, is the sample space: every ordered five-slot list the sampler could produce. The vertical bars mean how many, so |Ω| is a count and not a probability. The exponent is 5, the number of draws, and the base is 100, the number of examples the pool offers on every draw.

Are those outcomes equally likely? Yes, and it is worth saying why rather than assuming it, because Part 6 is about a problem in this same lecture where the answer is no. Each draw picks uniformly, so each slot's hundred values are equally likely; the draws are independent, so the probability of a particular five-slot list is the product of five equal factors, (1/100)5, whatever the list is. Every outcome, the same weight. Part 8 of Lecture 4 is therefore licensed, and a probability here really is a ratio of two counts.

3. Counting the batches with no repeat

Now count the favourable outcomes: the five-slot lists in which no example appears twice. Build one slot at a time.

  1. Slot 1. Anything at all. 100 ways.
  2. Slot 2. Anything except whatever went into slot 1. 99 ways.
  3. Slot 3. Anything except the two already used. 98 ways.
  4. Slot 4. Anything except the three already used. 97 ways.
  5. Slot 5. Anything except the four already used. 96 ways.
  6. Multiply. |A| = 100 · 99 · 98 · 97 · 96.

That count is Lecture 4's case 2, ordered without replacement, appearing inside a case 1 sample space. The sampling really is with replacement; it is the event that forbids repeats, not the mechanism. Divide the two counts and the probability follows.

Pr(all 5 distinct) = (100 · 99 · 98 · 97 · 96) / 1005 The numerator counts the ordered lists with no repeat, and the denominator counts every ordered list the sampler can produce. Both are counts of the same kind of object, an ordered list of five, which is what makes the division meaningful. Splitting the denominator into five separate hundreds and pairing them off against the numerator gives the other form the lecture writes.

4. The same answer, read as five conditional probabilities

The handout writes the answer in the sequential form first, and the class notes write the leading factor as 100/100 rather than as 1, which is the more honest way round because it shows the pattern.

Pr(all 5 distinct) = (100/100) · (99/100) · (98/100) · (97/100) · (96/100) Read each factor as a conditional probability: given that the draws so far were all different, what is the chance this draw is different too? The denominator is always 100, because with replacement the pool never shrinks. The numerator is how many of those hundred examples are still unused, which is 100 minus the number already drawn. The first factor is 100/100 = 1 because the first draw cannot repeat anything.

This is the multiplication rule from Lecture 3 applied four times over. The two forms are the same number, and the lecture writes both because they suit different follow-up questions: the product form generalises to any batch size by adding a factor, and the ratio form makes the counting argument visible.

This course's arithmeticNeither the handout nor the class notes multiplies this out. Doing so is straightforward and the answer is worth having, so here it is under this course's own name rather than the lecturer's. The numerator is 100 · 99 · 98 · 97 · 96 = 9,034,502,400 and the denominator is 1005 = 10,000,000,000, so Pr(all 5 distinct) = 0.90345024, about 90.3 percent. The complement, at least one example repeating in a batch of five, is about 9.7 percent: roughly one mini-batch in ten already contains a duplicate. No figure in this callout carries a key-number mark, because none of them is on the board.

5. What happens as the batch grows

The product form makes the next question cheap. A batch of size n multiplies n factors, and each new factor is smaller than the last, so the probability of a clean batch falls away faster and faster. 6. Check yourself

Which of Lecture 4's four boxes is the mini-batch sample space?
The problem says with replacement in so many words, and the outcome is the sequence of draws the loader produced, so both switches point at case 1 and the space has 100 to the fifth outcomes. Case 2 would describe a sampler that removes each chosen example, under which the answer to this question would simply be 1. Case 3 is a subset of twenty distinct items, which is the next problem in this lecture and not this one. And case 4 would throw the order away and count multisets, which are not equally likely here, so the counting formula would not even be licensed.
In the falling product, why is the second factor 99/100 rather than 99/99?
With replacement the denominator is 100 on every single draw, and only the numerator falls, because the second draw still chooses from all hundred examples but only 99 of them keep the batch distinct. The first option describes sampling without replacement, which is a different experiment and would give 99/99 = 1. The order has not been discarded: an outcome here is an ordered list, which is what makes the sample space 100 to the fifth. And the batch is emphatically not a set, since the whole point of the question is that an example can appear in it twice.
Your teacher. The sentence to internalise is "the denominator does not move". Almost everybody writing this product for the first time lets both numbers fall, gets 100/100 · 99/99 · 98/98 and reaches the answer 1, then stares at it. Say out loud what each half of each fraction counts before you write the next factor: the top is how many examples keep the batch clean, the bottom is how many the sampler is choosing from. Only one of those two facts changes when a draw is made with replacement.
