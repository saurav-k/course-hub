Lecture 6 · Part 5 of 14 · the CDF theorem

Four properties, proved once, that every CDF in the rest of the course must obey

13 min frontier The only theorem in this lecture with proofs attached, and the notes work all four of them.

The one-minute version

  • Monotone. If x ≤ y then FX(x) ≤ FX(y). The staircase never goes down.
  • Zero far left. FX(x) → 0 as x → −∞.
  • One far right. FX(x) → 1 as x → ∞.
  • Right continuous. FX(x + ε) → FX(x) as ε shrinks to zero from above, at every x. This is the one that decides where the filled dot goes at a jump.
  • The first proof is one line of set containment. The other three all run the same argument twice over: build a shrinking family of events, take the intersection, and apply the continuity of probability.

1. Property 1: the staircase never goes down

The notes state it as: if x ≤ y then FX(x) ≤ FX(y). The proof is two lines and it is entirely a statement about sets.

  1. Write both events out. FX(x) prices the set {ω : X(ω) ≤ x} and FX(y) prices the set {ω : X(ω) ≤ y}.
  2. Notice the containment. Any outcome whose value is at most x has a value at most y as well, because x is not bigger than y. So {ω : X(ω) ≤ x} ⊆ {ω : X(ω) ≤ y}. The notes write exactly this line.
  3. Price both sides. A subset never has more probability than the set containing it, which is the containment rule proved in Lecture 3, Part 1. Applying it gives P(the smaller set) ≤ P(the larger set), which is FX(x) ≤ FX(y).

That is the whole proof, and it is worth noticing how little it used. Nothing about discreteness, nothing about the support, nothing about the shape. Every CDF of every random variable is monotone for this reason.

2. The tool the other three proofs need

Properties 2, 3 and 4 all invoke something the notes name in the margin as continuity of probability. This course has not built it yet, so it is built here before it is used.

This course's bridgeThe notes cite continuity of probability by name and do not prove it, which is normal: it belongs to the axioms lecture rather than to this one. This course has proved countable additivity's consequences in Lecture 3, Part 1 but not this result, so the four steps below supply it. They are this course's own derivation from the axioms this course already has, not something the notes state, and nothing later on this page depends on the derivation being read.
If A1 ⊇ A2 ⊇ A3 ⊇ ... and A = ∩n≥1 An, then P(An) → P(A) A1, A2, ... is an endless list of events, each one contained in the one before it, so the family only ever shrinks. ∩ is intersection, so A is the set of outcomes that survive in every one of them. The claim is that the probabilities of the shrinking sets close in on the probability of what is left.
  1. Slice the biggest set into disjoint rings. An outcome in A1 either survives for ever, and so lies in A, or drops out at some first step, and so lies in exactly one of the rings Ak − Ak+1. Those pieces are disjoint and they cover A1.
  2. Price the slices. Countable additivity from Lecture 2, Part 5 gives P(A1) = P(A) + ∑k≥1 P(Ak − Ak+1). That series has a finite total, at most 1, so its tail must shrink to zero.
  3. Do the same for the n-th set. The same slicing applied to An gives P(An) = P(A) + ∑k≥n P(Ak − Ak+1), which is P(A) plus exactly that tail.
  4. Let n grow. The tail goes to zero by step 2, so P(An) → P(A).

3. Properties 2 and 3: the two ends

The notes prove the left-hand end in full and say the right-hand end follows similarly. Here is the left-hand argument as they write it.

  1. Reduce the limit to a sequence. It suffices, the notes say, to show that for any strictly decreasing sequence {xn} with xn → −∞, the values FX(xn) tend to zero. This is the standard way of turning a limit over a continuous variable into a limit over a list.
  2. Name the events. Put An = {ω : X(ω) ≤ xn}, so that P(An) = FX(xn) by the definition of the CDF.
  3. Check that the family shrinks. The thresholds are decreasing, so An+1 ⊆ An. The notes write this as "An is a monotonically diminishing sequence of sets".
  4. Take the intersection. An outcome in every An would have X(ω) below every one of the thresholds, and those run off to minus infinity. No real number does that, so the intersection is empty.
  5. Apply the tool. Continuity of probability gives FX(xn) = P(An) → P(∅) = 0, using the fact from Lecture 3, Part 1 that the empty event has probability zero.

The right-hand end runs the same way with the arrows reversed: take an increasing sequence of thresholds running off to plus infinity, the events grow rather than shrink, their union is the whole sample space, and the limit is P(Ω) = 1. The notes compress this to the single word "similarly", and this course does not expand it further than the notes do.

The notes say "similarly" and stopProperty 3 is stated in the source as one line: similarly, the limit as x goes to infinity is 1. No proof is written. The sentence above about increasing sequences and unions is this course's paraphrase of what "similarly" points at, and it is deliberately kept to one sentence rather than worked out, because working it out would be importing a proof the source chose not to give.

4. Property 4: right continuity, and why the dot is filled

The fourth property is the subtle one, and it is the reason the staircase in Part 4 has a filled dot on the upper tread at every jump. The notes state it as

limε ↓ 0 FX(x + ε) = FX(x), for all x ε is a small positive number and the downward arrow means it shrinks towards zero while staying positive. So the threshold is being nudged in from above x and never from below. The claim is that the value the CDF approaches from that side is the value it actually takes at x.

The proof is the same machine as before, and the only change is what the intersection turns out to be.

  1. Fix a point and a sequence. Take any real x, and let {xn} be a strictly decreasing sequence with xn → x. Every threshold is strictly to the right of x and they close in on it.
  2. Name the events. An = {ω : X(ω) ≤ xn} and P(An) = FX(xn), exactly as before.
  3. The family still shrinks. An+1 ⊆ An, because the thresholds are decreasing.
  4. Identify the intersection. This is the step that differs. An outcome lies in every An exactly when X(ω) ≤ xn for every n, and since the thresholds close in on x from above, that happens exactly when X(ω) ≤ x. So the intersection is {ω : X(ω) ≤ x}, which is not empty this time: it is the very event the CDF prices at x.
  5. Apply the tool. Continuity of probability gives FX(x) = P(∩ An) = lim P(An) = lim FX(xn). The notes close with the remark that this holds for any such sequence, which is what upgrades the sequence statement back into a statement about the limit.

Step 4 is where the whole asymmetry comes from. Approaching x from the right, the events close down onto "at most x" and the limit lands on the value. Approaching from the left they would close down onto "strictly less than x" instead, and if there is mass sitting exactly at x that is a different set with a smaller probability. The definition said ≤, and this is the price of that choice.

6. Check yourself

In the proof of property 2, why is the intersection of all the events empty?
The thresholds run off to minus infinity, and X of any outcome is a single real number, which must eventually be overtaken and left above some threshold, so no outcome survives the whole family. The sample space is not empty; it is the events cut out by extreme thresholds that end up so. Probability zero and emptiness are genuinely different, as Part 11 shows when every single point of a continuous variable gets probability zero without being impossible. And the events are nested rather than disjoint, which is precisely what lets the continuity result apply.
Which property is the reason the filled dot at a jump sits on the upper tread?
Property 4 says the limit from above equals the value at the point, and the limit from above is the upper tread, so the value at the point is the upper one. Monotonicity only forbids going down and is satisfied by a jump with the dot on either tread. The two limit properties constrain the far ends of the line and say nothing at all about which tread a dot belongs to in the middle of it.
Your teacher. Do not try to memorise the four properties. Instead learn the one argument that proves three of them, because it is the same argument each time and only the last step changes. Build a family of events that shrinks, ask what survives the intersection, and price that. When the thresholds run to minus infinity nothing survives, so the answer is zero. When the thresholds close in on a point from above, "at most that point" survives, so the answer is the value there. Two different questions, one machine, and you will meet the machine again the first time a limit theorem appears.
