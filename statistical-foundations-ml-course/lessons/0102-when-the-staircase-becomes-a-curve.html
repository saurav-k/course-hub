Lecture 7 · Part 6 of 13 · continuous random variables

Writing the CDF as an integral is what turns the staircase into a curve

working 11 min The lecture's own definition of a continuous random variable, delivered live, and the first thing that follows from it.

After this page

  • You can state the definition of a continuous random variable in the lecturer's own order, and say which clause is the assumption.
  • You can say why a continuous CDF cannot jump, and what a jump meant on the discrete staircase.
  • You can tell an asserted result from a proved one, and name the one this page asserts.

Before you start: the CDF as a running sum, for the staircase this page replaces, and reading probability off the staircase, for what a jump height meant.

The one-minute version

  • X is continuous when there exists a non-negative function whose running integral is the CDF. Nothing else is assumed.
  • That function is the probability density function. The definition names the density before it names anything about continuity.
  • The first implication: because the CDF is an integral, it is continuous and differentiable almost everywhere, so it can never jump.
  • Lecture 6's discrete CDF jumped, and the height of each jump was a PMF value. Remove the jumps and that reading route is gone.
  • The cost: the phrase "almost everywhere" is stated and not proved, and this page says so rather than smoothing it.

1. The definition, in the order the lecturer gave it

The board went up in one line, and the order of the clauses is the teaching. The lecturer wrote "if there exists" first, paused when a student asked whether he had said non-negative, and then wrote the whole condition out.

X is continuous if ∃ fX : R → [0, ∞) such that P(X ≤ x) = FX(x) = ∫−∞x fX(z) dz, for all x in R Read as: ∃ is the backwards E for "there exists", which the lecturer named out loud as he wrote it. X is the random variable. fX is a candidate function that takes any real number as input and returns a value in [0, ∞), so it is never negative. z is the dummy variable being integrated over and exists only inside the integral. x is the threshold the question is asked at. FX(x) is the CDF of X, the probability that X lands at or below x, defined exactly as it was for discrete variables. The line says: if some such fX can be found, X is called continuous and fX is called its probability density function.

Two things about the shape of that sentence. The load is carried by "there exists": the definition asks you to find a function, and says nothing about X being smooth, spread out, or unbounded. And the word "continuous" appears nowhere on the right-hand side. It is the name given to a variable that passes the test, not a property stated in it.

The question a student askedNon-negative describes what fX returns, not what it is fed. A student asked whether the integral could then start at 0 rather than at minus infinity, and the answer was no: z is free to be negative, and it is fX(z) that never is. The lecturer's reply was "Z can be negative, but fX of Z will always be non-negative."

2. One instance, worked before the general claim

The definition is a test, so run it once on the simplest candidate the lecture will later name. Take the function that is 1 on the interval from 0 to 1 and 0 everywhere else, and ask what CDF it produces.

  1. Check the shape of the candidate. The function returns 1 or 0, and neither is negative, so it maps the real line into [0, ∞) as the definition requires.
  2. Integrate below the interval. For x < 0, every z from −∞ to x has f(z) = 0, so F(x) = 0.
  3. Integrate inside the interval. For 0 ≤ x ≤ 1, the integral collects a rectangle of height 1 and width x, so F(x) = x.
  4. Integrate above the interval. For x > 1, the rectangle stops growing at width 1, so F(x) = 1.
  5. Read the result. F is flat at 0, then a straight ramp, then flat at 1. It rises without a single vertical step, which is implication 1 arriving in a worked case before it is stated in general.

3. The first implication: the CDF can never jump

The lecturer drew the consequence immediately. Because FX is written as an integral, it is itself continuous, and also differentiable almost everywhere. His reason was mechanical rather than technical: change x by a tiny amount and the integral collects a tiny extra sliver of area, so the value of FX can only move a tiny amount with it. "That is just not allowed," he said of the jumps, "for a continuous random variable."

Set that against Lecture 6, Part 6, where the height of a jump at a point was the probability of that point. The two facts are the same fact seen twice. Where the staircase jumped, mass sat on a point; where the curve cannot jump, no mass can sit anywhere. Part 8 of this lecture collects that consequence in full.

4. What "almost everywhere" is doing there

The lecturer wrote "almost everywhere" in brackets and then said you could ignore it for now. It is worth one paragraph, because a reader who ignores it will later meet a density with corners and think something has gone wrong.

Take the uniform CDF from the worked example above: flat, then a straight ramp, then flat. At the two joins the slope on the left and the slope on the right disagree, so the derivative simply does not exist there. That is two points out of uncountably many, and by implication 4 each of them carries no probability at all. "Almost everywhere" is the phrase that lets a handful of such points be set aside without weakening the claim.

Asserted, not provedThat the CDF of a continuous random variable is differentiable almost everywhere is stated on the board and in the notes with no argument, and the lecturer said outright that you may ignore the qualifier for now. This course teaches it as stated and does not prove it. What can be checked from the definition alone is the weaker half: continuity of FX follows from its being an integral, and Hajek, Probability with Engineering Applications, Definition 3.2.1 and its footnote, reaches differentiability only by assuming the density is piecewise continuous. The corner argument above is this course's, not the lecture's.

Check yourself

Retrieval practice

Answer from memory before revealing.

What exactly does the definition of a continuous random variable require?
The definition is an existence claim about a density, and everything else is read off it. An interval range is typical of continuous variables but is not what is assumed, and a variable can have an interval range without any density existing. Continuity of the CDF is implication 1, so making it the definition swaps a conclusion for a premise. And equal likelihood is the uniform distribution, one continuous variable among many, not the general case.
Why can the CDF of a continuous random variable never jump?
An integral accumulates area, so a tiny change in the upper limit adds only a tiny sliver, and that is what forbids a step. The one-ceiling argument is wrong because a jump from 0.1 to 0.2 breaks no ceiling and is still forbidden here. Non-negativity gives monotonicity, which a staircase already satisfies, so it rules nothing out. And support size is a feature of the discrete case rather than the reason the integral is smooth.

Practice about 10 minutes, with paper

Practice 1working

A candidate density is proposed: f(z) = 2z for 0 ≤ z ≤ 1, and f(z) = 0 everywhere else.

Find the CDF it produces on the whole real line, and say where that CDF fails to be differentiable.

Hint

Do it in three pieces, exactly as the worked example did: below the interval, inside it, above it. The integral of 2z is z².

Show the worked solution
  1. Below the interval. For x < 0 the integrand is 0 all the way, so F(x) = 0.
  2. Inside the interval. For 0 ≤ x ≤ 1, F(x) = ∫ from 0 to x of 2z dz = x².
  3. Above the interval. For x > 1 nothing further is collected, so F(x) = 1² = 1.
  4. Find the corner. At x = 0 the slope is 0 from both sides, so the derivative exists there. At x = 1 the slope from the left is 2 and from the right is 0, so x = 1 is the only point with no derivative.

Sanity check. F should end at 1 and it does, since 1² = 1, and it should never fall, which x² does not on [0, 1]. One corner is fewer than the uniform's two, which is right: this density rises to meet the ramp at 0 instead of stepping up to it.

Carry this away

  • A random variable is continuous exactly when some non-negative function integrates up to its CDF, and that function is the density.
  • Because the CDF is an integral, it moves smoothly with x and can never jump, which is what ends Lecture 6's habit of reading probabilities off jump heights.
  • Differentiability holds only almost everywhere, the exceptions are corners like the uniform's two, and the claim is asserted here rather than proved.

Next: A density is not a probability, which takes the same clause and shows why the height of the curve can be larger than 1 without anything being wrong.

Your teacher. If the definition still feels like a formality, ask an agent to hand you three candidate functions and make you decide which of them could be a density, using only the two conditions on this page: non-negative everywhere, and integrating up to something that behaves like a CDF. The decision is quick and it is where the definition stops being a sentence and starts being a test. Then ask it to draw the CDF of a variable that is discrete on part of its range and continuous on the rest, so you can see a shape that fails this definition and still has a perfectly good CDF.
