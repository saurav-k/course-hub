Every problem is worked to the same fixed shape the earlier tutorials set, because a tutorial read alone is a bad teacher: the questions are terse and the working compresses three lines into one.

  1. The question restated in full, so you never hold it in your head while reading the answer.
  2. Every symbol named in words, on the page where it appears.
  3. The picture before the algebra. A staircase for a CDF, a grid for a pair of sales, a curve for a threshold.
  4. Every intermediate step, including the ones the working skips.
  5. The answer stated plainly, and then a check you can run without redoing the work.

Problems 6 to 9, solved by this course

All four are the same machine: count the successes, call the count X, and read X ∼ Bin(n, p) off the sentence. n is the number of independent repetitions, p is the chance of a success on one of them, and P(X = k) = C(n, k) pk(1−p)n−k, where C(n, k) counts the ways k successes can sit among n slots. A question asking for "at least" is a tail and is cheapest through the complement.

Problem 6 - the satellite, set as homeworkfoundation

A satellite system has 4 components and functions adequately if at least 2 of the 4 are working. Each component works independently with probability 0.6. What is the probability that the system functions adequately? Ross, Chapter 5, Problem 1, p. 212.

Hint

Two failures out of four is a shorter list than three successes out of four.

Show this course's worked solution
  1. Name the variable. X is the number of working components, so X ∼ Bin(4, 0.6) and the system is adequate exactly when X ≥ 2.
  2. Take the complement. The bad cases are only two, X = 0 and X = 1, so P(X ≥ 2) = 1 − P(X = 0) − P(X = 1).
  3. Price X = 0. All four fail: C(4, 0)(0.6)0(0.4)4 = 0.44 = 0.0256.
  4. Price X = 1. One works and three fail, in any of 4 positions: C(4, 1)(0.6)(0.4)3 = 4 × 0.6 × 0.064 = 0.1536.
  5. Subtract. 1 − 0.0256 − 0.1536 = 1 − 0.1792 = 0.8208.

Sanity check. The answer must beat a single component's 0.6, because two spares are being added to help it, and 0.8208 does.

Problem 7 - majority decoding on five digitsworking

A channel transmits 0s and 1s, and a digit is received incorrectly with probability 0.2. To reduce error, "0" is sent as 00000 and "1" as 11111. The receiver decodes by majority, reading "0" when at least 3 of the 5 received digits are 0. What is the probability that a message is incorrectly decoded, and what independence assumption is being made? Ross, Chapter 5, Problem 2, p. 212.

Hint

A wrong decode needs the majority of the five digits to be wrong.

Show this course's worked solution
  1. Name the variable. X is the number of the 5 digits received incorrectly, so X ∼ Bin(5, 0.2). The majority rule misreads the message exactly when the wrong digits are in the majority, that is when X ≥ 3.
  2. Price X = 3. C(5, 3)(0.2)3(0.8)2 = 10 × 0.008 × 0.64 = 0.05120.
  3. Price X = 4. C(5, 4)(0.2)4(0.8) = 5 × 0.0016 × 0.8 = 0.00640.
  4. Price X = 5. (0.2)5 = 0.00032.
  5. Add the tail. 0.05120 + 0.00640 + 0.00032 = 0.05792.
  6. Name the assumption. Writing the count as a binomial assumes the five digit errors are independent of one another and that each carries the same rate 0.2. A real channel breaks that assumption whenever noise arrives in bursts, which corrupts neighbouring digits together.

Sanity check. The answer must sit below the raw digit error rate of 0.2 or the coding would be worthless, and 0.058 is roughly a quarter of it.

Problem 8 - seven voters in tenfoundation

Each voter favours Proposition A with probability 0.7. What is the probability that exactly 7 of 10 voters favour it? Ross, Chapter 5, Problem 3, p. 212.

Hint

This is one point of the mass function, not a tail.

Show this course's worked solution
  1. Name the variable. X is the number of the 10 voters in favour, so X ∼ Bin(10, 0.7) and the question wants P(X = 7).
  2. Count the arrangements. C(10, 7) = 10!/(7!3!) = 120, the number of ways to choose which 7 of the 10 are in favour.
  3. Price one arrangement. (0.7)7(0.3)3 = 0.0823543 × 0.027 = 0.00222357.
  4. Multiply. 120 × 0.00222357 = 0.2668, about 26.7%.

Sanity check. Seven is the mean here, since np = 10 × 0.7 = 7, so this is the single largest mass in the whole distribution, and it is still only about a quarter of it.

Problem 9 - three dominant children in fourfoundation

Two hybrid parents have 4 children. Each child independently shows the dominant appearance with probability 3/4 and the recessive with probability 1/4. What is the probability that exactly 3 of the 4 children show the dominant appearance? Ross, Chapter 5, Problem 4, p. 212.

Hint

Keep the fractions rather than switching to decimals; the answer is exact.

Show this course's worked solution
  1. Name the variable. X is the number of the 4 children showing the dominant appearance, so X ∼ Bin(4, 3/4) and the question wants P(X = 3).
  2. Count the arrangements. C(4, 3) = 4, one for each child who could be the recessive one.
  3. Price one arrangement. (3/4)3(1/4) = (27/64)(1/4) = 27/256.
  4. Multiply. 4 × 27/256 = 108/256 = 27/64 = 0.421875.

Sanity check. Compare it with all four dominant, (3/4)4 = 81/256 ≈ 0.316: exactly three is the more likely of the two, which is right because there are four ways to place the recessive child and only one way to have none.
