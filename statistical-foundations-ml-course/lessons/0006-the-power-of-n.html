The same four point lift, now undeniable, because of one square root

9 min one idea, thoroughly Nothing about the buttons changes on this page. Only the number of users does, and that is enough to change the decision.

The one-minute version

  • Run the identical experiment with 5,000 users per group instead of 1,000, and observe the identical rates of 0.30 and 0.34.
  • The standard errors shrink to 0.0065 and 0.0067, because n sits under a square root in the denominator.
  • The intervals become [28.7%, 31.3%] and [32.7%, 35.3%]. They no longer touch.
  • The lift was always four points. What changed is our ability to see it. Deploy gold.

1. The one expression this page is about

Slide 15 opens by pointing back at the variance formula derived in Part 5, because everything here follows from it:

Var(p̂) = p(1 − p) / n  ⇒  SE = √( p̂(1 − p̂) / n ) The top of the fraction is a property of the thing being measured, and you do not control it. The bottom is how many people you asked, and you do control it entirely. That asymmetry is the whole of experiment design.

Notice exactly where n sits. It is in the denominator, so more users means less spread. But it is also inside a square root, so the payoff is not linear. Five times the users buys you √5 ≈ 2.24 times the precision, not five times.

2. Recomputing at n = 5,000, worked in full

  1. Gold button, the product. 0.34 × 0.66 = 0.2244. This is unchanged from Part 5, because the observed rate is unchanged.
  2. Gold button, divide by the new sample. 0.2244 ÷ 5,000 = 0.00004488, which is one fifth of the old 0.0002244.
  3. Gold button, take the root. √0.00004488 = 0.006699, which the deck reports as 0.0067. Sanity check: 0.0150 ÷ √5 = 0.0150 ÷ 2.236 = 0.0067, exactly as expected.
  4. Gold button, build the interval. 2 × 0.0067 = 0.0134, so 0.34 ± 0.0134 gives [32.7%, 35.3%].
  5. Grey button, the same three moves. 0.30 × 0.70 = 0.21, divided by 5,000 is 0.000042, and its square root is 0.006481, reported as 0.0065.
  6. Grey button, build the interval. 2 × 0.0065 = 0.013, so 0.30 ± 0.013 gives [28.7%, 31.3%].
  7. Compare. Grey reaches up to 31.3 percent. Gold reaches down to 32.7 percent. There is a gap of 1.4 percentage points between them, and no true rate is consistent with both.

3. Why the payoff is a square root

The relationship SE ∝ 1/√n is worth internalising as a curve rather than as a formula, because the curve tells you when to stop buying users. Early samples are enormously valuable. Later ones are not.

Decide n before you lookSlide 15 presents the larger experiment as a clean rerun, and read that way it is perfectly sound. The dangerous version, which happens constantly in practice, is to keep adding users to a running test and stop the moment the intervals separate. That procedure will eventually separate them even when the two buttons are identical, because you are taking many looks at a wandering estimate and stopping on the flattering one. The sample size is part of the experiment design, and it belongs before the data, not after it. Sequential testing done properly exists, but it needs different arithmetic from what is on this slide.

4. Check yourself

At n = 1,000 the standard error for the gold button is about 0.0150. Roughly what sample size would bring it to about 0.0075?
Halving the standard error requires doubling √n, and doubling a square root means multiplying n by four, so 1,000 becomes 4,000. Direct proportion would make 2,000 the answer, but that would need n rather than √n in the denominator. Shrinking the sample makes the error larger, not smaller, so 500 moves the wrong way. And a million would be the answer only if precision improved with n squared, which would make experiments far cheaper than they actually are.
Between Part 5 and Part 6 the recommendation flipped from "not established" to "deploy gold". What actually changed?
The rates are still 0.30 and 0.34, so the lift is still exactly four percentage points; only the intervals around them shrank. The observed rates did not move, which rules out the first option. The confidence level stayed at 95 percent throughout, so no threshold was relaxed. And the model is the same Bernoulli-plus-CLT argument from Part 5, applied with a different n in the very same formula.
Your teacher. Before your next experiment, invert this page. Do not ask "how many users can I get". Ask "how small does the interval have to be before I would act on the result", then use SE = √(p(1−p)/n) backwards to find the n that delivers it. If that n is unaffordable, you have learned something valuable before spending anything: this experiment cannot answer this question, and you should change the question.
