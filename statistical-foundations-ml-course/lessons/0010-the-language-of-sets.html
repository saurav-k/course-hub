Lecture 2 · Part 1 of 6 · Supporting: the set-theory primer

Probability is written in the language of sets

foundation 14 min A reference page, not a slide from the deck: the tutorial session assumes this vocabulary, so it is taught here openly before the lecture proper starts using it.

The one-minute version

  • A set is a collection of well-defined objects, and probability treats every question you can ask as a set of outcomes.
  • Four operations do all the work: union (or), intersection (and), complement (not), and difference (and not).
  • The translations table below is the highest-value table in the lecture: it turns English phrases like "exactly one of" into set notation.
  • De Morgan's laws say how "not" flips "and" into "or", for two sets or for a whole indexed family of them.
  • The power set of a set with n elements has 2n subsets, which is where counting arguments later stand.
Why this page existsThis page is supporting material, not a slide from the faculty deck. If you have ever written a union or an intersection, skim it and keep the translations table.

1. Sets, membership, and subsets

A set is a collection of well-defined objects, and the objects in it are called its elements. The deck's own examples are A = {1, 2, 3}, three numbers, and B = {x ∈ N : x even}, read as "every x in the natural numbers such that x is even". The colon is read "such that", and everything after it is the admission test.

x ∈ A Read as: "x is a member of A", or "x belongs to A". The symbol ∈ is membership. If x is not one of A's elements, write x ∈ A with a slash through it, "x is not in A".
A ⊆ B Read as: "A is a subset of B". It means every element of A is also an element of B, so the region A sits wholly inside the region B.

Two special sets bookend everything. The universe U is the set of every object under discussion, and every set here is a subset of it. The null set ∅, also written ∅ and read "the empty set", has no elements at all, and it is a subset of every set, because "every element of ∅ is in A" is a claim about nothing, which cannot fail.

Equality by double inclusion

How do you prove two sets are equal? Not by staring at them. The method the tutorial uses is double inclusion: show A ⊆ B and B ⊆ A, and equality follows. Each direction is proved by taking an arbitrary element and chasing it.

You will meet this method again on this page, where it proves a distributive law, and in every later proof that two events are the same event. It is the set-theoretic version of proving two programs equal by running both on the same input.

2. The four operations

Union: or

A ∪ B = {x : x ∈ A or x ∈ B} Read as: "A union B" is the set of every x that is in A or in B, or in both. The word "or" here is the inclusive or of mathematics, not the exclusive or of circuits.

Intersection: and

A ∩ B = {x : x ∈ A and x ∈ B} Read as: "A intersect B" is the set of every x that is in A and also in B. It is the overlap, and it is empty exactly when the two sets share nothing.

Complement: not

Ac = {x ∈ U : x ∉ A} Read as: "A complement" is every x in the universe U that is not in A. The symbol ∉ is "not a member of", and the superscript c always means "take the rest of the universe".

Difference: and not

A \ B = {x : x ∈ A and x ∈ B with a slash, i.e. x not in B} Read as: "A set-minus B", also called the relative complement. It is the part of A that B leaves untouched, and it equals A ∩ Bc.

Disjoint: no overlap at all

Two sets are disjoint when their intersection is empty, written A ∩ B = ∅. The picture is two discs that do not touch. Disjointness is the condition under which the probability axioms of Part 5 let you add, which is why the deck introduces it there.

6. Building new sets: the product and the power set

The Cartesian product

A × B = {(x, y) : x ∈ A, y ∈ B} Read as: "A cross B" is the set of every ordered pair whose first coordinate comes from A and whose second comes from B. Repeating one set n times is written An, so the space of three coin tosses is {H, T}3.

The power set

2A = the set of all subsets of A Read as: "the power set of A". For A = {1, 2} it holds four sets: the empty set, the two singletons, and A itself. If A has n elements, the power set has 2n elements.

Check yourself

With M the event "joined from mobile" and P the event "made a purchase", which expression reads "joined from mobile and made a purchase"?
Both tests at once is M ∩ P, the lens, which is exactly the region Part 6 labels MP and weighs at 0.18. The union also holds for users who did one without the other. M ∩ Pᶜ is mobile users who did not buy, the "only M" row of the table. And P \ M is buyers who did not come from mobile, which is the desktop purchase instead.
De Morgan says (A ∪ B)ᶜ equals which of these?
Being outside "A or B" means failing both tests, which is the intersection of the complements. The union of the complements is the complement of the intersection instead, the third option's region: everything but the lens. The complement of the lens is a different, larger region than outside both discs. And the crescent A \ B sits inside A, while the region asked about sits outside both.
A sample space will have eight outcomes. How many subsets does its full power set hold?
Each of the eight outcomes is either in or out of a subset, so the count is 2⁸ = 256. Sixteen is 2⁴, the answer for a four-outcome space. Nine counts only the singletons and the empty set, missing every multi-outcome subset. Sixty-four is 8², which multiplies instead of exponentiating.
