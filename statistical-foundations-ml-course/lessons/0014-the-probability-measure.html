The probability measure weighs every event from zero to one

working 11 min The last letter of the triple: a function P that takes each event in F and returns its weight, under three axioms that make the weights behave.

The one-minute version

  • The probability measure P is a function from F to the interval [0, 1]: it takes an event and returns a weight.
  • The deck's three axioms: P(∅) = 0, P(Ω) = 1, and P(A ∪ B) = P(A) + P(B) when A and B are disjoint.
  • The range [0, 1] is the non-negativity clause: no event weighs less than nothing, and nothing weighs more than certainty.
  • Additivity is stated for disjoint events, and the homework extends it to countable sequences of them.

1. What kind of function P is

P : F → [0, 1] Read as: "P is a function from the sigma-field F to the interval from 0 to 1". Feed it an event A and it returns a number P(A), the probability of A, always between 0 and 1. That range is the non-negativity clause: an event cannot weigh less than nothing, and no weight can pass certainty.

2. The three axioms

Axiom 1: P(∅) = 0. The impossible event weighs nothing. Part 4 bought the empty set with axioms 1 and 2 of the sigma-field; this axiom prices it.

Axiom 2: P(Ω) = 1. The certain event weighs exactly one, no more and no less. All the probability in the universe of this experiment sums to one, which is what makes P a total mass rather than a scale of arbitrary units.

Axiom 3: if A and B are disjoint, P(A ∪ B) = P(A) + P(B). When two events share no outcomes, the weight of "at least one of them" is the sum of the weights. The homework states the same axiom for a countable sequence of disjoint events: P(E1 ∪ E2 ∪ ...) = P(E1) + P(E2) + ... .

3. The countable version, and why it is not scary

One reading warning before the worked example. "Countable" is doing quiet work: it means the events can be lined up as a first, second, third, and so on, like the positive integers. A sequence is addable; a blur of uncountably many events is not, and the axioms deliberately promise nothing about those.

4. The deck's own example, before Part 6 generalises it

The measure board runs the whole machinery on one coin. The space is Ω = {H, T}, the sigma-field is the full power set F = {∅, {H}, {T}, {H,T}}, and P assigns 0, p, 1 − p, and 1 to the four members. Check the axioms against it: the empty set weighs 0, the whole space weighs 1, and heads and tails are disjoint, so P({H} ∪ {T}) should be p + (1 − p) = 1, which is exactly what axiom 2 demands of {H, T}. The three axioms hold, so the assignment is a legal probability measure.

Check yourself

Events A and B satisfy P(A) = 0.4 and P(B) = 0.5. When is P(A ∪ B) = 0.9 legal?
Additivity applies exactly to disjoint events; with any overlap, the lens gets counted twice and the sum overstates the union. Membership in F makes the events weighable, not additive. The sum reaching one is an accident of these particular numbers, not the condition. And A inside B makes the overlap everything in A, giving P(A ∪ B) = 0.5, not 0.9.
Why does the definition insist P maps into [0, 1] rather than any real number?
The range encodes two meanings at once: 0 is no chance and 1 is certainty, so a weight is always a fraction of the total. Adding stays exact for any range, so that is not the reason. Weights are decimals like 0.18, not whole percentages. The number line is this page's picture of the range, not the reason for it.
The homework strengthens axiom 3 to a sequence of disjoint events. Which question needs that strengthening?
"Odd count" is {1, 3, 5, ...}, a union of infinitely many single-outcome events, so its weight is an infinite sum and needs the countable axiom. Two disjoint events are the original two-set form. An event equal to the whole space is axiom 2, no summing at all. And events outside F are never weighed by P, whatever the axiom says.
Your teacher. The axioms are worth one minute of suspicion each: ask what breaks without them. Drop axiom 2 and "probability" becomes a scale with no units, like measuring lengths in unnamed units. Drop axiom 3 and combining evidence double-counts, the way a buggy analytics pipeline counts a user once per table. Drop the range clause and a weather report of minus 0.3 becomes sayable. Each axiom is load-bearing, which is why Lecture 3 can build on them without further checks.
