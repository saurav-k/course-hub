Uncorrelated becomes independent in exactly two places, and only one of them is proved here

Before you start: Uncorrelated is not independent, for the product rule and the counterexample this page answers.

The one-minute version

  • Independence always gives E[XY] = E[X]E[Y]. The reverse is false in general, and the notes list two exceptions.
  • Exception one: jointly Gaussian variables. The notes write "we will see this later" and move on, so it is a signpost, not a result.
  • Exception two: binary variables, worked here. For a Bernoulli pair, E[XY] is nothing but P(X = 1, Y = 1).
  • So the product rule already factorises one cell of the two-by-two table. The other three follow by subtracting from a margin, one at a time.
  • Four factorised cells is the whole definition of independence for a two-valued pair, so the pair is independent and the converse holds.

1. The claim, and how narrow it is

Page 9 of the notes opens with one sentence: uncorrelatedness implies independence only for jointly Gaussian random variables and for binary random variables. Read the word only carefully. It is not saying these are two convenient cases among many; it is saying the repair is rare, and outside these two settings a zero covariance carries no structural information about the joint distribution at all.

2. The Gaussian case, named and postponed

The notes write "we will see (1) later" and take case (2). This course does the same, and says so rather than filling the gap with a proof it has not earned.

The jointly Gaussian case is asserted here and proved nowhere in this courseNothing on these pages establishes that uncorrelated jointly Gaussian variables are independent, and nothing earlier does either. Two obstacles stand in the way. First, jointly Gaussian is a stronger condition than "each one is Gaussian": Hajek's Definition 4.11.1 asks that every linear combination aX + bY be Gaussian, and a pair of Gaussian marginals need not satisfy it. Second, the proof runs through the bivariate normal density, where setting the correlation to zero makes the joint density factor into two one-variable densities; this course has not built a joint density for two continuous variables, so the step cannot even be written down yet. Treat the Gaussian half as a signpost you have been handed, in the same way Lecture 7, Part 11 kept the exponential's uniqueness claim separate from the property it did prove.

3. The binary case: what the product rule already gives you

Take X ~ Ber(p) and Y ~ Ber(q), so each takes only the values 0 and 1. Assume they are uncorrelated. Being uncorrelated is the single equation below, and the point of the whole argument is that a two-valued variable makes that equation say far more than it usually does.

E[XY] = E[X] E[Y] X and Y are the two random variables, each taking only the value 0 or the value 1. E[XY] is the expected value of their product, computed on the joint distribution. E[X] and E[Y] are the individual expected values. The equation holding is the definition of uncorrelated, equivalently Cov(X, Y) = 0, from the previous pre-read page.

Now read each of those three expectations for a two-valued variable. The product XY is 1 only when both are 1 and 0 otherwise, so its average is the probability of that single outcome. The same collapse happens for each variable alone.

  1. Expand the product's expectation. E[XY] = 1·1·P(X = 1, Y = 1) + 1·0·P(X = 1, Y = 0) + 0·1·P(X = 0, Y = 1) + 0·0·P(X = 0, Y = 0). Three of the four terms carry a zero factor, so E[XY] = P(X = 1, Y = 1).
  2. Expand each marginal. By the same collapse, E[X] = 1·P(X = 1) + 0·P(X = 0) = P(X = 1) = p, and E[Y] = P(Y = 1) = q.
  3. Rewrite the assumption. Substituting all three into E[XY] = E[X]E[Y] turns it into P(X = 1, Y = 1) = P(X = 1) P(Y = 1). This is no longer a statement about averages: it is one cell of the joint table factorising.

For a general pair, one factorised joint probability is a long way from independence. For a binary pair it is one quarter of the whole table, and the margins supply the rest.

4. Filling the other three cells

Each remaining cell comes from a margin minus a cell already known. The rule used four times is that the two cells of a row add up to the row's margin, because Y must be either 1 or 0 and cannot be both.

Four cells, four products of a margin with a margin. That is the definition of independence for a pair that takes only two values each, so X and Y are independent and the converse holds here.

5. Why three values breaks it

The argument leans on the table being small. With two values each there are four cells, the two margins pin down three of them once one is known, and the single product equation supplies that one. Give X four values, as the counterexample in the previous pre-read page does, and the table has eight cells with far more freedom left in it than one equation can remove. That is precisely how that example arranged zero covariance alongside blatant dependence: it had room to.

Practice about 10 minutes, with paper

Practice 1working

A request either hits a cache or misses it, and it either comes from a mobile client or does not. Let X = 1 for a cache hit with P(X = 1) = 0.4, and Y = 1 for a mobile client with P(Y = 1) = 0.7. A log sample gives E[XY] = 0.28.

Fill in all four cells of the joint table, say whether the two are independent, and state what would have changed had the sample given 0.34 instead.

Hint

Start by checking the single product equation. E[XY] for a binary pair is one specific joint probability, not an average of anything you have to integrate.

Show the worked solution
  1. Test the product rule. E[X]E[Y] = 0.4 × 0.7 = 0.28, which is what the sample reports, so the pair is uncorrelated.
  2. Read the first cell. E[XY] = P(X = 1, Y = 1), so that cell is 0.28, and it equals its two margins multiplied.
  3. Row X = 1. P(X = 1, Y = 0) = 0.4 − 0.28 = 0.12, which is 0.4 × 0.3.
  4. Column Y = 1. P(X = 0, Y = 1) = 0.7 − 0.28 = 0.42, which is 0.6 × 0.7.
  5. Row X = 0. P(X = 0, Y = 0) = 0.6 − 0.42 = 0.18, which is 0.6 × 0.3.
  6. Conclude. All four cells factorise, so cache hits and mobile clients are independent here. Because both variables are binary, uncorrelated was already enough to force this.
  7. The alternative reading. With 0.34 the product rule fails, since 0.34 ≠ 0.28, so the pair is correlated and therefore also dependent. Mobile clients would be hitting the cache more often than the overall rate suggests.

Sanity check. The four cells must add to 1: 0.28 + 0.12 + 0.42 + 0.18 = 1. Each row must also add to its own margin, so 0.28 + 0.12 = 0.4 and 0.42 + 0.18 = 0.6. Every figure here is this course's own arithmetic; the notes state no numbers.

Carry this away

  • Zero covariance forces independence in two settings only: jointly Gaussian pairs and binary pairs.
  • For a binary pair, E[XY] is the single joint probability P(X = 1, Y = 1), so the correlation equation is a statement about the table itself.
  • Three subtractions from the margins turn that one factorised cell into four, and four factorised cells are independence.
  • The Gaussian half is a promise this course has not kept, and the rest of the syllabus is where these quantities go to work: the mean and the variance become the summaries every estimator is judged against, the covariance matrix becomes the shape of a multivariate model, and the same expectations reappear as the bias and variance of a fitted predictor.

If the cell-by-cell step feels like sleight of hand, draw the empty two-by-two table on paper, write only p, 1 − p, q, 1 − q in the margins, and put any single number you like in the top-left cell. For the citable statements, Hajek's Probability with Engineering Applications defines uncorrelated in Chapter 4 as Cov(X, Y) = 0, states plainly that independence implies uncorrelated and that the converse is false, and observes that independence asks for an equation at every pair of values while being uncorrelated asks for one. Its Section 4.11 carries the Gaussian half: Definition 4.11.1 calls X and Y jointly Gaussian when every linear combination aX + bY is Gaussian, and the proposition that follows proves that such a pair is independent if and only if its correlation coefficient is zero, by factoring the bivariate normal density.
