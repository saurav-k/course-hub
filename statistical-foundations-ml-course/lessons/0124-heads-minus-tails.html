TA Session 3 · Part 4 of 10 · Problems 2 and 3

One count decides both totals, so the difference can only move in steps of two

working 11 min Two problems the sittings treated as one: what the difference between heads and tails can be, and what its mass function is at three tosses.

After this page

  • You can express a two-sided count as a function of one count and read its support off the algebra.
  • You can say why the support of this variable has a gap of two in it, and what the gap depends on.
  • You can produce its mass function at a small n from the sample space alone.

Before you start: Part 1, for what a support is and why it belongs to the function.

The one-minute version

  • A fair coin is tossed n times. X is the number of heads minus the number of tails.
  • Write H for the heads count. Tails is then n − H, so X = H − (n − H) = 2H − n. One count decides everything.
  • H runs from 0 to n in steps of one, so X runs from −n to n in steps of two. Every extra head moves the difference by two, not by one.
  • That gap has a parity: for even n the support is 0, ±2, …, ±n, and for odd n it is ±1, ±3, …, ±n.
  • At n = 3 the support is −3, −1, 1, 3 and the masses are 1/8, 3/8, 3/8, 1/8.

1. Problem 2, restated

Let X represent the difference between the number of heads and the number of tails obtained when a fair coin is tossed n times. What are the possible values of X? The sheet cites Ross, Chapter 4, end-of-chapter Problem 2, p. 142.

A student asked how you would know to reach for a random variable here rather than for anything else. The tutor's answer was honest and worth recording: mostly practice, plus the convention that a capital letter names a random variable, plus the definition itself, which assigns a number to every outcome and is therefore always available. Some problems are simply easier that way.

2. Reducing two counts to one

X = H − (n − H) = 2H − n n is the number of tosses, fixed before the experiment. H is the number of heads, the only quantity the coin decides. n − H is the number of tails, which follows immediately because every toss is one or the other. X is the difference asked for. The final form says X is a straight-line function of H with slope 2.
  1. Name the free count. Let H be the number of heads. Nothing else about the sequence matters to X.
  2. Fill in the other count. Every toss is a head or a tail, so tails is n − H exactly, with no probability involved.
  3. Subtract. X = H − (n − H), and removing the bracket gives H − n + H = 2H − n.
  4. Walk H across its range. H = 0 gives X = −n. H = 1 gives 2 − n. H = n gives 2n − n = n.
  5. Read off the support. H moves in steps of one, so X moves in steps of two: −n, −n + 2, −n + 4, …, n.

A student objected that a negative value looked impossible, since neither count can be negative. The distinction is the one the whole problem turns on: X is not a count. It is a difference of two counts, and a difference is negative whenever the tails outnumber the heads. If the question had asked for the number of heads, the support would have been 0 to n.

The slow sitting sharpened the answer one step further, and the sharpening is the useful part. Because X = 2H − n, the parity of X is the parity of n. So for even n the support is 0, ±2, ±4 up to ±n, and it contains zero. For odd n it is ±1, ±3 up to ±n, and it can never be zero, because an odd number of tosses cannot split evenly.

3. Problem 3: the mass function at n = 3

The sheet's next problem fixes the coin as fair and n as 3, and asks for the probability attached to each value X can take. Ross, Chapter 4, Problem 3, p. 142.

The tutor worked this from the eight-outcome sample space, because it keeps the counting visible, and that is the route below.

  1. List the space. Eight equally likely strings: HHH, HHT, HTH, THH, HTT, THT, TTH, TTT. Each has probability (1/2)3 = 1/8.
  2. Translate each value. X = −3 means three tails and no heads; X = −1 means one head and two tails; X = 1 means two heads and one tail; X = 3 means three heads.
  3. X = −3. Only TTT qualifies, so the mass is 1/8.
  4. X = −1. Three strings qualify, HTT, THT and TTH, so the mass is 3/8.
  5. X = 1. Three strings, HHT, HTH and THH, so 3/8.
  6. X = 3. Only HHH, so 1/8.
The binomial route exists and was deliberately not usedThe same four masses come out of Bin(3, 1/2) on the head count in one line, and the tutor set that route aside so the class was not meeting a new formula and a new variable at once.

Chapter 4 of Ross, A First Course in Probability sets both problems as consecutive exercises, which is why the sittings treated them as one block rather than two.

Check yourself

Retrieval practice

Answer from memory before revealing.

A fair coin is tossed six times. Can the difference between heads and tails be three?
The difference is 2H minus 6, which is even for every whole H, so an odd value like three is unreachable. The second option is not a reason at all, since one and five are also smaller than six and one of them is likewise unreachable. The third checks the range and forgets the step of two. The fourth is arithmetic that does not work: four heads gives 8 minus 6, which is two.
Why do the two middle values at n = 3 each carry three eighths of the mass?
Every string has mass one eighth, and three separate strings produce one head or two heads, so those values collect three eighths each. The first option is false: a fair coin gives every string the same weight, and only the counting differs. The second is a pattern rather than a reason, and it fails for plenty of variables. The fourth reverses cause and effect: the ends are small because one string each maps there.

Practice about 10 minutes, with paper

Practice 1working

The same fair coin is now tossed four times, and X is again the number of heads minus the number of tails.

Give the support of X, then its full mass function, and say what changed from the three-toss case and why.

Hint

Use X = 2H minus 4 to get the support, then count the sixteen equally likely strings by their head count.

Show the worked solution
  1. Support. H runs 0 to 4, so X = 2H − 4 runs −4, −2, 0, 2, 4. Four is even, so zero is now reachable.
  2. Count the space. Four tosses give 24 = 16 equally likely strings, each of mass 1/16.
  3. Count by head count. One string has 0 heads, four have 1, six have 2, four have 3, one has 4.
  4. Attach the masses. P(X = −4) = 1/16, P(X = −2) = 4/16 = 1/4, P(X = 0) = 6/16 = 3/8, P(X = 2) = 1/4, P(X = 4) = 1/16.
  5. Say what changed. The support gained zero and lost every odd value, because the parity of X follows the parity of n.

Sanity check. The five counts 1, 4, 6, 4, 1 add to 16, so the masses sum to exactly 1. The distribution must also be symmetric about zero, since a fair coin makes heads and tails interchangeable, and it is.

Carry this away

  • When two counts must add to n, only one of them is free, and the whole variable is a function of that one.
  • The coefficient in front of the free count sets the step size of the support, here 2.
  • The parity of the support follows the parity of n, so an odd number of tosses can never tie.
  • At a small n the sample space produces the mass function and also shows why the middle values are heavier.

Next: Reading a CDF five ways, where the mass is not given and has to be recovered from the jumps.

Your teacher. Whenever a problem hands you two counts that must add to a fixed total, immediately write the second one in terms of the first and never carry both. Half the difficulty in this problem is imaginary and comes from tracking heads and tails as two independent quantities when only one of them is free. The habit pays again at the next binomial you meet, where the number of failures is likewise not a second unknown.
