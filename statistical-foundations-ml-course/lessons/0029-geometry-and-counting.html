When the sample space has a shape, let the shape do the work

working 15 min Tutorial problems 6 and 7. One border measured from the outside in, one discriminant counted from the inside out.

The one-minute version

  • Problem 6 works by complement: points further than 1/3 from every side form an inner square of side exactly 1/3, area 1/9.
  • So the answer is 1 − 1/9 = 8/9, with no rectangle bookkeeping at all.
  • Problem 7 turns "real roots" into an inequality: b² ≥ 4ac, counted systematically for each middle coefficient b.
  • The favourable triples number 43 out of 216, a probability of 43/216 ≈ 19.91% - demonstrated by a table, not asserted.

Problem 6, restated

A point (X, Y) is chosen uniformly at random from the unit square S = {(x, y): 0 ≤ x ≤ 1, 0 ≤ y ≤ 1}. Uniform means every region R inside S catches the point with probability equal to its share of the area:

P((X, Y) ∈ R) = Area(R)/Area(S) Read as: the chance of landing in region R is its area divided by the whole square's area. Here X and Y are the coordinates of the landed point, each running independently between zero and one.

Find the probability that the distance from (X, Y) to the nearest side of the square does not exceed 1/3.

Which theorem is in play, and why the complement

The governing fact is the uniform model above, plus the complement rule P(event) = 1 − P(opposite event). The event we want - close to some side - is a frame around the square, four strips plus four corners. Its opposite is one clean shape: the inner square of points far from every side. Computing one area beats computing six, which is the whole reason for complementing.

  1. Name the four distances. A point at horizontal position X sits X units from the left edge and 1 − X from the right; vertical position Y gives Y and 1 − Y against the bottom and top. The distance to the nearest side is therefore D = min{X, 1−X, Y, 1−Y}.
  2. Negate the question. We want P(D ≤ 1/3); the complement rule rewrites it as 1 − P(D > 1/3), so describe the set where D exceeds 1/3.
  3. Unfold the minimum. D > 1/3 means every one of the four distances exceeds 1/3: X > 1/3 and 1−X > 1/3, and likewise for Y. The X pair pins 1/3 < X < 2/3; the Y pair pins 1/3 < Y < 2/3.
  4. Recognise the shape. Those two pinning conditions carve out the open inner square from 1/3 to 2/3 in both directions. Its side length is 2/3 − 1/3 = 1/3 - stated explicitly, because jumping straight to area hides it - so its area is (1/3)² = 1/9.
  5. Convert area to probability. Area(S) = 1, so P(D > 1/3) = (1/9)/1 = 1/9.
  6. Close with the complement rule. P(D ≤ 1/3) = 1 − 1/9 = 8/9.

One refinement worth stating once: the boundary lines themselves have zero area, so whether the inner square is described with strict or non-strict inequalities changes no probability. The answer survives the difference between "exceeds" and "at least".

Where this goes wrongAttacking the band directly invites corner errors: the frame is four strips of width 1/3, but naive adding counts each 1/3-by-1/3 corner twice, and subtracting the corners again is exactly the sort of bookkeeping exams punish. The second slip is skipping the side-length step and writing "inner area = 1/9" without ever saying the side is 1/3 - right answer, unsupported. The complement route makes both mistakes structurally difficult.

Answer from memory before revealing.

Why compute P(D > 1/3) first rather than the band's area directly?
One square versus four strips plus four corners: fewer pieces, fewer double-counted areas. Complements help here for that specific reason, not by magic - often the complement is worse. Boundary lines carry zero area, so strictness changes nothing. Coordinates stay continuous throughout.

Problem 7, restated

Three numbers a, b and c are chosen independently and with replacement from {1, 2, 3, 4, 5, 6} - think of rolling a die once for each coefficient. Find the probability that the quadratic equation ax² + bx + c = 0 has at least one real root.

Which tools are in play, and why counting must be systematic

The governing result is the finite uniform model: with 216 equally likely ordered triples, the wanted probability is favourable triples divided by 216. The algebraic bridge is the discriminant test: a quadratic ax² + bx + c = 0 with a > 0 has a real root exactly when its discriminant b² − 4ac is non-negative, which rearranges to ac ≤ b²/4. Since a, b and c are integers while b²/4 need not be, the working condition rounds down to ac ≤ the largest whole number below or equal to b²/4. What remains is pure counting, done by fixing the middle coefficient and scanning - never by listing 216 triples.

  1. Count the whole space. Six choices per coefficient, independently, order mattering: 6 × 6 × 6 = 216 ordered triples.
  2. Fix b and derive each bound. b = 1 allows ac ≤ 0 - impossible, since the smallest product of two positive integers is 1. b = 2 allows ac ≤ 1; b = 3 allows ac ≤ 2; b = 4 allows ac ≤ 4; b = 5 allows ac ≤ 6; b = 6 allows ac ≤ 9.
  3. Scan a for each bound. For a fixed cap k on ac, row a contributes however many c in {1,...,6} satisfy a×c ≤ k. Example at b = 5, cap 6: a = 1 admits all six values of c; a = 2 admits c up to 3, so three; a = 3 admits two; a = 4, 5 and 6 admit only c = 1 each. Row total 6 + 3 + 2 + 1 + 1 + 1 = 14.   2. Divide. P(at least one real root) = 43/216 ≈ 0.1991, roughly a fifth of all rolls.
Where this goes wrongThree places. First, forgetting "with replacement" and shrinking the space to 6 × 5 × 4 - the coefficients are independent rolls, so repeats like (2, 2, 2) are legal outcomes. Second, misreading the discriminant direction: real roots need b² − 4ac ≥ 0, which bounds the product ac from above; flipping it counts mostly losing triples. Third, asserting 43 without the table - one missed row poisons the final fraction silently. The tutorial notes carry exactly this table, and reproducing it is how you check yourself.

Retrieval practice

Answer from memory before revealing.

In problem 7, what do the three dice rolls being "with replacement" guarantee?
With replacement means each roll starts from the full set again, so any combination including repeats stays live and the space keeps all 216 ordered triples. Rolls do not trend upward and do not collapse onto one value. Order still matters - (1, 6, 2) and (2, 6, 1) are different triples with different roots.
Why does b = 1 contribute zero favourable triples to the count?
The cap is b²/4 = 0.25, rounded down to zero, while the smallest product of two positive integers is already 1: nothing fits under it. Oddness is irrelevant, since b = 3 and b = 5 contribute plenty. Choosing a and c proceeds normally regardless. And the equation stays quadratic whenever a is nonzero, which it always is here.

Practice 1 - the complement of problem 7foundation

With the same setup - a, b, c rolled independently from {1,...,6} - find the probability that the equation ax² + bx + c = 0 has no real root.

Hint

You already own one side of this coin.

Show the worked solution
  1. Use the complement rule. Every triple either yields a real root or it does not, so P(no real root) = 1 − 43/216 = (216 − 43)/216.
  2. Compute. 216 − 43 = 173, so the probability is 173/216 ≈ 0.8009.
  3. Cross-check by regions. The failing triples are those with ac > b²/4; summing the complements of each table row gives 216 − 43, matching.

Sanity check. Roughly four rolls in five give complex roots, consistent with the main page's "about a fifth" for real ones - the two probabilities must total one, and they do.

Practice 2 - the square, tightenedworking

Return to problem 6's unit square but tighten the tolerance: find the probability that the distance from (X, Y) to the nearest side does not exceed 1/4.

Hint

Same complement, new width. State the inner square's side before its area.

Show the worked solution
  1. Complement conditions. D > 1/4 forces 1/4 < X < 3/4 and 1/4 < Y < 3/4.
  2. Inner square. Side length 3/4 − 1/4 = 1/2, hence area 1/4, hence P(D > 1/4) = 1/4.
  3. Complement rule. P(D ≤ 1/4) = 1 − 1/4 = 3/4.
  4. Notice the pattern. Tolerance t gives inner side 1 − 2t and answer 1 − (1 − 2t)²; plugging t = 1/3 reproduces 8/9, and t = 1/4 gives 3/4.

Sanity check. A tighter tolerance shrinks the band relative to the old one, so 3/4 sitting below 8/9 behaves as expected.

Your teacher. If the b = 6 row feels underived, rebuild it yourself from the grid picture with cap 9 and confirm the row reads 6, 4, 3, 2, 1, 1. If the geometry felt easy, ask the follow-up that examiners love: for which t does the probability hit exactly one half?
