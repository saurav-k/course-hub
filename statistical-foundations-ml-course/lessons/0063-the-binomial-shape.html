Lecture 5 · Part 5 of 10 · the classification-error board

Every pattern with three errors costs the same, so the answer is a count times a price

11 min working The third problem, and the one the whole lecture has been heading towards since the first line.

The one-minute version

  • A classifier errs on any given test example with probability 0.2, the errors are independent, and it is evaluated on 10 test examples. X is the total number of errors.
  • Fix any particular three examples to be the wrong ones. The probability of erring on exactly those and being right on the other seven is (0.2)3(0.8)7, and that value does not depend on which three.
  • There are C(10, 3) ways to choose which three, so Pr(X = 3) = C(10, 3) (0.2)3(0.8)7. The class notes write the same thing with the factors the other way round and note that C(10, 3) = C(10, 7).
  • The board then generalises it under the heading binomial probabilities: for n independent experiments each succeeding with probability p, Pr(k successes in n) = C(n, k) pk(1 − p)n−k.
  • Lecture 1, Part 3 used that formula on trust. This is the page where the course earns it.

1. The problem, and the three assumptions inside it

The problem. A classifier makes an error on any given test example with probability 0.2. It is evaluated on 10 independently selected test examples, and its errors on the different examples are independent. Let X denote the total number of classification errors among the ten. What is the probability that the classifier makes exactly three errors?

Three assumptions are stated and each one is doing work.

  • A fixed error probability. Every example is misclassified with the same probability 0.2, so it is correctly classified with probability 0.8. Nothing about the example changes that number, which is an idealisation and a strong one.
  • Independence. Erring on one example neither raises nor lowers the chance of erring on another, so probabilities multiply across examples.
  • A fixed number of examples. Exactly ten, decided before the evaluation begins rather than by watching the results.

Name one outcome. Here an outcome is a string of ten letters, one per test example in order, each letter either C for a correct classification or E for an error. The class notes draw exactly this and list several such strings down the page.

2. What one pattern costs

Take a single pattern with three errors in it, say seven C's followed by three E's. Its probability is a product of ten independent factors, one per example: 0.8 wherever a C sits, 0.2 wherever an E sits.

Now take a different pattern with three errors, with the E's scattered instead of bunched at the end. Its probability is a product of the same ten numbers, written in a different order. Multiplication does not care about order, so the two products are equal.

Pr(one particular pattern with three errors) = (0.2)3(0.8)7 0.2 is the probability of an error on one example and 0.8 is the probability of a correct classification, the two adding to one because a classification is one or the other. The exponent 3 is the number of errors in the pattern and 7 is the number of correct results, and they add to the ten examples. The exponents appear because independent events multiply, so ten factors collapse into two powers.

3. How many patterns there are

A pattern with three errors is completely determined by which three of the ten positions hold the E's. Everything else is forced: the remaining seven positions must be C's.

So the count is a choice of three positions out of ten, where the positions are distinct and their order is irrelevant, since a pattern does not record which error you decided on first. That is case 3 of the four boxes.

  1. The count. C(10, 3) ways to choose the three error positions.
  2. Evaluate it. C(10, 3) = 10! / (3! × 7!) = (10 × 9 × 8) / (3 × 2 × 1) = 720 / 6 = 120. The handout uses this value later, in the gaps argument on Part 8.
  3. The board's remark. C(10, 3) = C(10, 7). Choosing which three examples go wrong is the same act as choosing which seven go right, so the two counts must agree. It is a free sanity check on any binomial coefficient.

4. Multiplying the count by the price

The event "exactly three errors" is the union of 120 patterns. They are disjoint, because a single evaluation produces exactly one pattern, and they all carry the same probability. So the probability of the union is 120 copies of that shared value, which is a multiplication.

Pr(X = 3) = C(10, 3) (0.2)3(0.8)7 C(10, 3) counts the patterns with three errors and carries no probability at all: it is a plain integer. (0.2)3(0.8)7 is the probability of any one of them. The product is a count multiplied by the price each counted thing carries, and Part 7 checks that this multiplication is legal on a case small enough to list by hand.
This course's arithmeticThe lecture leaves the expression standing. Evaluating it: (0.2)3 = 0.008 and (0.8)7 = 0.2097152, so one pattern is worth 0.0016777216, and 120 of them come to Pr(X = 3) = 0.2013 to four places. A classifier with a twenty percent error rate produces exactly three errors on a ten-example evaluation about one time in five. Neither figure is on the board and neither carries a key-number mark.

5. The general shape, named on the board

Immediately after the answer, the class notes write a heading, binomial probabilities, and generalise. Nothing in the argument above used the numbers 10, 3 or 0.2, so the same four steps run with letters in their place.

Pr(k successes in n experiments) = C(n, k) pk(1 − p)n−k n is how many independent experiments are run, fixed in advance. p is the chance of success in each single experiment, the same for all of them. k is the number of successes being priced. C(n, k) counts which k of the n experiments are the successful ones. pk prices those k succeeding and (1 − p)n−k prices the other n − k failing. Note that "success" is just a label for the outcome being counted: on this page a success is an error, because errors are what X counts.

This is the formula Lecture 1, Part 3 used to price a run of extreme days, at a point where the course had no counting machinery and had to take it on trust. Everything in it has now been built: the coefficient is Lecture 4, Part 11 and the two powers are Lecture 3, Part 8.

6. Two checks the board runs on it

The class notes immediately apply the general formula twice, and both applications are checks rather than new problems.

  1. A fair coin. Set p = 1/2 and the formula gives C(10, 3)(1/2)3(1/2)7, which the notes collapse to C(10, 3) · 1/210. The two powers merge because 1/2 and 1 − 1/2 are the same number. This course's arithmetic: that value is 120/1024 = 0.1172. This is the one case where every pattern really is equally likely, and Part 6 is about what goes wrong when a reader assumes it in general.
  2. Everything adds to one. The notes write ∑k=0..n C(n, k) pk(1 − p)n−k = 1, with the reason underneath it: the sum is (p + 1 − p)n, which is 1n. A run of n experiments produces some number of successes between 0 and n, and the formula accounts for every one of those possibilities exactly once.

The second check is the more useful of the two in practice, because it catches a wrong coefficient immediately. If a set of binomial terms does not add to one, something in them is wrong, and the check costs nothing.

7. Check yourself

Why does every pattern with exactly three errors carry the same probability?
Each pattern contributes seven factors of 0.8 and three of 0.2, and a product does not depend on the order its factors are written in, so all 120 patterns are worth 0.0016777216 each. No pool is being drawn from here: the ten examples are independent trials, not a sample without replacement, which is the previous problem in this lecture and a different structure. The coefficient counts patterns and rescales nothing; it is a plain integer sitting outside the probabilities. And one over two to the tenth would be the value only if the error rate were 0.5, which it is not.
What does the factor C(10, 3) count in this answer?
A three-error pattern is fixed once you say which three positions hold the E's, so the coefficient counts exactly that set of choices, and it comes to 120. How many errors the classifier makes is X itself, a quantity the question has already fixed at three. Order is not counted here at all: a set of three positions is unordered, and counting orders would give 10 times 9 times 8, which is 720 and six times too large. And the coefficient is an integer, not a probability, so it cannot be how likely anything is.
Your teacher. Read the formula aloud as an English sentence every time you write it: how many ways it can happen, times how much each way costs. Two nouns, one verb. Almost every mistake with the binomial comes from blurring those two halves, usually by trying to put a probability inside the coefficient or a count inside the powers. If you can say which half of the formula each symbol belongs to, you own it; if you cannot, you have memorised a string.
