A poll calls the wrong winner exactly when one CDF value says it does

working 11 min The first worked application in Lecture 7: an election, a polling company, and a binomial hiding inside both.

After this page

  • You can turn a described sampling procedure into a named random variable, by writing it as a sum of indicators.
  • You can say why a poll's error probability is a CDF value rather than a PMF value, and evaluate it.

Before you start: the binomial as a distribution, for the PMF this page evaluates, and the CDF is a running sum, for what a running sum of that PMF means.

The one-minute version

  • An election has two candidates. 60% of the population supports A, and nobody knows that before election day.
  • A polling company samples n people and names whichever candidate holds the majority of that sample.
  • Each sampled person contributes a 1 or a 0, so the count X is a sum of n indicators and X ~ Bin(n, p) with p = 0.6.
  • The poll errs on the event X ≤ n/2, rounded down, which is a CDF value rather than a PMF value.
  • At n = 5 that value is P(X ≤ 2) = 0.3174, so five people misname the winner about a third of the time.

1. The setup, exactly as the lecture states it

An election is coming with two candidates, A and B. The population splits 60% for A and 40% for B, and the lecturer is explicit that this is ground truth nobody knows before the election. A polling company samples a subset of size n, asks each person who they support, and predicts the majority of that sample.

The true winner on election day is A, so the poll is wrong precisely when A fails to hold the majority among the n people asked. Everything on this page is the probability of that one event.

2. The count is a sum of indicators, so it is binomial

Write X for the number of sampled people who support A. The lecture builds X from the bottom up: one indicator per person polled, worth 1 if they support A and 0 if not.

X = ∑i = 1n 1{i-th sampled person supports A} X is the number of sampled people who support candidate A. n is how many people were polled. i runs over those people, one at a time. 1{...} is the indicator of the event in the braces: it is 1 when that person supports A and 0 when they support B. Adding n of those zeros and ones counts the ones, so the sum is exactly the number of supporters of A in the sample.

Each indicator is a Bernoulli variable with parameter p: it is 1 with probability p and 0 with probability 1 − p, and here p = 0.6, because a randomly chosen member of a 60% population supports A with chance 0.6. The lecture requires one more thing, and states it as an assumption rather than deriving it: the n people decide independently of each other.

A sum of n independent Bernoulli trials, counting the successes, is the binomial. Hajek, section 2.4.4, page 38 defines it in exactly those words and derives the same PMF the lecture writes.

X ~ Bin(n, p)   with   P(X = k) = nCk pk (1 − p)n − k X is again the count of supporters of A in the sample. n is the number of people polled, called the number of trials. p is the chance a single sampled person supports A, here 0.6. k is one particular count you might ask about, any whole number from 0 to n. nCk, read "n choose k", counts how many of the n people could be the k supporters. pk is the chance that those k specific people all support A, and (1 − p)n − k is the chance the remaining n − k all support B.
The move worth keepingNothing in the story said "binomial". The lecture built the binomial by writing each person as a zero or a one and adding. That is the reusable step: when a procedure produces a count of yes-or-no answers over a fixed number of independent tries, the count is binomial, and you do not have to recognise it, you can derive it.

3. Why the error is a CDF value and not a PMF value

The poll is wrong when A is not in the majority. With n = 5 a majority needs 3 or more, so the poll is wrong when X is 0, 1 or 2. That is three outcomes, and the PMF answers about one outcome at a time.

P(poll predicts incorrectly) = P(X ≤ 2) = FX(2) FX is the cumulative distribution function of X. FX(2) is the probability that X lands at 2 or anywhere below it, which is the running total of the PMF from 0 up to 2. The event "the poll is wrong" is the whole left-hand end of the distribution, and the CDF is the object that reports a whole left-hand end in one number.

NIST's e-Handbook gives F(x) = Pr[X ≤ x] and, for a discrete variable, the sum of the mass up to x; Hajek, section 3.1, page 95 defines it identically. The CDF turns up here for one reason: the question asked is a threshold question.

4. The arithmetic, worked

The lecture writes one line, sums the binomial PMF from k = 0 to k = 2, and says the answer is roughly 0.3. Here is that line expanded.

  1. Write the three terms. P(X ≤ 2) = P(X = 0) + P(X = 1) + P(X = 2), because those are the three ways the poll can be wrong and they cannot happen together.
  2. The k = 0 term. 5C0 = 1, so the term is 1 × 0.60 × 0.45 = 1 × 1 × 0.01024 = 0.01024. Everyone polled supports B.
  3. The k = 1 term. 5C1 = 5, so the term is 5 × 0.6 × 0.44 = 5 × 0.6 × 0.0256 = 0.0768.
  4. The k = 2 term. 5C2 = 10, so the term is 10 × 0.36 × 0.43 = 10 × 0.36 × 0.064 = 0.2304.
  5. Add them. 0.01024 + 0.0768 + 0.2304 = 0.31744, which rounds to 0.3174.

The lecturer's board figure is ≈ 0.3. The four-place value 0.3174 is this course's arithmetic, computed from the formula above, and it agrees with him.

Read back in the language of the problem: poll five people in a country that is 60:40 for A, and roughly one poll in three announces B. The lecturer's own reading is that this is unsurprising, because five people is far too few.

5. Check yourself

Retrieval practice

Answer from memory before revealing.

Why is the poll's error probability a CDF value rather than a PMF value?
The poll fails on every count from 0 up to the majority threshold, and a CDF is the object that reports a run like that in one number. Ease of evaluation is not the reason: both are the same sum, and the CDF is that sum written down once. The count is a whole number and firmly discrete, which is why the CDF is a staircase here. And speed is not a property of the object at all; the third option restates the first in different words.
What makes the count of supporters binomial rather than merely a count?
The binomial is defined as the number of successes in a fixed number of independent Bernoulli trials, and the sum of indicators is that definition written out. A known population split supplies the value of p but does not make the count binomial: without independence the same p gives a different distribution. Two candidates make each answer binary, which is necessary but not sufficient. And the reporting rule is what turns the count into a prediction afterwards; it plays no part in the count's own distribution.

Practice about 10 minutes, with paper

Practice 1working

Keep the same election, p = 0.6, but poll only three people. The poll still names the sample's majority.

Find the probability that the poll names the wrong winner, working every term.

Hint

With three people a majority is 2 or more, so the poll is wrong when the count is 0 or 1. That is F(1) for a Bin(3, 0.6).

Show the worked solution
  1. Name the event. The poll is wrong when X ≤ 1, so the answer is P(X = 0) + P(X = 1).
  2. The k = 0 term. 3C0 = 1, so it is 1 × 0.60 × 0.43 = 0.064.
  3. The k = 1 term. 3C1 = 3, so it is 3 × 0.6 × 0.42 = 3 × 0.6 × 0.16 = 0.288.
  4. Add them. 0.064 + 0.288 = 0.352.

Sanity check. Three people is fewer than five, so the answer must be worse than the 0.3174 this page computed for n = 5, and 0.352 is. It must also stay below 0.5, because A is the more likely answer from every single person; a value above a half would mean the arithmetic named the wrong candidate.

Carry this away

  • A count of yes-or-no answers over n independent tries is binomial, and you reach that by writing each try as an indicator and adding, not by recognising a name.
  • A question about a threshold - at most this many, fewer than that - is a CDF question, and the CDF is the running sum of the mass function up to that point.
  • Five people polled in a 60:40 country leaves a 0.3174 chance of naming the loser, so a small sample is not a slightly worse poll, it is close to a coin toss.

Next: how many people must you poll, which takes this one CDF value and asks what happens to it as n grows, which is the question a polling company actually has to answer.

Your teacher. If the jump from "a poll" to "a binomial" felt like a leap, do it once by hand rather than reading it again. Take n = 4, write out all sixteen sequences of A and B, mark the ones with two or fewer A's, and add their probabilities using 0.6 for each A and 0.4 for each B. You will get the binomial PMF back, term by term, with the choose-coefficients appearing as the number of sequences that share a count. That exercise is what makes the indicator sum feel like a description of the procedure rather than a formula placed on top of it.
