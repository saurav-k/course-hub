Lecture 6 · Part 2 of 14 · the definition

Nothing about a random variable is random, and the notes say so outright

10 min the unlock One definition, one drawing, and one correction to a name that has misled readers for a century.

The one-minute version

  • The definition is one line. A random variable is a function X from the sample space to the real line, written X : Ω → R, satisfying certain properties.
  • The notes then say the name is a bit of a misnomer, and give the reason: X is a deterministic function mapping an outcome from a probability space to a real number.
  • So there are two separate things and only one of them is random. The function is fixed before the experiment runs. The argument it gets called with is what the experiment chooses.
  • Getting that split right is the single highest-value thing on this page. Almost every later confusion in probability is a reader who has quietly let X become "a number that wobbles".
  • The notes say "satisfying certain properties" and never say which. This page says what the phrase is guarding, and does not go further than the notes do.

1. The definition, in the notes' own words

After the two examples of Part 1, the notes generalise in a single sentence: a random variable is essentially a function X : Ω → R satisfying certain properties.

X : Ω → R X is the name of the function, capitalised by convention so that a random variable is visibly not an ordinary variable. Ω is the domain, the sample space, so the thing you feed in is one outcome of the experiment. The arrow means "maps to". R is the codomain, the real numbers, so what comes back is always a single real number. Read the whole line aloud as "X takes an outcome and gives back a real number".

Both examples from Part 1 fit this shape exactly. The head-count function takes a string of H and T and gives back an integer. The dice-sum function takes an ordered pair of faces and gives back an integer. Integers are real numbers, so both are random variables under this definition.

2. Why the name is wrong

The notes follow the definition with a remark, and it is not a throwaway. In their words: the term "random variable" is a bit of a misnomer, because it is a deterministic function mapping an outcome from a probability space to real numbers.

Take the two halves of the name in turn.

  • "Variable" is wrong because X is not a variable at all. It is a function. A variable holds a value; a function is a rule that produces one from an input. The notation X(ω) makes this visible, and the reason people forget is that probability almost always writes the shorter X and leaves the argument implicit.
  • "Random" is wrong because the rule has no randomness in it anywhere. Given an outcome, the value is fixed and computable. There is nothing to sample, nothing to simulate and nothing to wait for. You can write out the whole map on paper before the experiment exists.

So where does the randomness live? In exactly one place: which outcome the experiment produces. That is the only uncertain thing in the entire construction, and it was already the only uncertain thing before this lecture began. The random variable does not add uncertainty; it inherits it.

Running the experiment does not write this table, and it does not edit it. It puts a finger on one row. That is the whole of what "the experiment happened" means, once a random variable is in play.

4. What "satisfying certain properties" is guarding

The notes write "satisfying certain properties" and do not say which properties. That is a deliberate compression in an engineering course, and this course keeps it compressed for the same reason: measure-theoretic probability is out of scope here.

What can be said honestly, from these notes alone, is what the phrase is protecting. Two pages later the notes define the CDF as

FX(x) = P( { ω : X(ω) ≤ x } ) The braces hold a set of outcomes: all the outcomes on which X gives a value no bigger than x. P is then applied to that set. But P is only defined on members of F, the collection of events fixed back in Lecture 2, Part 4. So for this line to mean anything, the set inside the braces has to be an event.

That is the property. A function from Ω to the reals is a random variable when the sets it carves out this way are events, so that P can be applied to them. Any function on a finite or countable sample space where every subset is an event automatically qualifies, which covers every example in this lecture.

The notes state the phrase and never expand itNothing in the eight pages says what the certain properties are. The paragraph above is this course's reading of what the phrase is for, drawn from the notes' own later definition of the CDF and from the sigma-field this course already built. It is not a statement the source makes, and it is not the formal condition, which belongs to the measure theory MISSION.md puts out of scope. If you want the precise version, Grimmett and Stirzaker state it; this course will not.

5. Reading the notation without stumbling

Three shorthands appear from here on, and all three drop the argument. They are worth decoding once, slowly, because every later page uses them.

  1. Writing X where X(ω) is meant. Probability almost never writes the argument. When you see X standing alone, read it as "the value this function will give on whichever outcome occurs".
  2. Writing {X = 2} as if it were a set of numbers. It is not. It is shorthand for {ω : X(ω) = 2}, a set of outcomes. For three tosses that set is {HHT, HTH, THH}, which has three members and lives in Ω.
  3. Writing P(X = 2). Unpack it in two steps. First, X = 2 names the event above. Second, P prices that event. So the expression means "the probability that the experiment produces an outcome on which X happens to give 2", and it is a perfectly ordinary event probability of the kind Lecture 3 already handled.
This course's arithmeticFor three tosses of a fair coin every outcome has probability 1/8, so the event {X = 2} = {HHT, HTH, THH} has probability 3/8. The notes state no such value on this page and no fairness assumption is made in them either. This figure is here only to show what the notation unpacks into, and it is not the lecturer's.

6. Check yourself

The notes call "random variable" a misnomer. What exactly is misnamed?
X is a deterministic function from outcomes to numbers, so calling the function random misdescribes it, and calling it a variable misdescribes it a second time. The values are not the problem: they are ordinary real numbers and nobody claims otherwise. The outcome is the one genuinely uncertain object here, so it is the part of the picture the name should have been attached to, not the part that is wrongly named. And P being a function is true but is not what the notes are objecting to; the remark is specifically about the phrase "random variable".
In the three-toss experiment, what kind of object is the expression written as X = 2?
It is shorthand for the set of outcomes on which X gives two, which for three tosses is HHT, HTH and THH, so it is an event and P can be applied to it. It is not a number: the number 2 appears inside the shorthand but the expression as a whole names the outcomes that produce it. It is not a probability either, since no probability has been applied yet; that step is what writing P around it does. And the function is X itself, which appears in the expression but is not what the expression denotes.
Your teacher. Say this out loud once and it will stay with you: the coin is random, the counting is not. Nobody thinks that counting heads is a random act. The act of counting is completely mechanical, and if two people count the same string they get the same answer or one of them made a mistake. All the uncertainty was spent when the coins landed. Every time a later formula starts to feel slippery, come back and ask which part of it is the coins and which part is the counting.
