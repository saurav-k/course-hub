Every exact value is worth zero, so the strict and non-strict signs stop mattering

working 12 min Implication 4 of the definition, the two student questions it drew, and the one practical rule it buys.

After this page

  • You can reproduce the shrinking-band sketch for P(X = a) = 0 and say which step is an approximation.
  • You can swap < for ≤ on a continuous variable without hesitating, and refuse to on a discrete one.
  • You can answer the objection that the probability only tends to zero.

Before you start: a density is not a probability, because this page shrinks that page's interval down to nothing.

The one-minute version

  • Implication 4: P(X = a) = 0 for every real a, on any continuous random variable.
  • The argument is a shrinking band: P(a − δ < X ≤ a) is about δ × fX(a), and δ is sent to 0.
  • A student asked whether that is zero or only tends to zero. It is zero, because the limit is taken rather than approached.
  • The payoff: for a continuous variable < and ≤ may be swapped freely. For a discrete one they may not, and the gap is the mass at the endpoint.
  • The cost: this is called a sketch on the board, not a proof, and this page keeps that label.

1. The shrinking-band sketch

The lecturer boxed the fourth implication and then argued for it in four moves. The move that matters is the first: he looked not at the point but at a narrow band ending on it.

P(X = a) = limδ→0 P(a − δ < X ≤ a) = limδ→0 ∫a−δa fX(z) dz ≈ limδ→0 δ · fX(a) = 0 Read as: a is the exact value being asked about. δ is the width of a narrow band sitting just to the left of a, and it is a positive number about to be made as small as you like. limδ→0 means "the value this settles on as δ is made smaller without limit". fX is the density and z is the dummy integration variable. fX(a) is the height of the density at a, one fixed finite number. The line says: the band's probability is its area, that area is roughly its width times its height, and driving the width to nothing drives the whole product to nothing.
  1. Replace the point with a band. Ask instead for P(a − δ < X ≤ a), a band of width δ whose right-hand end is a.
  2. Turn the band into an area. By implication 3 that probability is the integral of fX from a − δ to a.
  3. Approximate the area. Over a very short stretch the density hardly changes, so the strip is close to a rectangle: width δ times height fX(a). This is the only approximate step.
  4. Send the width to zero. fX(a) is a fixed finite number and δ is heading to 0, so the product heads to 0 with it.
  5. Take the limit rather than stopping near it. The limit of that product is exactly 0, so P(X = a) = 0.

Watch the shape of the argument. The height never moves and the width does all the work, which is why the result holds at every a, including a point where the density is large.

This course's arithmeticThe three areas are worked here on the uniform density with f = 0.25 on [0, 4]: the band area is width × 0.25, giving 0.100, 0.025 and 0.005 at widths 0.40, 0.10 and 0.02. The lecture states implication 4 with a symbolic band and draws no numbers, so none of these is the lecturer's.

2. Is it zero, or does it only tend to zero?

A student asked exactly this, and it is the sharpest question in the session: the band never actually has zero width, so should the answer not be "approaching zero"?

The reply drew the distinction the argument rests on. P(X = a) is not about X landing near a; it is about X taking that value and no other. The band is only a device, and it is finished by taking the limit rather than stopping at some small width. A limit that is taken produces a number, and here that number is zero. In the lecturer's words: "when I say X equal to A, I'm not saying X close to A."

A sketch, and the board says soThe board calls the band argument a way to see the result, not a derivation of it, and the rectangle step is written with an approximately-equals sign that is never discharged. The tidier route is available and the lecture does not take it: implication 1 says the CDF has no jumps, Lecture 6, Part 6 says the mass at a point is the size of the jump there, and no jumps means no mass. Hajek, Probability with Engineering Applications, Section 3.2, argues it that way round. This course teaches the sketch as delivered and names it a sketch.

3. What it buys: the signs stop mattering

Another student asked what the interval formula becomes when both ends are non-strict. The answer is the rule this page exists to earn.

A closed interval is a half-open one plus its left endpoint: P(a ≤ X ≤ b) = P(a < X ≤ b) + P(X = a). The second term is zero, so the two are the same number. Repeat at the other end and all four spellings of the interval agree. On a discrete variable that step is illegal, because P(X = a) is an actual mass and including or excluding a changes the answer by exactly that mass.

4. The lecturer's own illustration

Late in the session a student asked whether a continuous variable is just a discrete one with decimals. The reply is the cleanest statement of implication 4 in the class.

Pick a random number between 0 and 1. The probability of picking exactly 0.333 is zero. The probability of picking a number between 0.3 and 0.35 is, he said, a question he can answer. One question names a width and the other does not.

  1. Name the density. A number picked uniformly on [0, 1] has density 1 across the whole interval, since 1 ÷ (1 − 0) = 1.
  2. Answer the second question. P(0.3 ≤ X ≤ 0.35) = height × width = 1 × 0.05 = 0.05.
  3. Answer the first. The value 0.333 has no width at all, so height × width = 1 × 0 = 0.
  4. Read the contrast. Zero probability does not mean impossible. The pick has to land somewhere, and wherever it lands is a value that carried probability zero before the pick.

Check yourself

Retrieval practice

Answer from memory before revealing.

A student says P(X = a) only tends to zero. What is the reply?
The band is a device for reaching the point and the argument finishes by taking the limit, which yields a number, and that number is zero. Keeping a width means answering a different question, about landing near a rather than on it. A bounded density is what makes the sketch work at all, so it is a condition rather than a hedge. And being outside the support gives zero for a second reason, while inside the support the answer is still zero.
Why may < and ≤ be swapped on a continuous variable but not a discrete one?
Including an endpoint adds P(X = a) to the answer, and that term is zero for a continuous variable and a genuine mass for a discrete one. A discrete sum is exactly where the open end matters, since the endpoint term drops in or out of the sum. A continuous variable does have a support and does have endpoints, and it is the mass at them rather than their existence that has changed. And boundedness makes the band argument work but is not itself the rule about the signs.

Practice about 10 minutes, with paper

Practice 1working

X is uniform on [0, 4], so its density is 0.25 on that interval and 0 elsewhere. Y is the number showing on a fair six-sided die.

Compute P(X < 1) and P(X ≤ 1), then P(Y < 3) and P(Y ≤ 3), and say which pair differs and by how much.

Hint

For X the answer is a rectangle's area both times. For Y write out which faces each inequality actually admits, and compare the two lists.

Show the worked solution
  1. Take the continuous pair. P(X < 1) is the area from 0 to 1 under a height of 0.25, so 1 × 0.25 = 0.25. P(X ≤ 1) adds P(X = 1), which is 0, so it is also 0.25.
  2. List the faces for the strict discrete case. Y < 3 admits 1 and 2, so P(Y < 3) = 2 ÷ 6 = 1/3.
  3. List them again for the non-strict case. Y ≤ 3 admits 1, 2 and 3, so P(Y ≤ 3) = 3 ÷ 6 = 1/2.
  4. Name the gap. The discrete pair differs by 1/2 − 1/3 = 1/6, which is exactly P(Y = 3), the mass sitting on the endpoint. The continuous pair differs by 0.

Sanity check. The gap in the discrete case has to be one face's worth of probability and 1/6 is exactly that, so an answer of 1/3 or 1/2 for the gap means an endpoint was counted twice or not at all. And 0.25 is a quarter of the range, which is what X < 1 covers on [0, 4].

Carry this away

  • P(X = a) = 0 for every value of a, argued by a band of width δ whose area is about δ times the density at a, with δ sent to zero.
  • It is zero and not merely close to it, because the argument ends by taking the limit rather than by stopping at a small width.
  • So the four ways of writing an interval all agree for a continuous variable, and differ by the endpoint masses for a discrete one.

Your teacher. The sentence that unsticks this one is that probability zero is not the same as impossible. If it still grates, ask an agent to run the argument backwards: have it pick a number uniformly on [0, 1] a thousand times and report how often each exact value repeats. It never does, and every single value that came up had probability zero before it was drawn. That is the whole paradox, and once you have watched it happen the result stops feeling like a trick and starts feeling like arithmetic about widths.
