Lecture 8 · Part 5 of 6 · the expected-value rule

A function of X averages against the old distribution, and expectation always adds

working 11 min Two results on one page of the notes, and both are labour-saving devices. One says you never have to derive a second distribution. The other says you never have to check independence before adding.

After this page

  • You can compute the average of any function of X, or of a pair X and Y, without first working out what that function's own distribution looks like.
  • You can prove that expectation adds, by running the double sum and watching each inner sum collapse into a marginal.
  • You can say exactly which expectation results need independence and which do not, and defend the answer with the proof rather than with a rule of thumb.

Before you start: Heavy tails and an infinite mean, for what has to be true before an expectation is worth computing at all.

The one-minute version

  • The expected value rule, widely known as LOTUS: E[g(X)] = ∑x g(x) pX(x). New value slot, same weights.
  • For two variables it is the same sentence with a double sum: E[g(X,Y)] = ∑x ∑y g(x,y) pXY(x,y).
  • What it saves is the whole detour of deriving the distribution of g(X) before you can average it.
  • Two consequences the notes call linearity: E[aX] = a E[X], which is a constant pulled out of a sum, and E[X + Y] = E[X] + E[Y].
  • The second one is proved by splitting one double sum in two and letting each inner sum marginalize the joint pmf.
  • The margin of the notes says it plainly: always true, and it does not need X independent of Y.

1. The detour you are allowed to skip

You know the distribution of X. You want the average of some transformed quantity: a squared error, a cost, a payoff, a bin count. The obvious route treats Y = g(X) as a new random variable, works out its pmf by collecting every x that maps to each value y, and then averages Y against that new pmf.

That route is correct and it is almost always wasted work. Nothing about the underlying experiment changed when you applied g. Each outcome still occurs with the probability it always had; g only relabels the value attached to it. So average the relabelled values against the original weights and stop.

2. The rule, with every symbol named

E[g(X)] = ∑x ∈ EX g(x) pX(x) X is the random variable, and it may be a random vector, which means a list of several random variables handled at once. g is any real-valued function you apply to it, such as squaring, a cost, or a payoff. EX is the support: the set of values X actually takes with positive probability. pX(x) is the pmf, the probability that X comes out exactly equal to x. g(x) sits in the value slot where a plain x sat when this was the ordinary mean.
E[g(X)] = ∫ g(x) fX(x) dx The continuous twin. fX is the density, whose integral over a region gives the probability of landing in it. For a random vector the single integral becomes a multiple integral, one for each component, over the whole space the vector lives in. dx is the width of the sliver being weighted.
E[g(X,Y)] = ∑x ∑y g(x,y) pXY(x,y) pXY(x,y) is the joint pmf: the probability that X equals x and Y equals y in the same run of the experiment. The two sums together sweep every cell of that joint table exactly once. The continuous version is the double integral of g(x,y) fXY(x,y) over both variables.

Bertsekas and Tsitsiklis state the single-variable form as the expected value rule for functions of random variables in Section 2.4 of Introduction to Probability, and extend it to E[g(X,Y)] in Section 2.5. They also derive it from the long route, which is the honest way to see that the two agree.

3. Linearity, part (a): a constant comes out

  1. Put the function in the slot. Take g(x) = ax, where a is a fixed number and not random. The rule gives E[aX] = ∑x (ax) pX(x).
  2. Factor the constant out of the sum. Every term carries the same a, so ∑x a x pX(x) = a ∑x x pX(x). This is ordinary distributivity, nothing probabilistic.
  3. Name what is left. The remaining sum is the definition of the mean, so E[aX] = a E[X].

The notes dispose of this one with the words "substitute in the formula", and that is fair: doubling every value doubles the average, whatever the weights are.

4. Linearity, part (b): the double sum that marginalizes

This is the result the rest of the lecture leans on, and it is worth watching closely, because the step where independence would have been needed never arrives.

  1. Apply the two-variable rule. Set g(x,y) = x + y. Then E[X + Y] = ∑x ∑y (x + y) pXY(x,y). The joint pmf is the only distribution in sight, and no assumption has been made about it.
  2. Split the bracket. Addition inside a finite sum separates: = ∑x ∑y x pXY(x,y) + ∑x ∑y y pXY(x,y). Two sums over the same table, each carrying half of the value.
  3. Work on the first term. In the inner sum over y, the factor x is a constant, so pull it out: ∑x x ( ∑y pXY(x,y) ).
  4. Collapse the inner sum. Adding the joint probabilities along a whole row, over every value y can take, gives the probability of that x on its own: ∑y pXY(x,y) = pX(x). That is marginalization, and it is a consequence of the events "X = x and Y = y" being disjoint and covering "X = x". The first term is now ∑x x pX(x) = E[X].
  5. Do the same to the second term. Swap the order of summation, hold y fixed, and add down the column: ∑x pXY(x,y) = pY(y), leaving ∑y y pY(y) = E[Y].
  6. Add the halves back. E[X + Y] = E[X] + E[Y].
  7. Audit the proof for an assumption. Read back through it. The only facts used are that a finite sum splits, a constant factors out, and a row or a column of a joint table adds up to a marginal. None of those is a statement about independence, so the identity holds for any joint distribution at all.

5. Which results need independence, and which do not

The notes write the point in the margin as a flat sentence: always true, does not need X independent of Y. It is worth separating from the result on the next page but one, which does need it.

The notes prove the discrete case only, and state the rule for the restEvery proof on this page is written for discrete X and Y, with sums over a joint pmf. The notes give the continuous forms as definitions, with integrals in place of sums, and do not repeat the argument there. The continuous proof is the same three moves with an integral sign, and it needs the joint density to be integrable for the split in step 2 to be legitimate. That condition is not mentioned in the source and is not a formality: Part 3 already met a variable whose average does not exist, and adding two of those does not produce a valid identity. Read linearity as holding whenever the expectations on the right-hand side both exist, which covers everything the rest of this lecture does with it.

Check yourself

Retrieval practice

Answer from memory before revealing.

Why can E[g(X)] be computed without ever deriving the distribution of g(X)?
Applying g relabels the value attached to each outcome and moves no probability, so the old weights are still the right weights. The first option restricts the rule to linear g, but the rule holds for any real-valued g, which is exactly why it can produce a second moment. The third is false and irrelevant: g may map several values of x to one value, and the rule handles that by counting each x separately. The fourth imports independence, which plays no part here, since only one variable is involved.
What must be true of X and Y for E[X + Y] = E[X] + E[Y] to hold?
The proof uses only splitting a sum, factoring a constant, and adding a row or a column of the joint table into a marginal, so no structural assumption is left over. The first option names the condition the product rule needs, not the sum rule. The second names a weaker condition that is also unnecessary here, and there is no cross term in a sum to drop. The fourth is invented: the two sums range over their own supports independently and never need to match.

Practice about 10 minutes, with paper

Practice 1working

Roll one fair die and let X be the face shown, so X is uniform on 1 to 6. Let Y = 7 − X, which is the face on the opposite side. X and Y are about as dependent as two variables can be.

Find E[X2] using the rule and not a new distribution, then E[X + Y], then E[XY], and say which of the two linearity claims survives the dependence.

Hint

Every probability here is 1/6. For E[X2] put the squared value in the value slot and leave the weights alone. For E[XY] you cannot add: write XY as a single function of X and use the rule once.

Show the worked solution
  1. The mean first. E[X] = (1 + 2 + 3 + 4 + 5 + 6)/6 = 21/6 = 3.5.
  2. Second moment by the rule. E[X2] = ∑ x2 times 1/6 = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6 = 15.1667. No distribution of X2 was written down, which is the point.
  3. Check it against the long route once. X2 takes the six values 1, 4, 9, 16, 25, 36, each with probability 1/6, so its mean is the same 91/6. Doing this once is worth it; doing it every time is the waste the rule removes.
  4. The mean of Y. By the rule with g(x) = 7 − x, E[Y] = ∑ (7 − x)/6 = (6 + 5 + 4 + 3 + 2 + 1)/6 = 3.5.
  5. The sum. X + Y is 7 on every single roll, so E[X + Y] = 7, and E[X] + E[Y] = 3.5 + 3.5 = 7. Linearity holds exactly, on a pair where knowing X tells you Y completely.
  6. The product. XY = X(7 − X) = 7X − X2, so E[XY] = 7(3.5) − 15.1667 = 24.5 − 15.1667 = 9.3333, which is 28/3.
  7. Compare with the factored version. E[X] E[Y] = 3.5 times 3.5 = 12.25, which is not 9.3333. The sum rule survived the dependence and the product rule did not.

Sanity check. E[X2] must exceed E[X]2 = 12.25 for any variable that is not constant, and 15.1667 does, by 35/12 = 2.9167, which is the variance worked in the variance pre-read. E[XY] must also be at most the largest possible product on any roll, which is 3 times 4 = 12, and 9.3333 is. Every decimal here is this course's own arithmetic, not the lecture's.

Carry this away

  • The expected value rule puts a new value in the slot and keeps the old weights, so no second distribution is ever derived.
  • It reads the same for a random vector and for a pair, with one sum or integral per variable.
  • E[X + Y] = E[X] + E[Y] is proved by splitting a double sum and letting each inner sum add a row or a column into a marginal.
  • Independence appears nowhere in that proof, so the sum rule is free, while the product rule later has to buy the same convenience.

Your teacher. If linearity still feels like it ought to need independence, the cure is the die above rather than another reading of the proof. X and Y there are locked together, and their means still add, because an average is a weighted sum and sums do not care where the weights came from. Then ask an agent to generate a joint table of your own choosing, deliberately lopsided, and to check both identities on it numerically: the sum rule will hold to the last decimal and the product rule will miss, and the size of the miss is the covariance you meet in the covariance pre-read.

For citable statements of the same two results see Section 2.4 of Bertsekas and Tsitsiklis, Introduction to Probability, which boxes the expected value rule for functions of random variables and derives the mean of a linear function, and Section 2.5 of the same chapter, which extends the rule to E[g(X,Y)] over a joint pmf, obtains each marginal by adding a row or a column of the joint table, and states E[aX + bY + c] = aE[X] + bE[Y] + c.
