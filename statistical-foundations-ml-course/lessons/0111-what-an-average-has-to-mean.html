An average of many runs collapses into a single weighted sum

foundation 11 min The notes do not define expectation and then justify it. They run the experiment N times first, watch the arithmetic rearrange itself, and let the definition fall out of the rearrangement.

After this page

  • You can derive the discrete definition of expectation from a run of N experiments, without skipping the step where the counts turn into probabilities.
  • You can read the continuous definition as the same sum with the sum sign changed, and say what the density is doing in the value slot.
  • You can compute the mean of a uniform variable on [a, b] from the integral rather than quoting the midpoint.

Before you start: Lecture 8, the map, for what this session delivers and the honesty notes it carries.

The one-minute version

  • A random variable hands you a real number every time the experiment runs. Expectation is what those numbers average to over a very long run.
  • Run it N times, let Nk count the runs where the value was k, and the plain average is Σk k · (Nk/N): each value times the fraction of runs it appeared in.
  • The frequency Nk/N settles on the probability pX(k) as N grows. The notes assert that and mark it "we will formalize this later".
  • Swap the frequency for the probability and the average becomes the definition: E[X] = Σk k pX(k), a weighted average of the values X takes.
  • For a density, the sum becomes an integral: E[X] = ∫ x fX(x) dx. The uniform on [a, b] gives (a+b)/2, the midpoint, and the integral confirms what symmetry already suggested.

1. The picture: one number to stand for a whole distribution

A random variable is a rule that assigns a real number to each outcome, so every run of the experiment produces a number. A whole distribution is a lot of information: one probability for every value the variable can take. Expectation is the first attempt to compress all of it into a single representative number, and the compression is deliberately lossy.

Bertsekas and Tsitsiklis motivate it with a wheel of fortune in Section 2.4 of Introduction to Probability: spin it k times, collect a payout each spin, and ask what you receive per spin. Our lecturer's notes ask the same question with no story attached, which is why the algebra is easier to see.

2. The mechanism: from a run of N to a weighted sum

Take X discrete, with probability mass function pX and support EX, the set of values X can actually take. Run the experiment N times.

  1. Count the runs by value. Let Nk be the number of runs in which X came out equal to k. Every run lands on exactly one value, so the counts add to N: Σk Nk = N.
  2. Total up what was observed. The value k was seen Nk times and each sighting contributes k, so the sum over all N runs is Σk k Nk.
  3. Divide by N to get the ordinary average. (1/N) Σk k Nk = Σk k · (Nk/N). Nothing probabilistic has happened yet; this is the arithmetic mean of a list of observed numbers, regrouped by value instead of by run.
  4. Read the new factor. Nk/N is the fraction of runs that produced k. The notes annotate this line exactly that way: value times fraction of times k observed.
  5. Let N grow. The notes assert that Nk/N → pX(k) and add "we will formalize this later in the course". That formalisation is the law of large numbers, and it is not available yet.
  6. Take the limit. E[X] = limN→∞ Σk k (Nk/N) = Σk∈EX k pX(k). The counts have gone and the probabilities have taken their place.

Step 5 is doing real work and is worth being uncomfortable about. It is an assumption at this point in the course, borrowed on credit against a theorem the syllabus has not reached. Everything after step 5 is a definition, and a definition needs no proof; only the motivation for choosing it does.

E[X] = Σk ∈ EX k · pX(k) E[X] is the expectation, or mean, of X, a single real number, not a random one. X is the random variable, the rule turning each outcome into a number. k is one particular value X can take. EX is the support: the set of all values X can take with non-zero probability. pX(k) is the probability mass function, the probability that X comes out exactly k. The Σ adds one term per value in the support. The notes name the result in words: a weighted average of the values X takes, with each value weighted by its own probability.

3. Watching the frequencies settle

The figure below is this course's own simulation, not the lecture's: the notes contain no numbers anywhere. A variable takes the values 0, 1, 2 and 3 with probabilities 0.45, 0.25, 0.20 and 0.10, so its weighted sum is fixed before a single run happens.

This course's arithmetic. The weighted sum for that variable is 0(0.45) + 1(0.25) + 2(0.20) + 3(0.10) = 0 + 0.25 + 0.40 + 0.30 = 0.95. Twenty thousand simulated runs of it gave a running average of 0.9499, with observed frequencies 0.4512, 0.2470, 0.2024 and 0.0993 against the four probabilities above. Neither the variable nor any of these numbers appears in the source notes.

4. The continuous version, and one question the notes leave open

A continuous variable has no values with non-zero probability, so there is nothing to count and no Nk to form. The notes simply write the second definition alongside the first.

E[X] = ∫−∞∞ x · fX(x) dx x is a value on the real line, taking the role k had. fX(x) is the probability density function: not a probability, but a probability per unit length, so that fX(x) dx is the probability of landing in a sliver of width dx at x. The ∫ replaces the Σ and runs over the whole real line. Read it as before: a value, times the weight attached to that value, added up.
The notes ask in the margin whether there is one definition rather than twoBeside the continuous definition the lecturer writes general defn of expectation? and moves on. The two lines above genuinely are different objects, one a sum over a countable support and one an integral against a density, and neither covers a variable that is part discrete and part continuous. There is a single definition that covers all three, the measure-theoretic one, which integrates the random variable against the probability measure itself rather than against a mass function or a density. This course does not develop it: MISSION.md puts measure theory out of scope, and the delivered session never returned to the question either. Take the two definitions as two faces of one idea, note that the question was asked, and expect no answer here.

5. The first worked example: the uniform on [a, b]

The uniform density from Lecture 7, Part 9 is flat: every point in [a, b] carries the same weight 1/(b − a), and everything outside carries zero. The notes work its mean as the first example of the definition.

  1. Write the integral with the density in place. Outside [a, b] the density is zero, so those parts contribute nothing and the limits shrink to a and b: E[U] = ∫ab x · (1/(b − a)) dx.
  2. Pull the constant out. 1/(b − a) does not depend on x, so E[U] = (1/(b − a)) ∫ab x dx.
  3. Integrate. The antiderivative of x is x2/2, so the integral is [x2/2]ab = (b2 − a2)/2.
  4. Factor the difference of two squares. b2 − a2 = (b − a)(b + a). This is the step the notes compress into the answer.
  5. Cancel. E[U] = (b − a)(b + a) / (2(b − a)) = (a + b)/2. The width of the interval cancels completely, so only its midpoint survives.
  6. Check it against the picture. A flat density is symmetric about its midpoint, so anything that deserves the name "centre" had to land there. The integral agrees, which is the reassurance you want the first time a definition is used.

6. What the room asked, and what the answers settle

The delivered session spent almost half its length on questions from the floor, and four of them are worth carrying because each one repairs a misreading a solitary reader is about to make.

  • "Isn't the expected value just the mean?" The lecturer's correction was one word long: it is a weighted average, not a plain one. A plain average adds every value the variable can take and divides by how many there are, which would give the same weight to a value seen once in a thousand runs as to a value seen half the time. Here each value k carries the weight pX(k), and those weights add to one by construction.
  • "What is the support?" The set of values the variable can actually take: 0 and 1 for a Bernoulli, every natural number for a geometric, every non-negative real for an exponential. Nothing more.
  • "For a continuous variable, between what limits do we integrate?" The whole real line, always. If the density is zero on part of it, that part of the integral is zero and the limits collapse on their own, which is what happens for the exponential and for the uniform in section 5 above. The lecturer refused to give a shorter rule and worked examples until the collapse was visible.
  • "What is the difference between the mean and the expectation?" The distinction the lecturer drew is worth keeping. The expectation is a statistical average: a number computed from the distribution itself, before any data exists. The mean of a sample is a time average: a number computed from values you actually observed. They are two different objects, and the claim that the second approaches the first as the sample grows is the law of large numbers, which the course has not reached.
The convergence this page leans on is still assumed, twice over. Step 5 of the derivation borrows Nk/N → pX(k) on credit, and the answer to the fourth question above borrows the same theorem again in a different guise. The lecturer named it both times and both times deferred it: "we will formalize this notion ... this is done via this notion of law of large numbers". Nothing on this page proves it, and nothing later in this lecture does either.

Check yourself

Retrieval practice

Answer from memory before revealing.

In the derivation, what does the factor Nk/N stand for before any limit is taken?
Before the limit it is pure bookkeeping on observed data: how many of the N runs landed on k, divided by N. The first option is what it becomes only after N grows, and treating it as a probability from the start assumes the very step the notes defer. The second names the size of the support, which appears nowhere in that ratio. The fourth is the whole weighted sum, not one of its factors.
Why does the width of the interval vanish from the mean of a uniform on [a, b]?
The height is one over the width, the integral of x produces a difference of squares that factors into the width times the sum of the endpoints, and the two widths cancel. The second option is false: a uniform is defined over any finite interval. The third is a true fact about densities that plays no part in this cancellation, since the x in the integrand is what makes this a mean rather than a total probability. The fourth is false in general, as the skewed shapes in Part 4 will show.

Practice about 10 minutes, with paper

Practice 1warm-up

A build pipeline retries a flaky step. The number of retries X takes the values 0, 1, 2 and 3 with probabilities 0.5, 0.3, 0.15 and 0.05.

Find E[X] from the definition, then say how many retries you would budget for a thousand builds, and check the answer against the range of X.

Hint

Write one term per value: the value, times its probability. Then remember what the frequency argument said the sum is an average of, and scale it.

Show the worked solution
  1. Confirm the weights are a distribution. 0.5 + 0.3 + 0.15 + 0.05 = 1.00, so nothing is missing and no value has been double counted.
  2. Write one term per value. E[X] = 0(0.5) + 1(0.3) + 2(0.15) + 3(0.05).
  3. Evaluate each term. 0, then 0.30, then 0.30, then 0.15.
  4. Add them. E[X] = 0 + 0.30 + 0.30 + 0.15 = 0.75 retries per build.
  5. Scale to a thousand builds. The frequency argument ran the other way: the expectation is the long-run average per run, so a thousand runs total roughly 750 retries. That is a budget, not a guarantee, and this page has said nothing yet about how far a single thousand-build week can stray from it.
  6. Check against the range. X never leaves the interval from 0 to 3, so the mean must lie inside it; 0.75 does, and sits toward the low end, which matches half the builds needing no retry at all.

Sanity check. A mean outside the support is always an arithmetic error, since a weighted average of numbers between 0 and 3 with weights adding to one cannot escape that interval. A second check: raising the weight on 3 and lowering the weight on 0 must push the mean up, and it does.

Carry this away

  • The average of N runs, regrouped by value, is already a weighted sum: each value times the fraction of runs it appeared in.
  • Letting the fractions settle on the probabilities turns that observed average into the definition, and the settling itself is assumed here and proved much later.
  • The continuous definition is the same object with a density in the weight slot and an integral in place of the sum.
  • The uniform's width cancels and its midpoint survives, which is the first sign that a mean is a balance point.
