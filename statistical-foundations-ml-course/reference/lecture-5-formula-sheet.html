The two shapes: which one is in front of you

One question chooses between them. Can the same item come out twice, or does each draw remove what it takes?

The item goes back, or the trials repeatThe item stays out
What changes between draws Nothing. The chance p is the same on every trial and the trials are independent. The pool shrinks by one, so every draw faces different odds from the last.
The formula C(n, k) pk(1 − p)n−k C(50, r) C(950, 20 − r) / C(1000, 20)
Its name The binomial. Named on the board. The hypergeometric. This name is supplied by this course; neither source uses the word.
The lecture's own instance 10 test examples, error probability 0.2, exactly 3 errors. 20 images inspected from 1000, of which 50 are mislabelled.
Where Part 5 Part 4
Reading the table. The two shapes converge when the pool is enormous relative to the sample, because removing a few items from a very large pool barely moves the odds. They are built from exactly the same two ingredients, a count and a weight, and the difference is only in whether the weight is the same for every counted thing. The switch that chooses between them is the same replacement switch that picks a column in Lecture 4's four boxes.

The rule that limits all of this

FormulaRead it aloud asWhere
P(A) = ∑ω ∈ A P({ω}) The definition. A probability is the total of the weights of the outcomes inside the event, never a count of them. Everything else on this sheet is a special case of this line. Part 6
P(A) = |A| × w, when every outcome in A is worth w Count, then multiply. The sum collapses when all its terms are equal. This is the step that turns the count C(n, k) into the binomial, and it needs the equality checked, not assumed. Part 7
P(A) = |A| / |Ω|, only when every outcome weighs the same Lecture 4's formula, which is the line above with w = 1 / |Ω|. It is illegal on the classifier's error patterns, because a one-error pattern is sixteen times as likely as a three-error one. It becomes legal again at p = 0.5, and inside the conditional world of a fixed error count. Part 6

Problem 1: the mini-batch

FormulaRead it aloud asWhere
|Ω| = 1005 Five draws, each seeing all hundred examples, so five hundreds multiplied. Sampling with replacement and the outcome is an ordered list, which is case 1 of the four boxes. Every one of these lists carries the same weight. Part 1
Pr(all 5 distinct) = (100 · 99 · 98 · 97 · 96) / 1005 The falling product. The numerator counts the lists with no repeat, falling by one each slot because each draw has one more example it may not match. The denominator never falls, because the example goes back. Equivalently (100/100)(99/100)(98/100)(97/100)(96/100), five conditional probabilities multiplied. Part 1
Pr(both classes) = 1 − (0.6)5 − (0.4)5 The complement. A batch fails only by being all one class, and the two ways of doing that are disjoint so they simply add. The class notes write the same thing as 1 − (3/5)5 − (2/5)5. Part 2

Problem 2: the dataset quality check

FormulaRead it aloud asWhere
|Ω| = C(1000, 20) = 1000! / (20! · 980!) Twenty distinct images, order irrelevant, so case 3 of the four boxes. The handout states that these C(1000, 20) selections are equally likely, which is what licenses every ratio below. Part 3
Pr(X = 0) = C(950, 20) / C(1000, 20) The check finds nothing: all twenty inspected images came from the 950 correctly labelled ones. Cancelling the factorials turns this into twenty conditional probabilities, (950/1000)(949/999) and so on down to (931/981), in which both numbers fall. Part 3
Pr(X ≥ 1) = 1 − C(950, 20) / C(1000, 20) At least one mislabelled image found. The event subtracted is "every inspected image is correct". Subtracting "every inspected image is wrong" is the classic error and would give an answer of essentially 1. Part 3
Pr(X = r) = C(50, r) C(950, 20 − r) / C(1000, 20) One choice made in two stages, one per pool: r images out of the 50 bad ones and the remaining 20 − r out of the 950 good ones. The stages multiply because fixing r leaves no freedom about how many good images are needed. Part 4
Pr(X ≥ 2) = 1 − (Pr(X = 0) + Pr(X = 1)) The complement again, now with two terms taken off, because two-or-more fails in exactly two disjoint ways. On the class notes and not in the handout. Part 4

Problem 3: classification errors

FormulaRead it aloud asWhere
Pr(one three-error pattern) = (0.2)3(0.8)7 Ten independent factors collapsing into two powers: 0.2 wherever an error sits, 0.8 wherever a correct result does. The same for every pattern with three errors, whatever their positions, because a product ignores the order of its factors. Part 5
Pr(X = 3) = C(10, 3) (0.2)3(0.8)7 A count times a price. C(10, 3) = 120 is a plain integer counting which three positions hold the errors, and the powers price any one of them. The board also notes C(10, 3) = C(10, 7): choosing the errors is choosing the correct results. Part 5
Pr(k successes in n) = C(n, k) pk(1 − p)n−k The binomial, under that heading on the board. n independent experiments, each succeeding with the same probability p, and k of them succeeding. "Success" is only a label for what is being counted: here a success is an error. Part 5
∑k=0..n C(n, k) pk(1 − p)n−k = (p + 1 − p)n = 1 The sum check. A run of n trials produces some number of successes between 0 and n, and the formula accounts for every possibility exactly once. Run it whenever a set of binomial terms looks wrong: it costs nothing and it catches a bad coefficient at once. Part 5
Pr(2 errors in 4) = |A| · (0.8)2(0.2)2 The bridge from counting to the binomial, checked on a case small enough to list: six configurations, all worth the same, so the probability is six times that shared value. Put |A| = C(n, k) and the shared value = pk(1 − p)n−k and the general formula is this line. Part 7
Pr(A | B) = Pr(A ∩ B) / Pr(B) Conditional probability, unchanged from Lecture 3. Used twice in this lecture, once for adjacency given three errors and once for three errors given one named image. Part 8
Pr(adjacent | X = 3) = 1 − C(8, 3)/C(10, 3) = 1 − 56/120 = 8/15 The gaps argument. Lay the 7 correct results down first, which creates 8 gaps. At most one error per gap keeps them apart, so C(8, 3) = 56 patterns are non-adjacent out of C(10, 3) = 120. The weight (0.2)3(0.8)7 cancels top and bottom, so the error rate does not appear in the answer. Part 8
Pr(X = 3 | 2nd image wrong) = Pr(both) / 0.2 The conditional the room added. The denominator is stated as 0.2 and the numerator is set up and never evaluated. This course finishes it as C(9, 2)(0.2)2(0.8)7: one error position is fixed, so two remain to be placed among nine. Part 9
