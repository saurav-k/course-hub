Descriptive summaries

FormulaRead it aloud asWhere
x̄ = ( ∑ xᵢ ) / n The arithmetic mean. Add every value, divide by how many there were. Uses the size of every value, so one enormous value moves it. Part 2
x̃ = the middle value once sorted The median. Sort, then take the middle; with an even count, average the two central values. Uses only the ordering, so a value's size never reaches it. Part 2

Expectation and the binomial

FormulaRead it aloud asWhere
E[X] = ∑ (value × its probability) Expectation, the long-run average of X. A weighted average in which each outcome is weighted by how likely it is. Part 3
P(X ≥ 6) = ∑k=610 C(10, k) (0.1)k (0.9)10−k The binomial tail. C(10, k) counts the ways to choose which k of 10 days are extreme; (0.1)k prices those k being extreme; (0.9)10−k prices the rest being quiet. Part 3
C(n, k) = n! / ( k! (n − k)! ) The binomial coefficient, "n choose k": how many different subsets of size k a set of size n has. C(10, 6) = 210. Part 3

The exponential model

FormulaRead it aloud asWhere
f(x) = λ e−λx, for x ≥ 0 The exponential density. λ is the rate, and one number fixes the whole curve. f is a density, not a probability: probabilities are areas under it. Part 4
median = ln(2) / λ, so λ = ln(2) / median Where the exponential's half-way point sits. Comes from setting P(X > m) = 0.5 and taking logarithms. ln(2) ≈ 0.693. Part 4
P(X > t) = ∫t∞ λe−λx dx = e−λt The tail probability: the whole area to the right of t. The integral collapses to one term, which is why this model is so convenient. Part 4

Estimating a rate, and its uncertainty

FormulaRead it aloud asWhere
p̂ = (1/n) ∑i=1n Xᵢ, with Xᵢ ~ Bernoulli(p) The sample proportion. Each Xᵢ is 1 for a click and 0 otherwise, so the sum counts clicks and dividing by n turns it into a rate. The hat means "estimated from data"; bare p is the truth we never see. Part 5
E[p̂] = p and Var(p̂) = p(1 − p) / n The estimator is unbiased, meaning right on average, and its spread shrinks as n grows. This one line drives Parts 5 and 6 entirely. Part 5
p̂ ≈ N( p, p(1 − p)/n ) The Central Limit Theorem applied here: for large n the estimate is shaped like a bell, whatever shape the individual pieces had. Part 5
Z = ( p̂ − p ) / √( p(1−p)/n ) ≈ N(0, 1), and Pr(|Z| ≤ 1.96) ≈ 0.95 Standardising: subtract the centre, divide by the spread, and measure the answer in spreads. 1.96 is simply where 95 percent of a standard bell curve lives. Part 5
SE = √( p̂(1 − p̂) / n ), and CI = p̂ ± 2 × SE The standard error, with the estimate standing in for the unknown p, and the 95 percent confidence interval built from it. Slide 14 uses the multiplier 2 rather than the exact 1.96. Part 5
SE ∝ 1 / √n Precision improves with the square root of sample size. Half the error costs four times the users; a tenth of the error costs a hundred times. Part 6

Correlation

FormulaRead it aloud asWhere
r = ∑(xᵢ − x̄)(yᵢ − ȳ) / √( ∑(xᵢ − x̄)² ∑(yᵢ − ȳ)² ) Pearson's correlation coefficient. The top adds up co-movement: positive when both values sit on the same side of their averages. The bottom rescales so the answer always lands between −1 and +1. Part 7
