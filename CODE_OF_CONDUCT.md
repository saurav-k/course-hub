# Code of Conduct

## Our pledge

We want this to be a place where anyone can learn and contribute without being made to feel unwelcome, regardless of experience, background, identity, or how basic their question is.

## Expected behaviour

- Be direct about the work and kind about the person.
- Critique the lesson, the explanation, or the code - never the contributor.
- Assume good faith. Most disagreements here are about accuracy, and accuracy is settled with a source, not with volume.
- Accept correction gracefully. A wrong explanation in a teaching repository is worth fixing quickly and without drama.

## Unacceptable behaviour

- Harassment, insults, or personal attacks of any kind.
- Discriminatory or demeaning comments.
- Publishing anyone's private information without permission.
- Sustained disruption of discussions or reviews.

## Scope

This applies in issues, pull requests, commit messages, and any other space where someone is representing this project.

## Enforcement

Report a problem by opening an issue, or privately to the repository owner if a public issue is not appropriate.
Reports are handled confidentially.
Maintainers may edit or remove contributions that violate this code, and may block repeat offenders.
