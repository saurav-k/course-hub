# AGENTS.md - Backend Engineering

Instructions for AI coding agents working inside this course folder.
The repository root [`../AGENTS.md`](../AGENTS.md) still binds, and it wins wherever the two disagree.
This file adds only what is true of this course and nowhere else.

## What this course is

The first-principles backend course of the hub, derived from the open
[Backend from First Principles](https://github.com/DsThakurRawat/Backend-from-first-Principle) field
manual. One connected route from a single request to a horizontally scaled fleet. 13 modules, lesson
shape, Go and Python implementation voices. `MISSION.md` owns why it exists; `PLOT.md` owns the order.

## Read before you write

In this order:

1. [`MISSION.md`](MISSION.md) - why it exists, the learner, and out of scope. Canonical, settled by
   interview; do not rewrite it as a side effect of other work.
2. [`NOTES.md`](NOTES.md) - how this course teaches and the gotchas found while authoring it.
3. [`BUILDER-SPEC.md`](BUILDER-SPEC.md) - the markup contract and the derivation rules.
4. [`RESOURCES.md`](RESOURCES.md) - the canon and the attribution contract. Add anything new there
   before citing it.
5. [`PLOT.md`](PLOT.md) - the true reading order and everything planned but unwritten. Place any new
   session by it, never at the bottom.
6. Two neighbouring lessons, to match voice, depth and structure.

## The rules that bite hardest here

- **This is a derived course, not a copy.** Every page is re-authored prose and re-drawn diagrams from
  first principles. Never transcribe the source series' text or lift its figures. Name the source in
  `RESOURCES.md` and link the primary source per page, but write the page yourself.
- **Every mechanism is owned, never waved at.** When a page names a framework behaviour it names the
  mechanism underneath; the framework is never the reason.
- **Both implementation voices.** A mechanism appears in Go and Python where the page needs code.
- **Certainty is earned.** Unsourceable claims go to `RESOURCES.md` under `## Gaps`, not into a page.

## Out of scope here

Cloud platforms, any single framework's docs, and a full protocol catalogue. `MISSION.md` owns the
list and the neighbours who cover them.
