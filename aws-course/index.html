Inside AWS

Amazon Web Services, taught end to end as one connected platform: how its accounts, networks, identities and services actually fit together. Service-by-service documentation tells you what each piece is; this course shows how the pieces compose into a platform you can reason about.

Written for an engineer who is new to AWS but not to cloud computing. Every page teaches one idea with diagrams first and cites Amazon Web Services's own documentation for every claim. The course is being written module by module, and only from verified research: no topic reaches a page before it has been checked against the vendor's own documentation. Start at Module 01 even if you know clouds generally, because every later module grounds its vocabulary there.
