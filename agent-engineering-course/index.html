AGENT ENGINEERING Glossary Course Hub
The build track, for engineers operating agents in production

A demo agent is a loop. A production agent is a distributed system.

The gap between the two is not model quality. It is context you manage rather than accumulate, evaluation that grades the path and not just the answer, state that survives a deploy, a bill that cannot run away overnight, and isolation that holds when one agent reads something hostile. Five chapters, eighteen topics, a linked primary source for every one.

Written for engineers who already know distributed systems. Start with Chapter 1, keep the Glossary open in a tab, and read the sibling AI System Design course when you need the interview framing for the same material.
