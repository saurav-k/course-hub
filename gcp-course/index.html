Inside Google Cloud

Google Cloud, taught end to end as one connected platform: how its projects, networks, identities and services actually fit together. Service-by-service documentation tells you what each piece is; this course shows how the pieces compose into a platform you can reason about.

Written for an engineer who is new to Google Cloud but not to cloud computing. Every page teaches one idea with diagrams first and cites Google Cloud's own documentation for every claim. The course is being written module by module, and only from verified research: no topic reaches a page before it has been checked against the vendor's own documentation. Modules are written and released one at a time; the modules still listed as planned are recorded here so later work has a place to attach.
