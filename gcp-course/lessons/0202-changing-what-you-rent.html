Module 02 · Compute · Lesson 0202

Five levers change what a rented machine is, and each one is paid for differently

working 7 min Capabilities gpu-compute, dedicated-hosts, confidential-compute, bare-metal and spot-capacity.

The one-minute version

  • Beyond family and size, five properties change what a Compute Engine machine actually is, and they are independent of one another.
  • Accelerators: attach GPUs to a machine, or use Cloud TPUs, Google's own tensor processors sold as multi-host slices.
  • Sole tenancy: your instances on a physical host reserved to you, for licensing and isolation, at node pricing rather than instance pricing.
  • Confidential computing: memory encrypted from the hypervisor, with attestation so the workload can prove what it is running.
  • Bare metal removes the hypervisor entirely for a narrow set of workloads, and Spot trades the deepest discount for capacity the platform may reclaim.

1. The five, placed against each other

2. Accelerators, and the zone question underneath them

Cloud GPUs attach NVIDIA accelerators - the T4, L4, A4 and H-series lines - to a machine, or arrive as part of a GPU-optimized machine type. Cloud TPUs are Google's own tensor processors for machine-learning training and inference, sold as v5e, v5p and v6e-class slices. The word slice is the one to hold: a TPU allocation has a topology, and multi-host topology is what large training runs are actually designing against.

Accelerator availability is a zone question, not a region question, because accelerator hardware sits in designated AI zones. A region that lists an accelerator does not offer it in every zone inside itself, and this is the single most common way an accelerator deployment fails on the first attempt. Check the regions and zones page for the specific zone before committing a design to a location.

3. Two different meanings of "dedicated"

Sole-tenant nodes are dedicated physical hosts for licensing and compliance isolation of your own virtual machines, arranged through node templates and node groups, and billed per node at premium pricing with affinity labels deciding what lands where. Confidential VMs and Confidential Space encrypt memory and support attestation, using the hardware technology of the machine series they run on. Bare Metal is single-tenant physical servers for specialised and licensed workloads, notably Oracle, and its workload focus is narrow enough that the region list should be checked before anything is promised to a customer.

4. The lever that pays you

Spot VMs are deeply discounted reclaimable capacity with no service level agreement and no fixed maximum runtime. That last property is a change from the older shape: preemptible VMs, which still exist as a separate provisioning model, could only run for twenty-four hours at a time. A design carried over from the preemptible era may therefore contain a restart cycle it no longer needs, and new designs use Spot.

The reframing These five compose. A Spot instance can carry a GPU. A confidential machine can sit on a sole-tenant node. Because they compose, the useful question is never which one of these do I want - it is which constraint am I removing, and what am I paying for it, asked once per lever. Four of the five are paid in money and one is paid in interruption.

Check yourself

Retrieval practice

Answer from memory before revealing.

A long-running job is moved onto Spot VMs to cut costs. What is the design question that follows?
Spot capacity is reclaimable and carries no service level agreement, so interruption handling is the whole design. The first option describes the older preemptible shape, whose twenty-four hour cap Spot does not have. The second is answered by there being no agreement at all. The third invents a tier.
A workload must keep its memory opaque to the hypervisor but has no licensing requirement. Which lever fits?
Memory encryption with attestation is exactly what confidential computing sells. Sole tenancy controls whose virtual machines share the host and leaves the hypervisor in place. Bare metal would satisfy the requirement and buys far more than was asked for. The fourth confuses a hardware profile with an isolation property.
A deployment using a particular accelerator fails in a region that lists it. What is the likeliest reason?
Accelerators live in designated AI zones, so a region can list hardware it does not hold in every zone. The fourth option names a real constraint that a clear error message would state, which makes it the strongest distractor. The first and second attach plausible platform mechanisms to the wrong problem.

Practice about 15 minutes, with paper

Practice 1working

A research team runs nightly model training that can checkpoint and resume, on hardware accelerators, for a customer whose contract requires that the workload's memory not be readable by the platform operator.

List which levers this design pulls, state what each one costs, and name the one placement fact that could stop the whole design.

Hint

Take the requirements one at a time and match each to exactly one lever. Then ask where the hardware for the first lever physically is.

Show the worked solution
  1. Match the accelerator requirement. Training on accelerators pulls the GPU or TPU lever. The cost is a higher rate and a narrower set of places the machine can exist.
  2. Match the memory requirement. Memory that the operator cannot read is the confidential computing lever - encrypted memory with attestation. The cost is a higher rate and a dependency on the hardware technology of the series chosen.
  3. Match the interruption tolerance. Work that checkpoints and resumes is exactly the Spot case, so the third lever is reclaimable capacity. Its cost is paid in interruption rather than money, and it is the only one of the three that lowers the bill.
  4. Name the placement risk. Accelerator hardware sits in designated AI zones. If no AI zone in the chosen region also offers the confidential and Spot combination the design needs, the design fails on availability rather than on configuration - so the zone is checked before anything else is built.

Sanity check. Three levers, two paid in money and one in interruption, and a placement constraint that is a zone rather than a region. If the answer named sole tenancy or bare metal, re-read the memory requirement: it asks for memory the operator cannot read, which reserving a host does not by itself provide.

Your teacher. If sole tenancy and confidential computing still blur together, ask an agent what each one changes about who can read the workload's memory. The answers are different in kind, and that difference is why both products exist.
