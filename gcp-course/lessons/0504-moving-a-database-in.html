One service ends in a cutover, the other never ends

working 7 min Capabilities db-migration-service, change-data-capture and database-fleet-management. Sourced from Database Migration Service and Datastream.

The one-minute version

  • Database Migration Service performs homogeneous migrations - MySQL, PostgreSQL and SQL Server - into Cloud SQL and AlloyDB, keeping up with the source by continuous change capture.
  • It finishes with a promotion: the destination stops following the source and becomes the database. The documentation positions the service itself as free, with networking paid for.
  • Datastream is change data capture as a service: a backfill plus a stream, from Oracle, MySQL, PostgreSQL and SQL Server, into BigQuery, Cloud SQL and Spanner.
  • The difference is the ending. A migration is meant to stop; a change feed is meant to keep running, and it usually feeds a different kind of system than the source.
  • Database Center is the fleet-level view across databases. The inventory records it as preview and says to verify its stage before relying on it.

1. Two shapes, told apart by their ending

2. The promotion, which is the part people plan badly

Database Migration Service is homogeneous by design: the engine is the same on both sides, which is what lets the destination be a faithful replica rather than a translation. Its destinations are Cloud SQL and AlloyDB, so a migration through this service lands on the relational tier of lesson 0500. The documentation positions the service as free, with the networking it uses paid for in the ordinary way, which removes cost as a reason to hurry the promotion.

3. The feed that has no ending

Datastream also reaches a source that Database Migration Service does not: Oracle. That is worth holding, because an Oracle estate that has to stay where it is can still have its changes land in BigQuery continuously, and that is a very different project from moving it.

4. Seeing the whole fleet

Database Center is a fleet-level console for database health, security, cost and reliability across the estate, and the verified inventory records it as preview, with an explicit instruction to verify its stage before teaching it as settled. Treat it as a place to look rather than a control to build a process on, and check the current stage on its documentation page.
The reframing Both services read a change log and neither one is chosen for that. Database Migration Service is a project with an end date, and its whole design is about making the end safe. Datastream is a pipeline with no end date, and its whole design is about staying current. The word "replication" covers both and distinguishes neither, which is why the question to ask is about the source's future.

Check yourself

Retrieval practice

Answer from memory before revealing.

An Oracle database must stay in the data centre, and its changes must reach BigQuery continuously. Which service does this?
Datastream reads Oracle and writes to BigQuery, and the source stays authoritative because nothing promotes. The first names a service whose sources do not include Oracle and whose ending would retire the source. The third describes a console as though it moved data. The fourth is the over-reading of an absence - Oracle is a Datastream source.
What does promotion do at the end of a Database Migration Service job?
Promotion ends the following relationship, which is why it is the one-directional moment worth rehearsing. The first describes the following state, which is what promotion leaves. The second invents a resizing step. The third describes a reverse replication the service is not recorded as providing.
How should Database Center be treated in a design right now?
The inventory records it as preview and says to verify the stage, so it is a place to look rather than a dependency. The first builds on something not recorded as settled. The second invents a retirement. The fourth narrows it - health, security and reliability are in its scope alongside cost.

Practice about 15 minutes, with paper

Practice 1working

A retailer runs two databases. A PostgreSQL order store in its own data centre is being retired at the end of the programme, and its application will point at Google Cloud instead. An Oracle inventory system is staying where it is for contractual reasons, and the analytics team wants its changes in the warehouse within minutes.

Choose a service for each, name the ending each one has, and say which of the two decisions can be rehearsed and how.

Hint

One source disappears and one does not. That single fact assigns both services before any other property is considered, including the engine.

Show the worked solution
  1. Place the order store. The source is retired, the engine is PostgreSQL on both sides, and the destination is the relational tier. That is Database Migration Service, into Cloud SQL or AlloyDB depending on what lesson 0500 decided about the query shape.
  2. Place the inventory system. The source stays authoritative and the destination is analytical, so it is a change feed rather than a migration. Datastream reads Oracle and writes to BigQuery, backfilling first and then streaming.
  3. Name the endings. The first ends at promotion, after which the destination is the database and the old server is decommissioned. The second has no ending: for as long as the Oracle system exists, the warehouse copy is derived and never authoritative.
  4. Say what can be rehearsed. Only the first. While the migration job is in its following state the source is still live, so the application can be pointed at the destination in a test, the row counts compared and the query plans checked, all before promotion is spent. The change feed has nothing equivalent, because it has no cutover to rehearse.

Sanity check. Your two answers should have been decided by the fate of the source rather than by the engine. If you reached for Database Migration Service on the Oracle system, note that promotion would have retired a database the contract says must stay.

Your teacher. If a project calls its work "replication" and the plan is unclear, ask an agent one question: what is the source doing six months from now. An answer of "switched off" is a migration with a promotion to rehearse, and an answer of "still taking writes" is a feed you will be operating for years.
