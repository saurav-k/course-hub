Practice problems

P1easyrates from a table

An evaluation set of 500 rows: the model flags 90; of those flagged, 60 are truly positive; there are 150 true positives in total. Compute TP, FP, precision, recall, FPR and FNR.

Solution

TP = 60; FP = 30; precision = 60/90 = 0.667; recall = 60/150 = 0.400; FN = 90 so FNR = 90/150 = 0.600; negatives = 350, TN = 320, FPR = 30/350 = 0.0857. Read-back: catches 40% of real cases while burning 8.6% of honest ones.

P2easythe base-rate trap, computed

Prevalence 1%, sensitivity 90%, FPR 5%. Compute PPV exactly and explain the result in one sentence.

Solution

Per 10,000: TP = 100 x 0.9 = 90; FP = 9,900 x 0.05 = 495; PPV = 90/585 = 0.1538. Sentence: even with excellent-looking operating characteristics, a flagged case is more likely innocent than not at this prevalence - the flags are mostly false. (The Bayes derivation lives in Bayes rule; the trap itself in the base rate trap.)

P3mediumECE by hand

Bins: [0, 0.5): n = 100, mean p-hat 0.30, observed frequency 0.20. [0.5, 0.8): n = 60, mean 0.62, observed 0.50. [0.8, 1]: n = 40, mean 0.92, observed 0.75. Compute ECE and write the one-line verdict. Then say which single bin contributes most to the number, and check whether it is the one with the largest gap.

Solution

Weighted gaps: 100/200 x |0.20-0.30| = 0.050; 60/200 x |0.50-0.62| = 0.036; 40/200 x |0.75-0.92| = 0.034. ECE = 0.120. Verdict: every bin promises more than it delivers and the gap widens with confidence - precisely the pattern temperature scaling softens. The largest contribution is the first bin's 0.050, from the smallest gap of the three (0.100), because it carries half the rows; the largest gap (0.170) sits in the lightest bin and contributes least. Weights matter as much as gaps.

P4mediumtemperature arithmetic

Logit 2.0 gives sigmoid(2.0) = 0.881. After scaling by T = 2 compute the new probability; then find T mapping logit 2.0 to p = 0.70 approximately. Finally: this row sat above a threshold of t = 0.80 before scaling. Is it still flagged at t = 0.80 after T = 2, and at what threshold t' does the original decision reappear?

Solution

T = 2: sigmoid(1.0) = 0.731. For p = 0.70: z/T = ln(0.7/0.3) = 0.8473, so T = 2/0.8473 = 2.36. Direction note: T above 1 cures overconfidence; this week's fitted value sat below 1 because its distortion ran the other way. The fix follows the sign of the disease.

The threshold part: after T = 2 the row scores 0.731, which is below 0.80, so it is no longer flagged at t = 0.80 - the decision moved, because 0.80 is not the sigmoid's midpoint. The original decision reappears at t' = sigmoid(logit(0.80)/2) = sigmoid(1.3863/2) = sigmoid(0.6931) = 0.6667, and 0.731 clears that. Scaling relabelled the operating point rather than removing it. Had the threshold been 0.5, nothing would have moved at all: logit(0.5) = 0, and zero divided by any T is still zero.

P5mediumMurphy decomposition

Prevalence pi = 0.3. Forecaster A outputs 0.3 for everyone. Forecaster B outputs 0.1 to half the population (true frequency there really 0.1) and 0.5 to the rest (really 0.5). Compute both Brier scores and identify uncertainty, reliability, resolution.

Solution

A: Brier = 0.3 x 0.49 + 0.7 x 0.09 = 0.210, the uncertainty term alone - calibrated, zero resolution. B: low-half contribution 0.01 x 0.9 + 0.81 x 0.1 = 0.090; high-half 0.125 + 0.125 = 0.250; mean = 0.170. Reliability still perfect, so resolution gained = 0.210 - 0.170 = 0.040 and Brier = uncertainty - resolution. Calibration without resolution is the constant weather app: paid only for information that changes decisions.

P6medium-codebootstrap an accuracy CI

Add to your bench copy: resample n rows with replacement 1000 times (seeded LCG), recompute accuracy each time, report the 2.5 and 97.5 percentiles. Run on the default dataset and state the interval.

Solution sketch

Expected output at n = 2000 around accuracy 0.8255, with seed 99 and B = 1000: [0.8130, 0.8310], width 0.0180, and not centred on the point estimate - percentile intervals need not be symmetric. The two classic bugs both look plausible: reseeding inside the loop collapses all resamples into one identical draw (interval width zero); sampling without replacement permutes rather than resamples (same collapse). Print width alongside 1/sqrt(n) so either failure announces itself.

P7hardderive the trade-off identity

Group g has prevalence pi_g. With v_g = PPV_g at threshold t, derive FPR_g/TPR_g = [pi_g/(1-pi_g)] x [(1-v_g)/v_g] from the four confusion-matrix counts, and conclude that unequal prevalences force equal error rates and equal PPV to be mutually exclusive. Then state, in one sentence each, what Chouldechova's theorem assumes and what Kleinberg-Mullainathan-Raghavan's assumes - they are not the same hypothesis.

Solution

Count the group's rows: TP_g = TPR_g pi_g n_g and FP_g = FPR_g (1-pi_g) n_g, so v_g = TP_g/(TP_g+FP_g) gives v_g(TPR_g pi_g + FPR_g(1-pi_g)) = TPR_g pi_g. Expand, subtract, divide: v_g FPR_g(1-pi_g) = TPR_g pi_g(1-v_g), which is the identity. Note that no calibration assumption was used anywhere - only the definitions of three rates - so the identity binds every classifier. If both groups share error rates and predictive parity, the right sides must agree; cancelling the shared (1-v)/v leaves pi_0/(1-pi_0) = pi_1/(1-pi_1), and since x -> x/(1-x) is strictly increasing on (0,1), pi_0 = pi_1 - contradicting unequal prevalence.

The two hypotheses. Chouldechova (arXiv:1703.00056) assumes predictive parity and unequal prevalence, and concludes that equal FPR and equal FNR cannot both hold; calibration is never assumed. KMR (arXiv:1609.05807) assumes calibration within groups plus balance for the positive class plus balance for the negative class, and concludes that all three hold together only under perfect prediction or equal base rates. Lesson 7 verifies the identity numerically to six decimals: 0.215833 against 0.215833, and 0.208018 against 0.208018.

P8hardaudit your own week-4 model

Export {y, logit} rows for 1000 held-out rows from your logistic regression test suite; paste into the bench on lesson 9; produce the complete card: confusion family at t = 0.5 with all six rates and intervals; ROC/AUC; reliability and ECE before and after temperature scaling fitted on half, compared at t = 0.5 so the decision is genuinely unchanged on both sides; group gaps if any grouping was recorded (else split on a feature median and label it a proxy analysis honestly); aleatoric-vs-epistemic paragraph; recommendation.

Grading checklist - this IS milestone five

Not a single number but a document, graded against: every required field present; threshold declared exactly once; T fitted on disjoint rows; every headline number carrying an interval; the fairness section naming which criterion was sacrificed; prose a manager can read without a glossary. Common failures and their tells: leakage (after-scaling ECE spectacular on reported rows, gone on fresh ones), an undeclared or quietly moved threshold (group section contradicts its criterion line), missing intervals (rumours masquerading as results).

Design problem the week's summit - budget an evening

Designhardaudit a deployed system you did not build

Take ProPublica's COMPAS-derived rows (github.com/propublica/compas-analysis, published for replication; journalism by Angwin et al. 2016 - download there, extract score/label/race rows yourself, attribute, and paste into the bench; nothing is fetched or redistributed here). Or UCI Adult rows if you prefer income prediction. Write the audit card as if evaluating a vendor system for renewal. You choose: the threshold policy to evaluate; which fairness criterion your organisation treats as binding and WHY - stated as an explicit value judgement, because the mathematics refuses to decide it; what you demand from the vendor next quarter; and the exact additional data that would let you separate aleatoric from epistemic error here.

Rubric - grade yourself before anyone else does

Fail: single accuracy quote; no interval; fairness discussed as vibes ("the data is biased") without rates.
Pass: correct confusion-matrix family at ONE declared threshold; reliability diagram plus ECE; both groups' rates shown; names the binding criterion and its cost.
Strong: adds bootstrap intervals on every quoted number; runs the base-rate demonstration on THIS data and connects it to the impossibility identity; distinguishes aleatoric versus epistemic residual error with evidence; recommendation is falsifiable ("if the recalibrated FPR gap remains above X, do not renew without a parity condition").
Excellent: also audits its own audit - binning choices stated, CI method stated, proxy-label caveats explicit, and a paragraph on what this evaluation set cannot show (deployment shift, gaming).
