Open the hood: forward pass and activations

10 min read the internals live Hover any point of input space and the page replays the entire forward pass for you - every layer's pre-activations, every activation, the final probability. Then delete the activations and watch three layers collapse into one line.

The one-minute version

  • The forward pass is bookkeeping: multiply, add bias, squash, hand to the next panel. Eighty-eight multiplies per input, left to right.
  • The new hover inspector shows that bookkeeping for any point you park on: layer pre-activations z, activations a, and p̂.
  • A hidden neuron sitting near zero is not broken - it is in its nearly-linear region, casting a weak vote (that reading matters when you debug real nets).
  • Switching the hidden activation to none makes the whole stack one big linear map: the bent boundary snaps back to a line. Non-linearity was the only thing depth was buying.

1. The pass, written out once

For an input (x, y), the 2–8–8–1 net computes, in order:

z(1)j = w(1)1j x + w(1)2j y + b(1)j,    a(1)j = tanh( z(1)j )   for j = 1..8 Layer 1: eight voters each produce a pre-activation z (the raw weighted vote) and an activation a (after the squash). Superscripts name the layer; this week's notation bar from lesson 1 still holds.
z(2)j = w(2)j · a(1) + b(2)j,    a(2)j = tanh( z(2)j ),    p̂ = sigmoid( w(3) · a(2) + b(3) ) Layer 2 reads layer 1's activations - not the raw inputs - which is why composition deforms space. The output neuron squashes its own pre-activation with the sigmoid, exactly as week 4 did.

Nothing in those lines knows anything about moons or blobs; the same arithmetic runs for every input. That indifference is what makes the inspector below possible: it just runs these lines wherever your mouse sits.

2. Read a point like an engineer

Two readings worth practising until they are reflexes. Near-zero tanh activations are information, not breakage. tanh(z) ≈ 0 means z ≈ 0, meaning the point sits almost exactly on that voter's decision edge - the nearly-linear knee where the voter is least committed. A point whose classification you care about is being decided mostly by the voters with large-magnitude activations, the ones deep in their saturated flats. And saturated is normal: most trained neurons spend most inputs far from their knees. A whole layer pinned near zero for every input would be suspicious; individual zeros are just geometry.

3. Delete the non-linearity and lose everything

The activation select is the experiment lesson 2 set up. Set hidden activation to none: every g becomes the identity, so the network computes

p̂ = sigmoid( W(3) W(2) W(1) x + (W(3) W(2) b(1) + W(3) b(2) + b(3)) ) = sigmoid( W x + b ) A product of matrices is one matrix, and sums of biases fold into one bias. Three stacked linear maps are algebraically indistinguishable from a single linear map plus squash: the same model week 4 built, wearing sixteen neurons' worth of parameters it does not need.

Watch the boundary snap back to a straight line mid-hover and accuracy on moons collapse to the same straight-line ceiling lesson 2 mapped - about 0.83 here after eight hundred epochs, against 1.000 once tanh is restored. The bent boundary is gone, produced by a network with 88 connections that now cannot use them. Reset, retrain with tanh restored, and the bend returns. Depth without non-linearity buys nothing but parameter count; the squashing functions are the only reason layers compound instead of collapse.

4. Check yourself

You delete every tanh activation but keep all weights and layers. What is the biggest model you now have?
Composition of linear maps is linear: W³(W²(W x)) folds into a single W x before the sigmoid ever sees anything. You verified this empirically above - the bent boundary snapped straight and moons became unfittable again. Piecewise-linearity would require the bends, so option two describes the healthy case, not this one. And capacity lives in the function class the architecture can express, not in how many unused numbers sit in the weight arrays.
Hovering a point shows layer-1 activations all near zero. For a tanh layer, what does that tell you?
tanh(z) near zero means z near zero: the point lies almost on each voter's edge, where its slope is steepest but its commitment weakest. Dead neurons - permanently zero outputs - are a real phenomenon, but they show up as zeros across all inputs, not one hovered point. Convergence changes weights, not the shape of tanh; and the inspector runs the very same forward pass the training loop uses, so if it were wrong the loss curve would be wrong too.

Where this came from

The forward pass as repeated affine-plus-squash blocks follows the CS231n notes presentation; Nielsen's chapter 1 develops sigmoid and tanh neurons' behaviour around the knee, which section 2 leans on. The collapse-to-a-linear-map identity is standard linear algebra; the empirical half of it is reproducible in the build above via the activation select.
