Stacking neurons into a network

11 min composition bends boundaries Eight week-4 votes feed eight more, which feed one final vote. Nothing else changes - and the straight line that could not follow two moons bends around both crescents while you watch.

The one-minute version

  • A hidden layer is just several neurons reading the same inputs; their outputs become the next layer's inputs. That is the entire definition.
  • Composition is the point: many slightly-bent pieces combine into one thoroughly bent function. The 2–8–8–1 net below reaches about 100% accuracy on moons within roughly 600 epochs at the default learning rate.
  • Architecture becomes clickable today: the hidden-size pickers change how many voters each layer fields.
  • The forward pass of 2–8–8–1 costs 2×8 + 8×8 + 8×1 = 88 weight-multiplies per input - a number that matters in lesson 5 when backpropagation refuses to pay it 88 times over.

1. A layer is a panel of voters

Take eight copies of last lesson's neuron, give each its own weights and bias, and let them all read the same two inputs x and y. Each computes zj = wj·x + bj, then passes it through an activation g. One change from week 4's squash: the hidden neurons here use tanh, which maps z into (−1, +1) instead of (0, 1). It is the same kind of object - a smooth bend - but its slope near z = 0 is steeper (1 rather than ¼), which turns out to matter for how fast signal flows backwards; lesson 5 leans on exactly that fact. The output neuron stays sigmoid: it still has to emit a probability.

So a "layer" is nothing more than a panel of voters reading identical inputs, and a "deep network" is panels feeding panels, with the week-4 classifier taking the final vote:

3. Why stacking buys bending

The mechanism deserves one careful sentence more than "deep learning finds patterns". Each hidden voter carves input space with its own soft edge - tanh(z) is nearly flat for very negative z, crosses zero steeply near z = 0, and flattens again for large positive z. A point sitting right on voter j's edge gets a middle-of-road vote from it; a point far off gets a saturated one. Layer two reads those votes instead of raw coordinates, so its own edges cut through vote space, which is space already deformed by layer one's edges. Chaining the deformations is how the final boundary acquires corners and arcs no single line could trace. Lesson 4 makes this literal: you will hover points and read each voter's exact output.

More is not automatically betterThe pickers invite the classic experiment: crank both layers to 16 on moons. Training slows noticeably, and while the fit looks fine here, there is no free lunch - a bigger panel memorises quirks as readily as shapes, and lesson 8 shows what that looks like when the data gets noisy. Capacity is a budget, and you are now spending it in public.

4. Count the machinery

One forward pass through 2–8–8–1 costs 2×8 multiplies in layer one, 8×8 in layer two, and 8×1 in the output: 16 + 64 + 8 = 88 weight-multiplies, plus biases and activations. Hold that number. In lesson 5 you might be tempted to verify a gradient by nudging each of the 88 weights and measuring the loss change twice per weight - 176 extra forward passes per check - and you will instead learn the chain-rule trick that prices all 88 weights in one backward sweep. The counting habit also explains why hidden-size pickers matter at all: doubling both layers roughly quadruples the middle term.

5. Check yourself

The forward pass of the 2–8–8–1 net computes, for one input, roughly how many weight-multiplies?
Each connection between a unit in layer l and a unit in layer l+1 costs exactly one multiply, so the total is the sum of per-layer products: 2×8 + 8×8 + 8×1 = 88. Nineteen confuses neurons with connections; 176 doubles for no reason - the backward pass reuses the same weights but is not a second forward pass; and 512 is the product of everything, which counts connections that do not exist - layer 2 never reads the raw inputs directly. Remember 88: lesson 5's finite-difference checker exists because checking gradients naively would cost 176 forward passes per check.

Where this came from

Composition of simple voters as the mechanism of depth is the standard account; the CS231n notes develop it layer by layer with the same counting arithmetic as section 4. Nielsen's chapter 1 introduces networks exactly as perceptron-stacks with squashing outputs, which is the framing this page runs with. Architecture constants (2–8–8–1, tanh hidden, sigmoid output, Xavier-style init) match the validated prototype in assets/builds/glassnet.js.
