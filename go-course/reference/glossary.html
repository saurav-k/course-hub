Glossary

12 terms The essential systems engineering vocabulary defined across 17 open-source codebases. Print it and keep it beside the code.

TermWhat it means here
Linux Namespaces Kernel isolation feature dividing system resources (PID, Mount, Net, IPC, UTS, User) so a process sees an isolated view of the OS. Configured via syscall.SysProcAttr in Go.
Control Groups (cgroups) Kernel mechanism for metering, limiting, and throttling CPU, memory, and I/O for a collection of processes. Managed via the cgroup filesystem tree in /sys/fs/cgroup.
Shim Pattern A lightweight, independent process (such as containerd-shim-runc-v2) that acts as the direct parent of a container process, holding its open file descriptors and exit status across daemon restarts.
Content-Addressable Storage (CAS) Storage architecture where files and blobs are identified, indexed, and retrieved strictly by their cryptographic hash (e.g. SHA-256), used in OCI image layers and Git.
Raft Ready Pattern A state machine design (championed by etcd/raft) that isolates consensus state transitions from I/O by returning an immutable Ready struct containing entries to save, messages to send, and committed entries to apply.
Write-Ahead Log (WAL) An append-only log on durable disk storage written and synced (via fdatasync) before any in-memory state is modified, ensuring crash recovery.
SWIM Protocol Structured Weakly-Consistent Infection-Style Process Group Membership Protocol, a decentralized gossip protocol with bounded failure-detection latency used in Consul's memberlist.
Multi-Raft A distributed consensus architecture where a database splits data into thousands of discrete ranges, each running an independent Raft consensus group, as implemented in CockroachDB.
Informer-Reconciler Loop Kubernetes' core pattern combining a cached local index (Informer), a change event queue (DeltaFIFO), and rate-limited worker goroutines (Workqueue) to drive actual state toward desired state.
Directed Acyclic Graph (DAG) A graph of directed edges containing no closed loops, used by Terraform to compute resource dependency order, parallelize independent operations, and guarantee safe destruction order.
Envelope Barrier Encryption A security model (used in Vault) where a high-entropy data encryption key encrypts plaintext data, and is itself encrypted by a key-encrypting key protected by Shamir secret shares.
Time-Series Chunking A compact storage format (used in Prometheus TSDB) grouping 2 hours of timestamp/value sample pairs into compressed byte slices using Gorilla XOR float compression.
