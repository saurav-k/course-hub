17 landmark systems disassembled

Go is the runtime language of the modern cloud; these 17 open-source systems show how it is built.

From container isolation and Raft consensus to declarative reconciliation, dynamic proxies, and TSDB storage engines. Docker, Kubernetes, containerd, Helm, Terraform, Vault, Consul, Nomad, Prometheus, Grafana, etcd, CoreDNS, Traefik, Caddy, Hugo, MinIO, and CockroachDB taken apart at their real Go packages.

Start with how Go talks to the Linux kernel, keep the Glossary open in a tab, and cross-reference with Backend Engineering when studying distributed service boundaries.
